# Cas 25.20

SOURCE : *Examen intercalaire R3 Microbiologie — 20 juillet 2025, Constantine*

L’interprétation d’un ECB des urines prélevées en l’absence de matériel endo-urinaire se fait en fonction de la présence de signes cliniques, d’une leucocyturie et d’une bactériurie.

Complétez le tableau suivant :

| Signes cliniques | Leucocyturie ⩾ 10^4^/mL | Bactériurie avec au plus **DEUX** micro-organismes différents | Interprétation | Antibiogramme |
|---|---|---|---|---|
| + | + | ⩾ 10^3^ UFC/mL |  |  |
| + | + |  |  | Non applicable |
| + | - | ⩾ 10^3^ UFC/mL |  | Oui ( si monomicrobien) |
| + | - | ⩾ 10^3^ UFC/mL | Patient immunodéprimé (Chimiothérapie, greffe…) : Possible infection urinaire |  |
| - | Variable |  | Colonisation | Non |
| - | Variable | < 10^3^ UFC/mL |  | Non applicable |

#### CORRIGÉ · CAS 25.20

*Corrigé type issu du document d’examen, reproduit tel quel.*

| Signes cliniques | Leucocyturie ⩾ 10^4^/mL | Bactériurie avec au plus **DEUX** micro-organismes différents | Interprétation | Antibiogramme |
|---|---|---|---|---|
| + | + | ⩾ 10^3^ UFC/mL | Infection urinaire | Oui |
| + | + | < 10^3^ UFC/mL | Inflammation sans bactériurie. Traitement antibiotique en cours. Micro-organismes à culture lente ou difficile. Etiologie non infectieuse | Non applicable |
| + | - | ⩾ 10^3^ UFC/mL | Patient immunocompétent : refaire ECBU (suspicion d’infection urinaire débutante) | Oui ( si monomicrobien) |
| + | - | ⩾ 10^3^ UFC/mL | Patient immunodéprimé (Chimiothérapie, greffe…) : Possible infection urinaire | Oui |
| - | Variable | ⩾ 10^3^ UFC/mL | Colonisation | Non |
| - | Variable | < 10^3^ UFC/mL | Absence d’infection urinaire OU colonisation | Non applicable |
