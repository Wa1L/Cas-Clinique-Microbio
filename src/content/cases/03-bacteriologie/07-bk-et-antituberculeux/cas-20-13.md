# Cas 20.13

T1 : Témoin 1 ; T2 : Témoin 2.

R : Rifampicine. H : Isoniazide. S : Streptomycine. E : Éthambutol.

TCH : Hydrazide de l’acide thiophène 2-carboxylique.

PNB : Acide para-nitro-benzoïque.

SM : solution mère

|---|---|---|---|---|---|---|---|---|
| SM | ∞ | ∞ |  |  |  |  |  |  |
| 10^-2^ | 50 | 100 |  |  |  |  |  |  |
| 10^-4^ | 250 | 200 |  |  |  |  |  |  |

#### CORRIGÉ · CAS 20.13

*Corrigé type issu du document d’examen, reproduit tel quel.*

Avant d’interpréter il faut d’abord regarder les témoins de chaque dilution et s’assurer que les dilutions sont respectées. Donc pour pouvoir interpréter il faut que le nombre de colonies des témoins de :

- la SM soient de l’incomptable ;
- la dilution 10^-2^ soient +/− comptable ;
- la dilution 10^-4^ soient comptable.

Et là dans cet exemple il y a un problème technique de dilutions : dans les témoins de la dilution 10^-4^ le nombre de colonies est plus important que dans la dilution 10^-2^ ⇒ antibiogramme non interprétable, dilutions non respectées.
