# Cas 6.36

SOURCE : *Épreuve de TP de virologie*

Résultats des marqueurs biologiques du virus de l’hépatite B :

| Ag HBs | Anti-HBc | Anti-HBs | ADN viral, Ag HBe, anti-HBe |
|---|---|---|---|
| − | Anti-HBc − | Anti-HBs − |  |
| − | Anti-HBc − | Anti-HBs + |  |
| − | Anti-HBc + | Anti-HBs + |  |
| − | IgM anti-HBc + ; Anti-HBc + | Anti-HBs − |  |
| − | IgM anti-HBc − ; Anti-HBc + | Anti-HBs − |  |
| + | IgM anti-HBc + ; Anti-HBc + | Anti-HBs − |  |
| + (> 6 mois) | IgM anti-HBc − ; Anti-HBc + | Anti-HBs − |  |
| + (> 6 mois) |  |  | ADN viral + (> 10^5^ copies/mL) ; Ag HBe + ; Anti-HBe − |
| + (> 6 mois) |  |  | ADN viral + (> 10^5^ copies/mL) ; Ag HBe − ; Anti-HBe + (transaminases élevées) |
| + (> 6 mois) |  |  | ADN viral − (< 10^5^ copies/mL) ; Ag HBe − ; Anti-HBe + (transaminases normales) |

#### CORRIGÉ · CAS 6.36

*Corrigé type issu du document d’examen, reproduit tel quel.*

**Interprétation et commentaire**, dans l’ordre des lignes du tableau :

1. Pas d’infection par le VHB : personne à vacciner en fonction de l’âge et des facteurs de risque.
2. Personne vaccinée.
3. Personne guérie.
4. Infection aiguë en voie de guérison : phase « fenêtre » : l’Ag HBs a disparu, l’Ac anti-HBs n’est pas encore apparu.
5. Infection ancienne et guérie à la suite de laquelle l’Ac anti-HBs a fini par disparaître.
6. Infection aiguë ou réactivation chez un porteur chronique de l’Ag HBs.
7. Porteur chronique ou hépatite chronique B (Ag HBs + depuis plus de 6 mois).
8. Phase réplicative d’une hépatite B chronique Ag HBe positif.
9. Phase réplicative d’une hépatite B chronique Ag HBe négatif (virus mutant).
10. Porteur inactif de l’Ag HBs.
