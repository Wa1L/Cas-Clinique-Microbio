# Cas 6.32

Interprétez les résultats de la sérologie HCV et de la recherche de l’ARN viral.

| | Cas 1 | Cas 2 | Cas 3 | Cas 4 |
|---|---|---|---|---|
| Ac anti-HCV | + | + | − | − |
| ARN viral | Positif | Non détecté | Non détecté | Positif |
| Possibilités diagnostiques |  |  |  |  |

#### CORRIGÉ SUGGÉRÉ · CAS 6.32

*Proposition de réponse rédigée par l’auteur (le sujet ne comportait pas de corrigé type dactylographié).*

**Cas 1.** Anticorps et ARN positifs : **hépatite C** en cours (aiguë ou chronique selon l’ancienneté).

**Cas 2.** Anticorps positifs, ARN non détecté : **hépatite C guérie** (cicatrice sérologique, clairance spontanée ou après traitement). Une sérologie faussement positive est possible : confirmer par un second test.

**Cas 3.** Anticorps et ARN négatifs : **pas de contamination** par le VHC.

**Cas 4.** Anticorps négatifs, ARN positif : **hépatite C très précoce** (fenêtre sérologique), ou infection chez un sujet **immunodéprimé** sans production d’anticorps. Contrôler la sérologie à distance.
