# Cas 6.3


### Exercice 1

Veuillez interpréter les profils sérologiques et charges virales de l’hépatite B des 4 patients suivants :


|  | Patient 1 | Patient 2 | Patient 3 | Patient 4 |
|---|---|---|---|---|
| ADN viral | + | + | − | − |
| Ag HBe | + | + | − | − |
| Ag HBs | + | + | − | − |
| Ac anti HBs | − | − | + | + |
| IgG anti HBc | + | + | − | + |
| IgM anti HBc | + | − | − | − |
| Ac anti HBe | − | − | − | +/− |
| Interprétation |  |  |  |  |


#### CORRIGÉ SUGGÉRÉ · CAS 6.3

Proposition de réponse rédigée par l’auteur (le sujet ne comportait pas de corrigé type dactylographié).

- **Patient 1** : AgHBs +, AgHBe +, ADN viral +, IgM anti-HBc +, anti-HBs *−*: **hépatite** **B aiguë** en phase de réplication active (forte contagiosité).

- **Patient 2** : AgHBs +, AgHBe +, ADN viral +, IgG anti-HBc + sans IgM, anti-HBs *−*: **hépatite B chronique** avec réplication virale active (AgHBe +, immunotolérance ou hépatite chronique active); bilan hépatique, charge virale, fibrose, indication de traitement.

- **Patient 3** : AgHBs *−*, anti-HBs seul +, anti-HBc *−*: **sujet vacciné** (immunité vaccinale).

- **Patient 4** : AgHBs *−*, ADN viral *−*, anti-HBs +, IgG anti-HBc + : **hépatite B guérie** (immunité naturelle, cicatrice sérologique).
