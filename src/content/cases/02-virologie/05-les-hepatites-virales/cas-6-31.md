# Cas 6.31

Le suivi de patients porteurs chroniques du VHB donne les profils sérologiques suivants, classer ces malades.

| | Cas 1 | Cas 2 | Cas 3 | Cas 4 | Cas 5 | Cas 6 |
|---|---|---|---|---|---|---|
| Ag HBs | + | + | + | + | + | − |
| Ac anti-HBc totaux | + | + | + | + | + | + |
| Ac anti-HBs | − | − | − | − | − | − |
| Ag HBe | + | + | − | − | − | − |
| Ac anti-HBe | − | − | + | + | + | + |
| ADN viral (en Log UI/mL) | 8,6 | 7,5 | < 3 à plusieurs reprises | 2,8 une seule fois | 5,2 | Non détecté à plusieurs reprises |
| Transaminases ALAT | N | 3 × N | N à plusieurs reprises | N une seule fois | 2,5 × N | N |
| Possibilités diagnostiques |  |  |  |  |  |  |

+ : positif ; − : négatif ; N : normales ; 1 Log UI/mL = 10 UI/mL, 2 Log = 100, …

#### CORRIGÉ SUGGÉRÉ · CAS 6.31

*Proposition de réponse rédigée par l’auteur (le sujet ne comportait pas de corrigé type dactylographié).*

**Cas 1.** **Immunotolérance** : Ag HBe positif, charge virale très élevée (8,6 Log), ALAT normales. Pas de traitement, surveillance.

**Cas 2.** **Hépatite chronique active à Ag HBe positif** (phase immuno-active) : réplication élevée (7,5 Log) avec ALAT à 3 × N. Indication de traitement après évaluation de la fibrose.

**Cas 3.** **Porteur inactif** : Ag HBe négatif, anti-HBe positif, ADN < 3 Log (< 1000 UI/mL) à plusieurs reprises, ALAT normales. Surveillance régulière.

**Cas 4.** **Portage inactif probable, non confirmé** : une seule mesure de l’ADN (2,8 Log) et des ALAT. Il faut un suivi d’au moins un an (ALAT et ADN tous les 3 mois) car les valeurs peuvent fluctuer.

**Cas 5.** **Hépatite chronique active à Ag HBe négatif** (virus mutant pré-C ou promoteur du core) : ADN à 5,2 Log et ALAT à 2,5 × N malgré l’anti-HBe. Indication de traitement après évaluation de la fibrose.

**Cas 6.** **Ag HBs négatif avec anti-HBc positif** et ADN non détecté : infection ancienne **guérie** (perte de l’Ag HBs) ; une **hépatite B occulte** (ADN détectable par PCR sensible) reste à rechercher en cas d’immunodépression.
