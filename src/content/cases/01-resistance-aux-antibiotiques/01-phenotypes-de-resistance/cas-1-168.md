# Cas 1.168

Interpréter les antibiogrammes suivants :

*Pseudomonas aeruginosa*

| Antibiotique | Résultat |
|---|---|
| Ticarcilline | S |
| Ticarcilline + acide clavulanique | S |
| Pipéracilline | S |
| Pipéracilline + tazobactam | S |
| Céfsulodine | S |
| Ceftazidime | S |
| Céfépime | S |
| Imipénème | R |

Réponse :

#### CORRIGÉ SUGGÉRÉ · CAS 1.168

*Proposition de réponse rédigée par l’auteur (le sujet ne comportait pas de corrigé type dactylographié).*

**Interprétation.** **Résistance isolée à l’imipénème** par **imperméabilité** : perte de la porine **OprD**.

- Cette porine est la voie d’entrée de l’imipénème ; son altération épargne les autres β-lactamines (pénicillines, céphalosporines, aztréonam), qui restent sensibles.
- Une carbapénémase ne s’exprimerait pas par une résistance isolée à l’imipénème : les autres β-lactamines seraient touchées.
- Le **méropénème** est moins affecté ; déterminer sa CMI.
- Cette résistance émerge souvent **sous traitement** par imipénème : surveiller les prélèvements de contrôle.
