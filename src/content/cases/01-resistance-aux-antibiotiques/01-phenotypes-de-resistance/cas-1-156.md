# Cas 1.156

SOURCE : *Phénotypes de Résistance aux Antibiotiques — Énoncé « Traiter les phénotypes suivants », Pr Kassah*

***K. pneumoniae*** **: urines. Que pensez-vous de cet antibiogramme ?**

- Amoxicilline : R
- Amoxicilline + acide clavulanique : S
- Ticarcilline : S
- Pipéracilline : S
- Pipéracilline + tazobactam : S
- Céfoxitine : S
- Céfotaxime : S
- Ceftazidime : S
- Ertapénème : S

Vrai ou faux ?

#### CORRIGÉ SUGGÉRÉ · CAS 1.156

*Proposition de réponse rédigée par l’auteur (le sujet ne comportait pas de corrigé type dactylographié).*

**Faux** : l’antibiogramme est **incohérent** pour la ticarcilline.

- *K. pneumoniae* produit naturellement une **pénicillinase chromosomique (SHV-1)** : résistance naturelle à l’amoxicilline **et à la ticarcilline**.
- La ticarcilline doit être **R** ; vérifier l’identification et la lecture.
- Le phénotype sauvage est : amoxicilline R, ticarcilline R, association avec inhibiteur S, pipéracilline S, C3G S.
