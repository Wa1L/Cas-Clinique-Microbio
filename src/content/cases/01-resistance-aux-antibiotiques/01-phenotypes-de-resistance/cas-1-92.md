# Cas 1.92

Exercice 1 : Souche de *Staphylococcus aureus*

![Antibiogramme – *S. aureus*, première gélose](images/cas-1-92-img1.jpeg)

RP : pénicilline ; ROX : oxacilline ; TEC : téicoplanine ; RA : rifampicine ; VA : vancomycine ; FOX : céfoxitine

![Antibiogramme – *S. aureus*, seconde gélose](images/cas-1-92-img2.jpeg)

S : streptomycine ; K : kanamycine ; G : gentamicine ; TM : tobramycine ; FOS : fosfomycine ; C : chloramphénicol ; FA : ac. fusidique ; N : néomycine ; TMP : triméthoprime ; SXT : sulfaméthoxazole ; OFX : ofloxacine ; TE : tétracycline ; PT : pristinamycine ; L : lincomycine ; E : érythromycine ; MNO : minocycline

Question : Lire l’antibiogramme et commentez.

#### CORRIGÉ SUGGÉRÉ · CAS 1.92

*Proposition de réponse rédigée par l’auteur (le sujet ne comportait pas de corrigé type dactylographié).*

**1.** Première gélose (β-lactamines et glycopeptides).

- Lire les diamètres de la **céfoxitine** : un diamètre inférieur au seuil définit un **SARM** (gène *mec*A, PLP2a), avec résistance croisée à toutes les β-lactamines.
- Lire la vancomycine et la téicoplanine : une CMI de la vancomycine est à déterminer pour exclure une sensibilité diminuée (GISA).

**2.** Seconde gélose (aminosides, MLS et autres).

- Aminosides : déterminer le phénotype **K**, **KT** ou **KTG** selon que la kanamycine seule, puis la tobramycine, puis la gentamicine sont touchées.
- MLS : comparer érythromycine et lincomycine ; une **image d’antagonisme** (« zone en D ») traduit un phénotype **MLSB inductible**.
- Conclure sur les résistances associées (tétracycline, chloramphénicol, fosfomycine, acide fusidique).
