# Cas 1.142

SOURCE : *Phénotypes de Résistance aux Antibiotiques — Énoncé « Traiter les phénotypes suivants », Pr Kassah*

**Aminosides /** ***S. aureus*** **: que pensez-vous de cet antibiogramme ?**

- Pénicilline G : R
- Oxacilline : R
- Kanamycine : S
- Tobramycine : R
- Gentamicine : S
- Ofloxacine : R
- Vancomycine : S

#### CORRIGÉ SUGGÉRÉ · CAS 1.142

*Proposition de réponse rédigée par l’auteur (le sujet ne comportait pas de corrigé type dactylographié).*

**Antibiogramme.** Il est **incohérent** pour les aminosides : la kanamycine sensible avec une tobramycine résistante est un phénotype impossible.

- Toutes les enzymes qui inactivent la tobramycine inactivent aussi la kanamycine : la kanamycine doit être corrigée en **R**.
- Le phénotype réel est **KT** (kanamycine + tobramycine résistantes, gentamicine sensible) : enzyme **ANT(4’)** ; l’amikacine peut être touchée.

Les autres résultats donnent un **SARM** (pénicilline G et oxacilline R) également résistant aux fluoroquinolones (ofloxacine R).
