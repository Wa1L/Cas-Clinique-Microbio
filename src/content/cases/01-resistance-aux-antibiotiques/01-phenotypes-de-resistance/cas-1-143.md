# Cas 1.143

SOURCE : *Phénotypes de Résistance aux Antibiotiques — Énoncé « Traiter les phénotypes suivants », Pr Kassah*

**Quinolones /** ***S. aureus*** **: que pensez-vous de cet antibiogramme ?**

- Pénicilline G : R
- Oxacilline : R
- Kanamycine : R
- Tobramycine : R
- Gentamicine : S
- Ofloxacine : R
- Lévofloxacine : S
- Vancomycine : S

#### CORRIGÉ SUGGÉRÉ · CAS 1.143

*Proposition de réponse rédigée par l’auteur (le sujet ne comportait pas de corrigé type dactylographié).*

**Antibiogramme.** Il est **incohérent** pour les fluoroquinolones : une souche résistante à l’ofloxacine est résistante à la lévofloxacine.

- La lévofloxacine doit être corrigée en **R** (résistance croisée, mutations *gyrA* et *grlA*).

Phénotypes associés :

- **SARM** (pénicilline G et oxacilline R).
- Aminosides **KT** (kanamycine + tobramycine R, gentamicine S) : enzyme **ANT(4’)**.
