# Cas 1.84

SOURCE : *Examen 2*^e^ *année Résidanat, 3 et 4 juillet 2013, Batna — Épreuve pratique*

Interprétez les phénotypes de résistance aux antibiotiques suivants :

1. *Staphylococcus aureus* :
    - Pénicilline R ; amoxicilline R ; Augmentin S ; oxacilline S ; céfalotine S
    - Pénicilline R ; amoxicilline R ; Augmentin R ; oxacilline R ; céfalotine R
    - Érythromycine R ; lincomycine S ; clindamycine S ; pristinamycine S
    - Érythromycine R ; lincomycine R ; clindamycine R ; pristinamycine S
    - Vancomycine S ; teicoplanine R
2. *Enterococcus* :
    - Amoxicilline S ; Augmentin S ; oxacilline R ; pipéracilline S ; pipéracilline + tazobactam S ; céfotaxime R ; ceftriaxone R
    - Érythromycine S ; lincomycine R ; pristinamycine R
    - Érythromycine R ; lincomycine R ; pristinamycine S
    - Vancomycine R ; teicoplanine S
    - Vancomycine R ; teicoplanine R
3. *Pseudomonas aeruginosa* :
    - Ticarcilline S ; pipéracilline S ; pipéracilline + tazobactam S ; céfotaxime R ; ceftazidime S ; céfépime S ; aztréonam S ; ertapénème R ; imipénème S
    - Ticarcilline R ; pipéracilline S ; pipéracilline + tazobactam S ; céfotaxime R ; ceftazidime S (absence de synergie TCC/CAZ) ; céfépime S/R ; aztréonam R ; ertapénème R ; imipénème S
    - Ticarcilline R ; pipéracilline R ; pipéracilline + tazobactam S ; céfotaxime R ; ceftazidime S ; céfépime S ; aztréonam S ; ertapénème R ; imipénème S
    - Ticarcilline S ; pipéracilline S ; pipéracilline + tazobactam S ; céfotaxime R ; ceftazidime S ; céfépime S ; aztréonam S ; ertapénème R ; imipénème R
    - Ticarcilline R ; pipéracilline R ; pipéracilline + tazobactam R ; céfotaxime R ; ceftazidime R ; céfépime R ; aztréonam S ; ertapénème R ; imipénème R

#### CORRIGÉ · CAS 1.84

1. *Staphylococcus aureus* :
    - Interprétation : Pénicillinase.
    - Interprétation : SARM, production de PLP2a.
    - Interprétation : MLSB inductible, antagonisme E/L.
    - Interprétation : MLSB constitutif.
    - Interprétation : GISA.
2. *Enterococcus* :
    - Interprétation : Phénotype sauvage pour *Enterococcus faecalis*.
    - Interprétation : Phénotype sauvage LS~A~ pour *Enterococcus faecalis*.
    - Interprétation : MLSB pour *Enterococcus faecium*.
    - Interprétation : Phénotype VAN B.
    - Interprétation : Phénotype VAN A.
3. *Pseudomonas aeruginosa* :
    - Interprétation : Phénotype sauvage.
    - Interprétation : Surexpression de système d’efflux.
    - Interprétation : Pénicillinase.
    - Interprétation : Imperméabilité sélective à l’imipénème, perte de porine OprD2.
    - Interprétation : Carbapénémase, métallo β-lactamase.
