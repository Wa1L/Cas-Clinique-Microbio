# Cas 1.89

2. Profil de sensibilité des entérobactéries aux β-lactamines (phénotypes acquis) :

Interprétez ces phénotypes de résistance acquise aux β-lactamines :

a. *Klebsiella pneumoniae* : AMX, TIC, CF : R ; PIP : R/I ; AMC, PTZ : S/I ; CTX, CAZ : S

b. *E. coli* : AMX, TIC, AMC : R ; CF, PIP, PTZ, CTX, CAZ : S

c. *Klebsiella oxytoca* : AMX, AMC, TIC, PIP, PTZ : R ; CTX, ATM, CRO : R/I ; CAZ : S (synergie AMC/CTX, ATM)

d. *E. coli* : ERT : R/I ; IMP : S

#### CORRIGÉ · CAS 1.89

*Corrigé type issu du document d’examen, reproduit tel quel.*

a. Interprétation : Pénicillinase de haut niveau.

b. Interprétation : Pénicillinase résistante aux inhibiteurs.

c. Interprétation : Pénicillinase hyperproduite « HyperOxy »

d. Interprétation : Imperméabilité à l’ertapénème.
