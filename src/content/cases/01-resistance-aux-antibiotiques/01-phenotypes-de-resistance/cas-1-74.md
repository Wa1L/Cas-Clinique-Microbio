# Cas 1.74

Quelles sont les corrections que vous allez apporter pour cette souche d’*Enterococcus faecalis* testée en routine par un antibiogramme standard :

| Antibiotique | Résultat |
|---|---|
| Ampicilline | S |
| Amoxicilline | R |
| Amoxicilline-Acide clavulanique | S |
| Céfotaxime | S |
| Ertapénème | S |
| Imipénème | S |
| Lincomycine | S |

#### CORRIGÉ · CAS 1.74

*Corrigé type issu du document d’examen, reproduit tel quel.*

- Ampicilline S
- Amoxicilline R → S . On interprète cet antibiotique suivant le résultat de l’ampicilline
- Amoxicilline-Acide clavulanique S → S . Si Ampi S , l’association ne peut étre que « S »
- Céfotaxime S→ R (résistance naturelle)
- Ertapénème S → R (résistance naturelle)
- Imipénème S→ S (C’est l’espèce *E. faecium* qui est R )
- Lincomycine S → R (résistance naturelle)
