<div class="box br"><div class="bt">Généralités — voies et déterminants du risque</div><div class="bb">
<p><span class="h">Voies</span> : transplacentaire (CMV, rubéole, B19, VZV, Zika) ; <b>périnatale</b> (HSV, VIH, VHB, VZV) ; postnatale (lait, salive).</p>
<p><span class="h">Risque</span> : type de virus · <b>terme (SA)</b> de l'infection maternelle · primo-infection vs réinfection / réactivation.</p>
<table class="mt">
  <tr><th>Virus</th><th>Période à risque</th><th>Atteinte typique</th></tr>
  <tr><td>CMV</td><td>Transmission ↑ avec le terme ; gravité max. si infection précoce</td><td>Surdité, microcéphalie, calcifications périventriculaires, choriorétinite</td></tr>
  <tr><td>Rubéole</td><td>Surtout &lt; 12–16 SA</td><td>Triade de Gregg : cataracte, cardiopathie, surdité</td></tr>
  <tr><td>B19</td><td>1<sup>er</sup>–2<sup>e</sup> trimestre</td><td>Anémie, anasarque fœto-placentaire, MFIU</td></tr>
  <tr><td>VZV</td><td>&lt; 20 SA (rare) ; éruption maternelle J−5 → J+2</td><td>Cicatrices cutanées, hypoplasie de membre ; varicelle néonatale grave</td></tr>
  <tr><td>HSV</td><td>Per-partum (primo-infection tardive)</td><td>Cutané/oculaire, neurologique, disséminé</td></tr>
  <tr><td>Zika</td><td>Surtout 1<sup>er</sup> trimestre</td><td>Microcéphalie, syndrome congénital</td></tr>
</table>

<div class="box bl"><div class="bt">Prélèvements — modalités</div><div class="bb">
<table class="mt">
  <tr><th>Prélèvement</th><th>Moment</th><th>Modalités / limites</th></tr>
  <tr><td>Sérum maternel</td><td>Dès suspicion (contage, fièvre, éruption) ; 2<sup>e</sup> sérum à 2–3 sem</td><td>Tube sec ; conserver le 1<sup>er</sup> sérum ; même technique</td></tr>
  <tr><td>Liquide amniotique</td><td>≥ 6–8 sem après l'infection ; ≥ 18 SA (CMV)</td><td>Amniocentèse écho-guidée, tube stérile, +4 °C, acheminement rapide ; éviter le sang maternel ; risque de perte fœtale faible</td></tr>

  <tr><td>Urine / salive du NN</td><td>CMV : urines ≤ 3 sem</td><td>Recueil stérile ; salive : faux + (lait maternel, même &gt; 1 h après tétée) → confirmer par urines</td></tr>

<div class="box dr"><div class="bt">Limites et pièges</div><div class="bb"><ul>
<li><b>IgM</b> : persistance prolongée (CMV), faux positifs (B19, EBV, rubéole), faux négatifs si immunodépression.</li>
<li><b>Avidité</b> : informative seulement dans les premiers mois ; seuils variables selon la trousse.</li>
<li><b>Infection non primaire</b> (CMV) : sérologie peu contributive ; une infection congénitale reste possible malgré l'immunité maternelle.</li>
<li><b>PCR LA</b> : sensibilité élevée si les délais sont respectés, mais VPN non absolue ; <span class="r">ne prédit pas la gravité</span>.</li>
<li><b>Nouveau-né</b> : IgG = anticorps maternels ; PCR CMV après 3 sem non discriminante.</li>
<li>Toujours corréler à la clinique et à l'écho ; avis pluridisciplinaire avant toute décision.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Conséquences pratiques</div><div class="bb"><ul>
<li><b>CMV</b> : primo-infection périconceptionnelle/T1 → <b>valaciclovir 8 g/j</b> (2 g × 4) jusqu'à l'amniocentèse (hydratation ≥ 2 L/j, créatininémie) ; écho/IRM ; NN avec atteinte SNC ou surdité → valganciclovir avant J28, 6 mois (NFS) ; suivi auditif ; hygiène.</li>
<li><b>Rubéole</b> : pas de traitement ; vaccination post-partum si non immune ; <span class="r">vaccin vivant contre-indiqué pendant la grossesse</span>.</li>
<li><b>B19</b> : transfusion in utero si anémie sévère.</li>
<li><b>VZV</b> : VZIG ≤ 10 j post-contage (SPILF 2024) ; sinon valaciclovir 1 g × 3/j, 7 j (J7–J14) ; aciclovir si varicelle.</li>
<li><b>HSV</b> : aciclovir IV chez le NN ; mère : valaciclovir 500 mg × 2/j ou aciclovir 400 mg × 3/j dès 36 SA ; césarienne si lésions/prodromes.</li>
<li><b>VIH</b> : ARV maternels + PCR du NN ; allaitement possible sous conditions strictes. <b>VHB</b> : vaccin à la naissance (PEV) ; Ig anti-HBs &lt; 12–24 h <u>seulement</u> si mère AgHBs+ ; ténofovir maternel dès 28 SA si ADN ≥ 200 000 UI/mL.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">Dater l'infection maternelle</span> (séroconversion, avidité) avant tout prélèvement fœtal ; IgM seules = piège.</li>
<li>Amniocentèse : <span class="r">≥ 6–8 sem après l'infection ET ≥ 18 SA</span> (CMV) ; PCR + = transmission, pas gravité.</li>
<li>NN et CMV : PCR urines <span class="r">≤ 3 sem</span> (salive+ → confirmer par urines) ; sérologie du NN inutile (IgG maternelles).</li>
<li>B19 → Doppler ACM ; rubéole → risque surtout &lt; 12–16 SA, PCR LA 20–22 SA ; dépistage CMV T1 systématique en France, ciblé en Algérie.</li>
</ul></div></div>
