<div class="box br"><div class="bt">Généralités / Épidémiologie</div><div class="bb">
<p><span class="h">Définition</span> : atteinte du parenchyme cérébral par un virus <b>persistant</b>, évoluant sur <b>mois–années</b> (≠ encéphalite aiguë : HSV, arbovirus). Ex-« infections à virus lents ».</p>
<p><span class="h">Mécanisme commun</span> : persistance virale + <b>défaut de clairance immunitaire</b> → variant défectif (PESS) ou immunodépression (LEMP, HAND).</p>
<p><span class="h">PESS</span> : ≈ 1/10 000 rougeoles (estimation classique) ; <b>1/609 si rougeole &lt; 12 mois</b>, 1/1 367 si &lt; 5 ans (Californie) ; plus fréquente chez le garçon ; latence médiane ≈ 10 ans.</p>
<p><span class="h">LEMP</span> : surtout VIH/SIDA, hémopathies, greffés ; <b>iatrogène</b> (natalizumab, rituximab).</p>
</div></div>

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><span class="h">PESS</span> : début insidieux (baisse scolaire, comportement) → <b>myoclonies périodiques</b>, crises, démence → mutisme akinétique (voir stades).</li>
<li><span class="h">LEMP</span> : <b>déficits focaux</b> progressifs (hémiparésie, aphasie, hémianopsie, dysarthrie) + troubles cognitifs ; mort en 1–9 mois si non traitée.</li>
<li><span class="h">HAND</span> : trouble cognitif sous-cortical (ralentissement, attention, mémoire), gêne motrice, apathie ; <b>Frascati 2007 : ANI → MND → HAD</b>.</li>
<li><span class="h">Autre</span> : méningo-encéphalite chronique à entérovirus (échovirus) chez l'agammaglobulinémique (XLA).</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie — points d'examen</div><div class="bb"><ul>
<li><b>PESS</b> : virus rougeoleux défectif (M altérée), pas de particules libres ; propagation de cellule à cellule qui échappe aux Ac ; Ac sériques et LCR très élevés.</li>
<li><b>LEMP</b> : réactivation du JCV (réservoir rénal) → lyse des <b>oligodendrocytes</b> (cellules myélinisantes) ; <span class="r">SIRI</span> à la restauration immunitaire (aggravation inflammatoire).</li>
<li><b>HAND</b> : <b>neurones non infectés</b> ; toxicité indirecte (gp120, Tat, cytokines) ; les formes légères persistent sous TARV.</li>
</ul></div></div>

</div></div>

<div class="box dr"><div class="bt">Limites et pièges diagnostiques</div><div class="bb"><ul>
<li><span class="r">LEMP</span> : PCR JCV du LCR parfois négative (charge faible, notamment sous natalizumab) → <b>répéter</b> ± biopsie ; <span class="r">PCR sérique/urinaire inutile</span>.</li>
<li><b>Index Ac anti-JCV</b> (test STRATIFY) : &lt; 0,2 négatif ; 0,2–0,4 indéterminé (test de confirmation) ; &gt; 0,4 positif. <b>Risque de LEMP</b> sous natalizumab (sans immunosuppresseur antérieur) : ≤ 0,9 faible ; 0,9–1,5 intermédiaire ; &gt; 1,5 élevé. <span class="r">Stratification du risque, pas un diagnostic de LEMP</span> ; autres facteurs : durée du traitement, immunosuppresseurs antérieurs.</li>
<li><b>PESS</b> : EEG typique souvent absent au début (apparaît avec l'évolution) ; IgM antirougeole négatives, IgG élevés.</li>
<li><b>HAND</b> : formes légères fréquentes sous TARV ; HAD rare (≈ 2–4 %).</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement / Prévention</div><div class="bb"><ul>
<li><b>PESS</b> : <span class="r">pas de traitement curatif</span> ; isoprinosine PO ± interféron-α intrathécal/intraventriculaire (ralentit) ; antiépileptiques (carbamazépine, valproate) pour les myoclonies. <b>Prévention : vaccination antirougeoleuse</b> (2 doses, couverture élevée, protéger les nourrissons &lt; 12 mois).</li>
<li><b>LEMP</b> : pas d'antiviral validé → <b>restaurer l'immunité</b> : TARV (VIH), arrêt du natalizumab/immunosuppresseur (± échanges plasmatiques, qui accélèrent l'élimination de l'Ac mais exposent à un <span class="r">SIRI sévère</span> : surveillance, corticoïdes si besoin) ; pembrolizumab : données limitées.</li>
<li><b>HAND</b> : TARV précoce et optimisé, traiter les comorbidités.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">PESS</span> : risque surtout si rougeole &lt; 1–2 ans ; latence 6–15 ans ; souche vaccinale non démontrée → <b>la vaccination la prévient</b>.</li>
<li><span class="r">LEMP = JCV + déficit de l'immunité cellulaire</span> : IRM asymétrique sous-corticale ; <b>PCR dans le LCR</b>.</li>
<li><b>HAND</b> : macrophages/microglie infectés, <b>pas les neurones</b>.</li>
<li>Prions (Creutzfeldt-Jakob) : évolution lente mais <span class="r">non virale</span> (ATNC).</li>
</ul></div></div>
