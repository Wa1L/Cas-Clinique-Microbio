<div class="box bl"><div class="bt">Caractères virologiques</div><div class="bb">
<p><span class="h">Virion</span> : <b>nu</b> (sans enveloppe), capside <b>icosaédrique</b>, 27–30 nm ; 60 protomères <b>VP1–VP4</b> (VP4 interne ; VP1 = antigénicité, fixation) ; <span class="r">résiste à l'éther, alcool, détergents, pH acide (sauf rhinovirus)</span>.</p>
<p><span class="h">Génome</span> : ARN <b>+</b> simple brin ≈ 7,5 kb, <b>VPg</b> en 5', poly(A) en 3', <b>IRES</b> en 5' ; infectieux seul ; 1 ORF → <b>polyprotéine</b> clivée par protéases <b>2A, 3C</b> ; ARN polymérase <b>3D</b> (RdRp, sans relecture ⇒ forte variabilité).</p>
<p><span class="h">Réplication</span> : <b>cytoplasmique</b> ; récepteur → décapsidation → traduction (IRES) → réplication via brin – → assemblage ; lyse cellulaire.</p>
<p><span class="h">Culture / ECP</span> : HeLa, Vero, MRC-5, cellules rénales de singe ; <b>ECP rapide</b> (arrondissement, 2–5 j) ; rhinovirus A/B : WI-38 / MRC-5 à <b>33 °C</b>, <span class="r">RV-C : non cultivable sur lignées standard (épithélium air-liquide)</span> ; Coxsackie A : souriceau ; VHA : lente, sans ECP.</p>
<p><span class="h">Antigénie</span> : neutralisation type-spécifique (VP1) ; pas d'immunité croisée entre types ; <b>PV1–3 + 1 sérotype VHA</b>.</p>
<p><span class="h">Stabilité</span> : survie longue dans l'eau / selles ; <b>stabilisés par MgCl₂</b> à 50 °C ; inactivés par <b>chlore, formol, UV</b>, ≥ 56 °C ; <span class="r">VHA très thermorésistant (60 °C 1 h ; inactivé &gt; 85 °C 1 min)</span>.</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li>Réservoir <b>strictement humain</b> (EV, VHA, rhinovirus) ; <b>excrétion fécale</b> prolongée (semaines–mois), porteurs asymptomatiques ⇒ source.</li>
<li>Transmission <b>féco-orale</b> (eau, mains sales, aliments : VHA, EV) ; <b>respiratoire</b> / mains-surfaces (rhinovirus, EV) ; verticale / néonatale (EV).</li>
<li>Saison : EV été–automne ; rhinovirus automne–printemps ; <b>enfants &lt; 5 ans</b>, bas niveau d'hygiène.</li>
<li><b>Polio sauvage</b> : endémique Afghanistan, Pakistan (WPV1) ; WPV2 (2015) et WPV3 (2019) éradiqués ; <span class="r">cVDPV2</span> (dérivé vaccinal circulant) persistant.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>Entérovirus</b> : bouche → oropharynx / intestin (plaques de Peyer) → <b>virémie mineure</b> → organes cibles → <b>virémie majeure</b> ; excrétion fécale.</li>
<li><b>Poliovirus</b> : neurones moteurs de la <b>corne antérieure</b> (moelle lombaire, bulbe) par voie sanguine / axonale rétrograde ; <span class="r">aggravants : injection IM, amygdalectomie, effort, grossesse, déficit immunitaire</span>.</li>
<li><b>Rhinovirus</b> : ICAM-1, réplication à 33–35 °C ; symptômes = inflammation (IL-8, bradykinine), pas lyse.</li>
<li><b>VHA</b> : hépatocyte → bile → selles ; lésions <b>immuno-médiées</b> (LT CD8), non cytopathogène.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Poliomyélite</b> : 90–95 % asymptomatique ; forme mineure 4–8 % ; <b>paralysie flasque</b> &lt; 1 % : asymétrique, proximale, aréflexie, <b>sans trouble sensitif</b> ; incub. 7–14 j ; <span class="r">séquelles définitives ; syndrome post-polio ; forme bulbaire = vital</span>.</li>
<li><b>Méningite aseptique</b> (Écho, CB) : LCR lymphocytaire, glycorachie normale, bon pronostic.</li>
<li><b>Myopéricardite</b> (CB) ; <b>pleurodynie</b> ; <b>main-pied-bouche</b> ; herpangine ; conjonctivite hémorragique.</li>
<li><span class="r">Nouveau-né : sepsis, myocardite, hépatite, méningo-encéphalite</span> ; immunodéprimé (agamma) : méningo-encéphalite chronique.</li>
<li><b>Rhinovirus</b> : rhume, sinusite, OMA ; <span class="r">asthme / BPCO décompensés</span>.</li>
<li><b>Hépatite A</b> : incub. 15–50 j (≈ 28) ; ictère ; <b>jamais chronique</b> ; fulminante &lt; 1 % ; contagiosité max avant l'ictère.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : <b>selles</b> (2 échantillons à ≥ 24 h d'intervalle, ≤ 14 j après début paralysie), LCR, gorge, écouvillon nasal ; <span class="r">chaîne du froid (+ 4 °C), jamais de congélation lente</span>.</li>
<li><b>Direct</b> : <b>RT-PCR pan-entérovirus</b> (5' UTR) sur LCR = référence ; PCR spécifique rhinovirus / parechovirus <span class="r">(sondes EV ne détectent pas HPeV)</span>.</li>
<li><b>Culture</b> : ECP sur HeLa / Vero ; identification par <b>neutralisation</b> ou séquençage <b>VP1</b>.</li>
<li><b>Sérologie</b> : peu utile (EV) ; <b>VHA : IgM anti-VHA</b> = infection aiguë, IgG = immunité.</li>
<li><b>Polio</b> : ITD (typage intratypique) : sauvage / Sabin / <span class="r">VDPV (divergence VP1 &gt; 1 % types 1, 3 ; &gt; 0,6 % type 2)</span> ; laboratoire de référence = IPA.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Antiviraux</div><div class="bb"><ul>
<li><b>Aucun antiviral</b> validé en routine ; <span class="r">antibiotiques inutiles</span>.</li>
<li><b>Pléconaril</b> (inhibe la décapsidation, poche VP1), pocapavir : sans AMM (expérimentaux).</li>
<li>Immunoglobulines IV : immunodéprimé (agamma) / néonat sévère.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Traitement symptomatique</b> ; polio : repos, kiné, orthopédie, <b>ventilation assistée</b> si bulbaire ; <span class="r">éviter injections IM</span>.</li>
<li><b>Vaccin polio</b> : <b>VPO</b> (Sabin, vivant, oral, immunité muqueuse) – risque PPAV ≈ 1 / 2,7 M doses ; <b>VPI</b> (Salk, inactivé, IM) ; <b>PEV algérien</b> : VPI (hexavalent) à 2, 4, 12 mois + rappel DTCa-VPI à 6 ans ; VPO à 2, 4, 12 mois (arrêté 28/04/2026).</li>
<li><b>VHA</b> : vaccin inactivé 2 doses (0, 6–12 mois) ; Ig polyvalentes en post-exposition ≤ 2 sem. ; <span class="r">non inclus au PEV algérien</span>.</li>
<li><b>Hygiène</b> : lavage mains, chloration de l'eau ; rhinovirus : pas de vaccin.</li>
<li><b>Entourage</b> : cas de PFA ⇒ investigation, <b>vaccination de rattrapage</b> ; <b>MDO</b> : PFA et hépatite A = catégorie 1 ; poliomyélite = catégorie 2 (RSI).</li>
</ul></div></div>
