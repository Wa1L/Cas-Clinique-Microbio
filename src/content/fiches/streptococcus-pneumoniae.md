<div class="col">

<div class="box bl"><div class="bt">Caractères bactériologiques</div><div class="bb">
<p><span class="h">Morphologie</span> : <b>diplocoques Gram +</b> lancéolés (« flamme de bougie »), 0,5–1 µm, entourés d'une capsule in vivo ; chaînettes courtes en culture ; immobiles, asporulés ; <span class="r">Gram – dans les vieilles cultures (autolyse)</span>.</p>
<p><span class="h">Exigences</span> : bactérie <b>exigeante</b> ; gélose au sang (cuit ou frais) / chocolat ; <b>CO₂ 5–10 %</b> ; 35–37 °C ; fragile (autolyse rapide).</p>
<p><span class="h">Culture</span> : colonies 0,5–1 mm, <b>α-hémolytiques</b> (verdissement), <b>ombiliquées « en bouton de chemise / soucoupe »</b> (autolyse centrale) ; souches très capsulées (type 3) : <b>mucoïdes bombées</b>. Lecture 24 h.</p>
<p><span class="h">Biochimie</span> : catalase –, oxydase – ; <b>sensible à l'optochine</b> (disque 5 µg ≥ 14 mm) ; <b>soluble dans la bile</b> (désoxycholate de Na) ; inuline +, esculine –, PYR –. Gène <i>lytA</i> / <i>ply</i> (PCR).</p>
<p><span class="h">Antigénie</span> : <b>capsule polyosidique</b> (≈ 100 sérotypes ; typage par réaction de <b>Quellung</b> = gonflement capsulaire) ; <b>polyoside C</b> (phosphocholine, fixe la CRP) ; <span class="r">pas de protéine M</span>.</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li>Réservoir <b>strictement humain</b> : portage rhinopharyngé (enfant 20–60 %, adulte 5–10 %) ; transmission par <b>gouttelettes</b> ; ↑ en hiver, post-grippe.</li>
<li>Terrain : <b>&lt; 2 ans, &gt; 65 ans</b>, <b>asplénie / drépanocytose</b>, VIH, déficit en complément, alcoolisme, BPCO, diabète, <b>brèche ostéoméningée</b>.</li>
<li>Post-vaccination : <b>remplacement sérotypique</b> (sérotypes non vaccinaux).</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>Capsule</b> : facteur majeur, <b>anti-phagocytose</b> (type-spécifique).</li>
<li><b>Pneumolysine</b> (cytolysine dépendante du cholestérol, lyse cellulaire) ; <b>autolysine LytA</b> (libère toxines et fragments de paroi) ; <b>protéase IgA1</b> ; neuraminidase ; PspA / PspC (anti-complément) ; H₂O₂.</li>
<li>Paroi (peptidoglycane, acides téichoïques) → <b>inflammation intense</b> (PAF-R via phosphocholine).</li>
<li>Voies : aspiration → <b>pneumonie</b> ; contiguïté → <b>otite, sinusite</b> ; bactériémie → <b>méningite</b>, arthrite ; brèche méningée → <b>méningite récidivante</b>.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Pneumonie franche lobaire aiguë</b> : début brutal, frisson solennel, fièvre 40 °C, <b>point de côté</b>, crachats « rouillés », herpès labial ; <span class="r">pleurésie purulente, bactériémie</span>.</li>
<li><b>Méningite purulente</b> (1<sup>re</sup> cause chez l'adulte ; enfant) : <span class="r">létalité élevée, séquelles (surdité), récidive si brèche</span>.</li>
<li><b>OMA, sinusite</b>, conjonctivite ; <b>EA-BPCO</b> ; endocardite, arthrite, péritonite (rares).</li>
<li><span class="r">Asplénique : sepsis fulminant (OPSI)</span>.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : hémocultures, <b>LCR</b> (<span class="r">jamais réfrigéré</span>, ensemencement rapide), crachat de qualité (&gt; 25 PNN et &lt; 10 cellules épithéliales / champ), liquide pleural, ponction tympanique.</li>
<li><b>Direct</b> : Gram (diplocoques Gram + lancéolés + PNN) ; <b>antigénurie</b> pneumocoque (rapide ; <span class="r">faux + chez l'enfant porteur</span>) ; latex LCR.</li>
<li><b>Culture</b> : gélose sang / chocolat, CO₂ 5–10 %. <b>Identification</b> : optochine, bile-solubilité, MALDI-TOF (<span class="r">confusion <i>mitis</i></span>), PCR <i>lytA</i>. <b>Typage</b> : Quellung, sérotypage.</li>
<li><b>ATBg (CLSI M100)</b> : McFarland 0,5, 35 ± 2 °C. <b>Disques</b> : gélose MH + 5 % sang de mouton, CO₂ 5 %, 20–24 h. <b>CMI</b> : CAMHB + 2,5–5 % LHB, en air, 20–24 h. Contrôle <b>ATCC 49619</b>. <b>Dépistage : disque oxacilline 1 µg ≥ 20 mm</b> ⇒ sensible à la pénicilline (prédit amoxicilline, céfotaxime, ceftriaxone) ; <b>≤ 19 mm ⇒ CMI obligatoire</b>, <span class="r">jamais R sur le seul disque d'oxacilline</span>.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Résistance aux antibiotiques</div><div class="bb"><ul>
<li><b>Naturelle</b> : aminosides (bas niveau), polymyxines, acide nalidixique.</li>
<li><b>β-lactamines</b> : <span class="r">pas de β-lactamase</span> ; résistance par <b>PLP modifiées (mosaïques)</b> ⇒ PSDP ; inhibiteurs sans intérêt ; <b>CMI à interpréter selon le site</b> (méningite ≠ autres).</li>
</ul>

</ul></div></div>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Pneumonie</b> : amoxicilline 3 g/j PO (ou IV si grave) ; alternative : C3G ; durée 7 j (à vérifier). <b>OMA</b> : amoxicilline 80–90 mg/kg/j.</li>
<li><b>Méningite</b> : <b>céfotaxime</b> 300 mg/kg/j ou <b>ceftriaxone</b> 100 mg/kg/j + <b>dexaméthasone</b> avant / avec la 1<sup>re</sup> dose ; ± vancomycine si PSDP ; 10–14 j.</li>
<li><b>Vaccin</b> : conjugué <b>VPC13</b> (PEV algérien : 2, 4 et 12 mois) ; <b>VPP23</b> chez sujets à risque / ≥ 65 ans (≥ 8 sem après VPC) ; <b>asplénie</b> : vaccins + pénicilline V prophylactique.</li>
<li><b>Entourage</b> : pas de prophylaxie systématique ; <b>déclaration</b> : méningite = MDO.</li>
</ul></div></div>
