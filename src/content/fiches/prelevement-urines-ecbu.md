<div class="box bl"><div class="bt">Seuils de significativité (SPILF 2015 / REMIC) — patient symptomatique</div><div class="bb">
<p><span class="h">Leucocyturie</span> significative : <b>≥ 10⁴/mL</b> (= 10/mm³). <span class="h">Hématurie</span> : hématies ≥ 10⁴/mL.</p>
<table class="mt">
  <tr><th>Bactérie (bactériurie, UFC/mL)</th><th class="c">Homme</th><th class="c">Femme</th></tr>
  <tr><td><i>E. coli</i>, <i>S. saprophyticus</i></td><td class="c">≥ 10³</td><td class="c">≥ 10³</td></tr>
  <tr><td>Autres entérobactéries, entérocoques, <i>C. urealyticum</i>, <i>P. aeruginosa</i>, <i>S. aureus</i></td><td class="c">≥ 10³</td><td class="c">≥ 10⁴</td></tr>
</table>
<p><span class="h">Bactériurie asymptomatique</span> : pas de seuil ni de leucocyturie requise ; <b>grossesse : ≥ 10⁵ UFC/mL</b> (un seul ECBU suffit).</p>
<p><span class="h">Autres recueils</span> : <b>sondé ≥ 10⁵ UFC/mL</b> (SPILF/AFU/SF2H 2015, REMIC ; <i>IDSA : ≥ 10³</i>) ; sondage aller-retour ≥ 10³ ; <b>PSP ≥ 10¹ UFC/mL</b> quel que soit le germe.</p>
<p><span class="h">Nombre d'espèces</span> : 1 espèce = interprétable ; 2 espèces = discuter (sondé, uropathie) ; <span class="r">≥ 3 espèces = contamination → refaire</span>.</p>
</div></div>

<div class="box db"><div class="bt">Examen au laboratoire</div><div class="bb"><ul>
<li><b>BU</b> : leucocyte-estérase + nitrites. Chez la <b>femme</b>, BU négative → <b>VPN &gt; 95 %</b> (élimine l'IU). Chez l'<b>homme</b> : <span class="r">plus de BU</span> (IUMACA SPILF/AFU/SFM 2025–2026) → <b>ECBU d'emblée</b>, quel que soit le tableau.</li>
<li><b>Nitrites faux –</b> : bactéries sans nitrate-réductase (<i>Enterococcus</i>, <i>S. saprophyticus</i>, <i>Pseudomonas</i>, <i>Acinetobacter</i>), stase vésicale &lt; 4 h, diurétiques, régime pauvre en nitrates.</li>
<li><b>Cytologie</b> (cellule de Malassez / automate) : cellules épithéliales nombreuses = <b>contamination vulvaire</b> ; cylindres leucocytaires → atteinte rénale.</li>
<li><b>Culture</b> : <b>1 µL → 1 colonie = 10³</b> ; <b>10 µL → 10²</b> ; <b>100 µL (PSP) → 10¹ UFC/mL</b> (REMIC 2022).</li>
</ul></div></div>

<div class="box or"><div class="bt">Terrains particuliers</div><div class="bb"><ul>
<li><b>Grossesse</b> : bactériurie asymptomatique → <b>traiter</b>. Bas risque : BU mensuelle dès le 4<sup>e</sup> mois, ECBU si BU+. <b>Haut risque</b> (uropathie, diabète, IU récidivantes) : <b>ECBU dès la 1<sup>re</sup> consultation</b>, puis mensuel dès le 4<sup>e</sup> mois.</li>
<li><b>Nourrisson</b> : nitrites souvent <b>faussement négatifs</b> (mictions fréquentes, stase courte).</li>
<li><b>Sujet âgé, sondé</b> : bactériurie asymptomatique fréquente → <span class="r">pas d'ECBU sans symptômes</span>.</li>
<li><b>Neutropénique</b> : leucocyturie possiblement absente malgré l'IU.</li>
<li><b>Candidurie</b> : le plus souvent colonisation (sonde, ATB) ; changer la sonde, recontrôler ; chercher une candidémie si sepsis.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Indications et place de l'ECBU</div><div class="bb"><ul>
<li><b>Cystite simple</b> : BU seule, <span class="r">pas d'ECBU</span>.</li>
<li><b>ECBU</b> : cystite à risque de complication ou récidivante, <b>PNA</b>, <b>IU masculine</b>, grossesse, IU associée aux soins.</li>
<li><b>Avant geste urologique</b> (RBP AFU/SPILF 2026) : ECBU <b>seulement si geste à risque</b> (RTUP/HoLEP, RTUV, chirurgie du haut appareil et des calculs, changement de JJ / néphrostomie). <span class="r">Plus d'ECBU systématique</span> avant cystoscopie, biopsies prostatiques, instillations endovésicales, changement/ablation de sonde vésicale.</li>
<li><b>Bactériurie asymptomatique</b> : <span class="r">ne pas traiter</span>, sauf <b>grossesse</b> et <b>avant geste urologique à risque</b>.</li>
<li><b>ECBU de contrôle</b> : non systématique ; recommandé chez la <b>femme enceinte</b> (8–10 j après la fin du traitement).</li>
</ul></div></div>

<div class="box br"><div class="bt">Contenu du compte rendu de l'ECBU</div><div class="bb"><ul>
<li><b>Pré-analytique</b> : mode de recueil, heure de prélèvement / réception, ATB en cours.</li>
<li><b>Cytologie</b> : leucocytes et hématies (/mL), cellules épithéliales, cylindres, cristaux ; résultat du Gram.</li>
<li><b>Culture</b> : numération (UFC/mL) de chaque espèce, identification, ATBg (CA-SFM / EUCAST).</li>
<li><b>Commentaire</b> : « contamination probable, à refaire » ; seuil retenu selon germe / sexe / terrain.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">Jamais d'urines prélevées dans le sac collecteur</span> ; chez le sondé, la leucocyturie n'a pas de valeur.</li>
<li>Seuil = f(<b>germe</b>, <b>sexe</b>, <b>mode de recueil</b>) ; <span class="r">homme : pas de BU</span>, ECBU d'emblée.</li>
<li>Poche pédiatrique : un résultat <b>négatif</b> est fiable, un positif doit être <b>confirmé</b>.</li>
<li>Leucocyturie sans germe → penser <b>BK</b>, <b>Chlamydia</b>, ATB préalable.</li>
