<div class="box br"><div class="bt">Généralités / Épidémiologie</div><div class="bb"><ul>
<li>IRA = 1<sup>re</sup> cause de consultation et de morbidité pédiatrique ; <b>majorité d'origine virale</b>.</li>
<li><span class="h">Saisonnalité</span> : grippe et VRS en <b>hiver</b> (épidémies annuelles) ; rhinovirus toute l'année ; PIV-1/2 plutôt à l'automne.</li>
<li><span class="h">Transmission</span> : gouttelettes, aérosols, <b>mains/surfaces</b> (rhinovirus, VRS) → hygiène des mains.</li>
<li><span class="h">Terrain à risque</span> : nourrisson, âge &gt; 65 ans, immunodépression, comorbidités (BPCO, cardiopathie), grossesse.</li>
</ul></div></div>

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><span class="h">Grippe</span> : début <b>brutal</b>, fièvre élevée, myalgies, céphalées, toux sèche ; ≠ rhume (fièvre modérée, rhinorrhée).</li>
<li><span class="h">Bronchiolite</span> : 1<sup>er</sup> épisode &lt; 2 ans ; rhinite → toux, tachypnée, sibilants, signes de lutte.</li>
<li><span class="h">Croup</span> : toux aboyante, stridor inspiratoire, dysphonie.</li>
<li><span class="h">Complications</span> : surinfection bactérienne (<i>S. pneumoniae</i>, <i>S. aureus</i> post-grippe, <i>H. influenzae</i>), SDRA, décompensation de comorbidités.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Limites / interprétation</div><div class="bb"><ul>
<li><span class="r">PCR positive ≠ causalité</span> : portage prolongé ou asymptomatique (rhinovirus, SARS-CoV-2 : ARN résiduel non infectieux).</li>
<li><b>Co-détections</b> fréquentes (surtout enfants) ; interpréter selon clinique et charge virale.</li>
<li>Prélèvement tardif ou mal fait → faux négatif.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box db"><div class="bt">Diagnostic virologique</div><div class="bb"><ul>
<li>Diagnostic surtout <b>clinique</b> ; virologie si forme grave, hospitalisation, immunodéprimé, surveillance épidémiologique.</li>
<li><span class="h">Prélèvement</span> : écouvillon ou aspiration <b>nasopharyngé</b> (LBA si grave), <b>précoce</b> (début des symptômes), milieu de transport viral, 4 °C.</li>
<li><span class="h">RT-PCR multiplex</span> (grippe A/B, VRS, SARS-CoV-2 ± autres) = <b>référence</b> (sensible, rapide).</li>
<li><span class="h">TDR antigéniques</span> (grippe, VRS, SARS-CoV-2) : rapides, sensibilité moindre → <span class="r">négatif n'exclut pas</span>.</li>
<li>Sérologie : <span class="r">inutile au diagnostic aigu</span> (rétrospectif/épidémiologie).</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement / Prévention</div><div class="bb"><ul>
<li><span class="h">Symptomatique</span> : désobstruction nasale (sérum physiologique), hydratation, antipyrétique, O<sub>2</sub> si besoin.</li>
<li><span class="r">Pas d'antibiotiques</span> sauf surinfection bactérienne documentée ou fortement suspectée.</li>
<li><span class="h">Grippe</span> : <b>oseltamivir</b> (inhibiteur de NA) ou baloxavir (inhibiteur de l'endonucléase PA) ; formes graves / à risque, <b>le plus tôt possible</b>.</li>
<li><span class="h">VRS</span> : anticorps monoclonaux (palivizumab ; nirsevimab) chez le nourrisson ; vaccins chez le sujet âgé.</li>
<li><span class="h">SARS-CoV-2</span> : antiviraux (remdésivir, nirmatrelvir/ritonavir) ; vaccination.</li>
<li><span class="h">Prévention</span> : vaccin grippal annuel (groupes à risque), hygiène des mains, masque, aération ; précautions gouttelettes/contact.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie / Récepteurs</div><div class="bb"><ul>
<li><span class="h">Tropisme</span> : épithélium respiratoire (cellules ciliées) → lyse, inflammation, œdème, hypersécrétion ; lésions muqueuses = porte d'entrée des surinfections bactériennes.</li>
<li><span class="h">Fixation</span> : influenza → <b>HA</b> / acide sialique ; SARS-CoV-2 → <b>ACE2</b> (spicule S) ; rhinovirus majeurs → <b>ICAM-1</b> ; VRS → <b>G</b> (attachement) puis <b>F</b> (fusion, syncytia).</li>
<li>Bronchiolite : œdème + nécrose épithéliale + bouchons muqueux → obstruction des petites voies.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><b>Bronchiolite → VRS</b> ; <b>croup → PIV-1</b> ; pneumonie virale grave → influenza, SARS-CoV-2, VRS (âgé), adénovirus.</li>
<li><span class="r">Un syndrome ≠ un virus</span> : un même tableau relève de plusieurs agents.</li>
<li><span class="r">IRA virale = pas d'antibiotiques</span>, sauf surinfection bactérienne.</li>
<li><span class="r">Détection d'un virus ≠ responsabilité</span> (rhinovirus, SARS-CoV-2) ; TDR négatif n'exclut pas.</li>
</ul></div></div>
