<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>SSSS</b> : clinique + Nikolsky ; <span class="r">culture des bulles stériles</span> (foyer = nez, ombilic, conjonctive) ; PCR <i>eta/etb</i> ; histologie : clivage granuleux.</li>
<li><b>TSS staph.</b> : critères CDC ; <span class="r">hémocultures le plus souvent négatives (&lt; 5 %)</span> ≠ <b>TSS strepto.</b> (~60 % positives, infection invasive) ; culture + PCR <i>tst</i> sur le foyer.</li>
<li><b>Scarlatine</b> : TDR / culture du <i>S. pyogenes</i> (gorge) ; ASLO rétrospectif.</li>
<li><b>PVL</b> : PCR <i>lukS/lukF-PV</i> sur la souche.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement / Prévention</div><div class="bb"><ul>
<li>Foyer : <b>ablation</b> (tampon, corps étranger), drainage, détersion.</li>
<li>ATB actif sur la paroi (staph. : oxacilline/cloxacilline ; SARM : vancomycine ; SGA : pénicilline/amoxicilline) <b>+ clindamycine</b> anti-toxinique <span class="r">si sensible (D-test –)</span> ; <b>linézolide</b> seul si SARM / clinda-R ; ± IgIV (TSS sévère).</li>
<li>SSSS : réhydratation, soins cutanés, <span class="r">corticoïdes proscrits</span>.</li>
<li>Scarlatine : β-lactamine (pénicilline/amoxicilline) ; éviction scolaire.</li>
<li>PVL : décolonisation, hygiène familiale.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">SSSS : ETA/ETB clivent Dsg1 (couche granuleuse)</span> ; bulles stériles, muqueuses épargnées ≠ NET.</li>
<li><b>Superantigène</b> : pont CMH II–TCR Vβ <b>hors poche peptidique</b> → 20–30 % des LT → choc.</li>
<li>TSS : desquamation <b>tardive</b> ; hémocultures négatives (staph.) ≠ ~60 % positives (strepto.) ; <b>clindamycine</b> anti-toxinique si sensible (D-test).</li>
<li>Scarlatine = toxine SPE codée par <b>phage</b> ; PVL = abcès/nécrose, <span class="r">pas de TSS (≠ superantigène)</span>.</li>
</ul></div></div>
