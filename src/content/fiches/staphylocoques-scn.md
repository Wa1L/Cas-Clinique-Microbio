<div class="box bl"><div class="bt">Caractères bactériologiques</div><div class="bb">
<p><span class="h">Morphologie</span> : cocci <b>Gram +</b> (0,8–1,2 µm), en <b>amas / grappes</b>, immobiles, non sporulés, capsule absente (ou discrète).</p>
<p><span class="h">Exigences</span> : aéro-anaérobies facultatifs ; <b>halotolérants</b> (NaCl 7,5 % ⇒ gélose de Chapman) ; peu exigeants.</p>
<p><span class="h">Culture</span> : gélose ordinaire / au sang, 35–37 °C, 18–24 h ; colonies 1–3 mm <b>blanches, non pigmentées</b> (≠ <i>S. aureus</i> doré), le plus souvent non hémolytiques (sauf <i>S. haemolyticus</i> β).</p>
<p><span class="h">Biochimie</span> : <b>catalase +</b>, oxydase – ; <b>coagulase libre –</b> (plasma de lapin, 24 h), DNase – ; latex (clumping factor) – ; mannitol variable. <span class="r">Exceptions : <i>S. lugdunensis</i> (clumping +), <i>S. schleiferi</i> subsp. <i>schleiferi</i> (clumping +)</span>. Novobiocine 5 µg : <i>S. saprophyticus</i> R (≤ 16 mm).</p>
<p><span class="h">Antigénie</span> : peptidoglycane, acides teichoïques ; <b>slime / PIA</b> (opéron <i>icaADBC</i>) ; pas de protéine A.</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li><b>Commensaux de la peau et des muqueuses</b> (flore cutanée résidente) : <i>S. epidermidis</i> (peau), <i>S. hominis</i> / <i>S. haemolyticus</i> (aisselles, périnée), <i>S. capitis</i> (cuir chevelu), <i>S. saprophyticus</i> (périnée, voies génito-urinaires).</li>
<li>Transmission <b>endogène</b> ou manuportée (soignants), contamination du matériel (cathéter, prothèse).</li>
<li>Terrain : <b>matériel étranger</b>, prématurés / réanimation néonatale, neutropénie, immunodéprimés ; <i>S. saprophyticus</i> : femme jeune sexuellement active (2<sup>e</sup> agent d'IU communautaire après <i>E. coli</i>).</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>Biofilm (slime)</b> : adhésion au matériel (AtlE, Fbe), PIA/PNAG (<i>ica</i>), Aap, Embp ⇒ protège de la phagocytose et des ATB ; infection <span class="r">chronique, rechutes, retrait du matériel souvent nécessaire</span>.</li>
<li>Peu de toxines (PSM) : <b>pathogènes opportunistes</b>, virulence faible. <i>S. lugdunensis</i> : virulence proche de <i>S. aureus</i>.</li>
<li><i>S. saprophyticus</i> : adhésine <b>Aas</b> (urothélium), <b>uréase</b> ; pas de biofilm.</li>
<li>Voie : flore cutanée → pose de cathéter / chirurgie → colonisation du matériel → bactériémie.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Infections liées aux soins sur matériel</b> : bactériémie sur cathéter ; infection de prothèse articulaire (chronique, descellement) ; <b>endocardite sur valve prothétique</b> (précoce < 1 an) ; dérivation du LCR ; pacemaker ; médiastinite post-sternotomie.</li>
<li><b>Nouveau-né / prématuré</b> : sepsis tardif sur cathéter.</li>
<li><b>Endocardite sur valve native</b> : <i>S. lugdunensis</i> <span class="r">(agressive, destructrice, comme <i>S. aureus</i>)</span>.</li>
<li><b>Cystite aiguë</b> (<i>S. saprophyticus</i>) ; pyélonéphrite rare ; urétrite chez l'homme.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : <b>≥ 2 hémocultures</b> sur sites différents ; <span class="r">SCN sur 1 seule hémoculture = contaminant probable</span> ; vrai si ≥ 2 positives, même ATBg + clinique. Cathéter : Maki ≥ 15 UFC ; quantitatif ≥ 10³ UFC/mL ; DTP ≥ 2 h. Prothèse : ≥ 3 prélèvements per-op, ≥ 2 positifs, même souche. ECBU : <i>S. saprophyticus</i> ≥ 10³ UFC/mL (seuil bas) chez la femme symptomatique.</li>
<li><b>Direct</b> : Gram → cocci Gram + en amas. <b>Culture</b> : gélose au sang / Chapman.</li>
<li><b>Identification</b> : catalase +, coagulase –, MALDI-TOF, galerie API Staph ; novobiocine (<i>S. saprophyticus</i>). <b>Typage</b> : PFGE / MLST (clonalité).</li>
<li><b>ATBg</b> : Mueller-Hinton, McFarland 0,5, 35 °C, 18–24 h (24 h oxacilline / glycopeptides) ; contrôle <i>S. aureus</i> ATCC 29213 (disque et CMI). <b>Méti-R</b> : disque <b>céfoxitine 30 µg</b> : <i>S. epidermidis</i> < 27 mm ⇒ R ; autres SCN < 22 mm ⇒ R (<i>S. lugdunensis</i> : à vérifier) ; <i>S. schleiferi</i> : oxacilline 1 µg ; PCR <i>mecA</i> / latex PLP2a.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Résistance aux antibiotiques</div><div class="bb"><ul>
<li><b>Naturelle</b> : <i>S. saprophyticus</i> : novobiocine, fosfomycine, acide fusidique.</li>
<li><b>Acquise</b> : <b>méti-R (<i>mecA</i>, PLP2a, SCC<i>mec</i>)</b> très fréquente chez les SCN nosocomiaux ⇒ <span class="r">R à TOUTES les β-lactamines</span> (sauf C5G anti-SARM), même si S à l'ATBg (hétérorésistance) ; aminosides (<i>aac6'-aph2''</i>), FQ (<i>gyrA / grlA</i>), rifampicine (<i>rpoB</i>, <span class="r">jamais en monothérapie</span>) ; <span class="r"><i>S. haemolyticus</i> : sensibilité ↓ glycopeptides (teicoplanine) ⇒ CMI par microdilution (référence ; E-test surestime) ; S ≤ 4 / R > 4 mg/L (vanco, teico)</span>.</li>
</ul>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Principe</b> : <span class="r">ne traiter que si infection prouvée</span> (≠ contaminant) ; <b>retrait du cathéter / matériel</b> si possible ; antibiothérapie guidée par l'ATBg.</li>
<li><b>Méti-S</b> : oxacilline / cloxacilline IV (ou céfazoline). <b>Méti-R</b> : <b>vancomycine</b> IV (dose de charge 15–20 mg/kg puis perfusion continue 30–40 mg/kg/j) ; alternatives : daptomycine, linézolide, teicoplanine.</li>
<li><b>Infection sur prothèse</b> : chirurgie + association avec <b>rifampicine</b> (jamais seule), durée longue (6 sem. – 3 mois, à vérifier). <b>Endocardite sur valve prothétique</b> : β-lactamine ou vancomycine + rifampicine + gentamicine.</li>
<li><b>Cystite à <i>S. saprophyticus</i></b> : <b>nitrofurantoïne</b> 5 j ; <span class="r">fosfomycine proscrite (R naturelle)</span>.</li>
<li><b>Prévention</b> : asepsie à la pose du cathéter (hygiène des mains, antisepsie chlorhexidine alcoolique), retrait précoce ; antibioprophylaxie chirurgicale (céfazoline). <b>Pas de vaccin</b> ⇒ PEV : sans objet. Pas de MDO ; signaler au CLIN.</li>
</ul></div></div>
