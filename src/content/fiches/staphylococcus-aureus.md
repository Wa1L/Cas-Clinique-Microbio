<div class="box bl"><div class="bt">Caractères bactériologiques</div><div class="bb">
<p><span class="h">Morphologie</span> : cocci <b>Gram +</b> (0,5–1,5 µm), <b>en amas</b> (grappes de raisin), immobiles, asporulés ; capsule inconstante (sérotypes 5 et 8).</p>
<p><span class="h">Exigences</span> : peu exigeant ; aéro-anaérobie facultatif ; <b>halotolérant</b> (NaCl 7,5 %) ; T 10–45 °C (optimum 37 °C).</p>
<p><span class="h">Culture</span> : gélose ordinaire / sang, 37 °C, 18–24 h ; colonies 1–3 mm lisses, bombées, <b>pigment doré</b>, <b>β-hémolyse</b> ; <b>Chapman</b> (mannitol salé) : colonies jaunes (mannitol +).</p>
<p><span class="h">Biochimie</span> : <b>catalase +</b>, oxydase – ; <b>coagulase libre +</b> (plasma de lapin, 4–24 h) ; clumping factor (latex) ; <b>DNase thermostable +</b> ; mannitol + ; <span class="r">coagulase – n'exclut pas <i>S. lugdunensis</i></span>.</p>
<p><span class="h">Antigénie</span> : <b>protéine A</b> (fixe le Fc des IgG) ; acides teichoïques ; capsule ; typage <i>spa</i>, MLST, PFGE.</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li>Réservoir <b>humain</b> (fosses nasales, périnée, mains) : <b>portage nasal 20–30 %</b> ; aussi animal.</li>
<li>Transmission <b>manuportée</b> (soignants), contact direct, objets ; aliments contaminés (TIAC).</li>
<li>Terrain : nouveau-né, diabète, dialyse, cathéters/prothèses, toxicomanie IV, grippe préalable, peau lésée.</li>
<li><b>SARM</b> : hospitalier (HA-MRSA) ; communautaire (CA-MRSA, <b>PVL +</b>) ; animal (LA-MRSA, ST398).</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>Adhésines</b> (fibronectine, fibrinogène, collagène) ; <b>protéine A</b> (anti-opsonisation) ; capsule ; <b>biofilm</b> (matériel).</li>
<li><b>Enzymes</b> : coagulase, staphylokinase (diffusion), hyaluronidase, lipases, DNase. Régulation <b>agr</b> (quorum sensing).</li>
<li><b>Toxines cytolytiques</b> : α-hémolysine ; <b>leucocidine de Panton-Valentine (PVL)</b> ⇒ furoncles récidivants, <span class="r">pneumonie nécrosante</span>.</li>
<li><b>Exfoliatines A/B</b> ⇒ impétigo bulleux, SSSS. <b>TSST-1</b> (superantigène) ⇒ choc toxique. <b>Entérotoxines</b> (SEA–SEE classiques ; &gt; 20 décrites : SEG, SEH, SEI…) <b>thermostables</b> ⇒ TIAC.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Cutanées</b> : furoncle, anthrax, panaris, folliculite ; <b>impétigo bulleux</b> ; <b>SSSS</b> (syndrome de Ritter, nourrisson : décollement cutané).</li>
<li><b>Profondes</b> : bactériémie, <b>endocardite aiguë</b>, ostéomyélite, arthrite, abcès, <span class="r">pneumonie nécrosante post-grippale (PVL)</span>, infections sur matériel.</li>
<li><b>Toxiniques</b> : <b>choc toxique</b> (fièvre, rash scarlatiniforme, hypotension, défaillance multiviscérale, desquamation tardive) ; <b>TIAC</b> : incubation 1–6 h, vomissements, <b>apyrexie</b>, guérison en 24 h.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : pus, hémocultures (≥ 2 paires), matériel, aliments (TIAC) ; <span class="r"><i>S. aureus</i> en hémoculture = jamais un contaminant</span> ; <span class="r">portage nasal ≠ infection</span>.</li>
<li><b>Direct</b> : Gram : cocci Gram + en amas. <b>Culture</b> : gélose sang, Chapman.</li>
<li><b>Identification</b> : catalase +, coagulase +, DNase +, latex, MALDI-TOF ; PCR <i>nuc</i>, <i>mecA/mecC</i>, PVL.</li>
<li><b>ATBg</b> : Mueller-Hinton, McFarland 0,5, 35 °C, air, 18 h ; contrôle <b>ATCC 29213</b> (disques et CMI ; 25923 = CLSI seul). <b>Dépistage SARM</b> : disque <b>céfoxitine 30 µg</b>, Ø &lt; 22 mm ⇒ SARM ; latex PBP2a.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Résistance aux antibiotiques</div><div class="bb"><ul>
<li><b>Naturelle</b> : molécules actives sur Gram – seul (aztréonam, polymyxines, acide nalidixique).</li>
<li><b>Acquise aux β-lactamines</b> :</li>
</ul>

<li><span class="r">SARM : toutes les β-lactamines R</span> (AMC, C3G, carbapénèmes), sauf <b>ceftaroline / ceftobiprole</b>.</li>
<li><b>MLSB</b> (<i>erm</i>) : constitutive (R E, L, SB) ; <b>inductive</b> (R E, S L ; <b>zone en D</b> ⇒ clindamycine à exclure) ; <i>msrA</i> : phénotype MS (R E, S L).</li>
<li>FQ : <i>gyrA/grlA</i> ; <b>rifampicine</b> (<i>rpoB</i>) : <span class="r">monothérapie proscrite</span> ; acide fusidique, fosfomycine : mutants rapides.</li>
<li><b>Glycopeptides</b> : GISA/hGISA (CLSI : CMI 4–8 ; EUCAST/CA-SFM : S ≤ 2, R &gt; 2, pas de I) ; paroi épaissie ; VRSA (<i>vanA</i>, rare).</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>SASM</b> : oxacilline/cloxacilline IV ou céfazoline (doses selon site, à vérifier). <b>SARM</b> : <b>vancomycine</b> (dose de charge puis perfusion continue, dosages) ; alternatives : daptomycine, linézolide, ceftaroline.</li>
<li><b>Endocardite</b> : β-lactamine IV 4–6 sem ; <span class="r">gentamicine non recommandée sur valve native</span> (ESC 2023 : sans bénéfice, néphrotoxique) ; valve prothétique : + rifampicine + gentamicine. <b>Choc toxique</b> : β-lactamine/vanco + <b>clindamycine</b> (anti-toxine) ± Ig IV, retrait du corps étranger (tampon).</li>
<li><b>Cutané</b> : <b>drainage</b> de l'abcès ; ATB selon gravité. Ostéo-articulaire / matériel : chirurgie + ATB prolongée.</li>
<li><b>Prévention</b> : hygiène des mains (SHA), <b>précautions contact</b> pour SARM, dépistage nasal, décolonisation (mupirocine + chlorhexidine). <b>Vaccin</b> : aucun (PEV : sans objet). <b>Déclaration</b> : TIAC (obligatoire) ; infections nosocomiales/SARM : surveillance.</li>
</ul></div></div>
