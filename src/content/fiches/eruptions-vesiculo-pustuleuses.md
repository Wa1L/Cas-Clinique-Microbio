<p><span class="h">Réplication</span> : herpèsvirus = <b>noyau</b>, enveloppés, <b>latence</b> ganglionnaire ; poxvirus = <b>cytoplasme</b> (ARN pol virale virionnaire, inclusions cytoplasmiques) ; entérovirus = cytoplasme, résistants.</p>
</div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>VZV</b> : voie aérienne / contact des vésicules → muqueuse ORL → <b>virémie</b> (foie, rate) → 2<sup>e</sup> virémie → peau. Histologie : <b>ballonisation</b>, cellules géantes multinucléées, inclusions intranucléaires.</li>
<li><b>Latence</b> : VZV (ganglions sensitifs crâniens et dorsaux), HSV-1 (trijumeau ; cause aussi d'herpès génital), HSV-2 (sacrés) → réactivation = <b>zona / récurrences</b> (stress, immunodépression).</li>
<li><b>Mpox</b> : zoonose (rongeurs) ; transmission interhumaine par contact étroit (dont sexuel), gouttelettes.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Complications / terrains à risque</div><div class="bb"><ul>
<li><b>Varicelle</b> : surinfection (SGA, <i>S. aureus</i> → fasciite), pneumonie (adulte, grossesse), cérébellite / encéphalite ; formes graves chez l'immunodéprimé.</li>
<li><b>Congénitale</b> (infection maternelle précoce) ; <b>néonatale</b> grave si éruption maternelle de J–5 à J+2 de l'accouchement.</li>
<li><b>Zona</b> : névralgie post-zonale ; <b>V1</b> (signe de Hutchinson → kératite) ; Ramsay-Hunt.</li>
<li><b>HSV</b> : eczéma herpeticum (Kaposi-Juliusberg), herpès néonatal, encéphalite temporale.</li>
<li><b>EV-A71</b> : rhombencéphalite, œdème pulmonaire.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic virologique</div><div class="bb"><ul>
<li><b>Prélèvement</b> : écouvillon sur le <b>plancher de la vésicule</b> (après ouverture) ; croûtes utilisables pour les poxvirus.</li>
<li><b>PCR / RT-PCR = référence</b> : typage VZV / HSV-1 / HSV-2 ; orthopoxvirus + MPXV spécifique (clade) ; entérovirus (vésicule, gorge, selles).</li>
<li><b>Tzanck</b> : cellules géantes multinucléées, peu sensible, <span class="r">ne distingue pas HSV de VZV</span>.</li>
<li><b>Sérologie</b> : IgG VZV = <b>statut immunitaire</b> (grossesse, soignants) ; IgM peu utiles.</li>
<li><b>Poxvirus</b> : ME (virion « en brique »), laboratoire habilité ; <span class="r">suspicion de variole = alerte sanitaire</span>.</li>
</ul></div></div>

</div></div>

<div class="box gr"><div class="bt">Traitement / prévention</div><div class="bb"><ul>
<li><b>Aciclovir IV</b> (activé par la <b>TK virale</b>) : immunodéprimé, nouveau-né, pneumonie varicelleuse, encéphalite herpétique, Kaposi-Juliusberg grave. <b>Valaciclovir PO</b> : zona (≥ 50 ans ou ophtalmique, &lt; 72 h), herpès (primo-infection, récurrences), varicelle de l'adulte. <b>Foscarnet</b> si résistance (TK mutée).</li>
<li><b>Varicelle</b> : vaccin vivant atténué (Oka ; CI grossesse, immunodépression) ; Ig anti-VZV post-exposition ; isolement aérien + contact jusqu'aux croûtes.</li>
<li><b>Zona</b> : vaccin recombinant (gE adjuvanté) chez ≥ 50 ans.</li>
<li><b>Mpox</b> : vaccin MVA-BN (non réplicatif) ; tecovirimat : <b>pas de bénéfice démontré</b> sur la résolution des lésions (PALM007, STOMP) ; soins de support.</li>
<li><b>Main-pied-bouche</b> : symptomatique, hygiène des mains / selles.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">Polymorphe = varicelle ; monomorphe = variole / mpox.</span> Centripète vs centrifuge.</li>
<li><b>Zona</b> : unilatéral, métamérique ; <b>V1</b> = urgence ophtalmologique.</li>
<li><span class="r">Aspirine et AINS contre-indiqués dans la varicelle</span> (Reye, surinfection).</li>
<li>Tzanck ne différencie pas HSV / VZV → <b>PCR sur plancher de vésicule</b>.</li>
<li>Aciclovir <b>inactif</b> sur poxvirus et entérovirus ; mpox : adénopathies (≠ variole).</li>
</ul></div></div>
