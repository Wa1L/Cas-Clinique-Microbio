<div class="box bl"><div class="bt">Caractères virologiques</div><div class="bb">
<p><span class="h">Virion</span> : sphérique <b>50–80 nm</b>, <b>enveloppé</b> (lipides + glycoprotéines <b>E1/E2</b>), nucléocapside icosaédrique (Core) ; circule en <b>lipoviroparticules</b> (liées aux VLDL/LDL) ⇒ <span class="r">neutralisation difficile</span>. Sensible à l'éther et aux détergents.</p>
<p><span class="h">Génome</span> : <b>ARN simple brin +, ≈ 9,6 kb</b>, un seul cadre de lecture ⇒ polyprotéine ≈ 3 000 aa clivée en <b>structurales</b> (Core, E1, E2, p7) et <b>non structurales</b> (NS2, <b>NS3/4A</b> protéase-hélicase, NS4B, <b>NS5A</b>, <b>NS5B</b> ARN polymérase). <b>5′UTR</b> = IRES, très conservée (cible de la PCR).</p>
<p><span class="h">Réplication</span> : cytoplasmique (« membranous web » du RE) ; récepteurs <b>CD81, SR-B1, claudine-1, occludine</b> ; pas d'intégration. <b>NS5B sans relecture</b> ⇒ erreurs ⇒ <b>quasi-espèces</b>.</p>
<p><span class="h">Culture</span> : <span class="r">pas de culture de routine, pas d'ECP</span> ; système <b>JFH-1</b> sur cellules Huh-7 (recherche) ; modèle animal : chimpanzé, souris à foie humanisé.</p>
<p><span class="h">Antigénie</span> : <b>HVR1</b> (région hypervariable d'E2) = cible des Ac neutralisants, mais <span class="r">échappement permanent</span> ⇒ pas d'immunité protectrice durable, <b>pas de vaccin</b>.</p>
<p><span class="h">Génotypes</span> : <b>8 (GT1–8)</b>, &gt; 90 sous-types (1a, 1b, 3a…) ; GT1 : le + fréquent dans le monde (<b>1b majoritaire en Algérie</b> : ≈ 57 % Alger, jusqu'à ≈ 80 % Est) ; GT2 : Afrique de l'Ouest (Algérie : Ouest) ; <b>GT3</b> : Asie du Sud, UDIV, stéatose ; <b>GT4</b> : Afrique du Nord/Égypte, Moyen-Orient ; GT5 : Afrique du Sud ; GT6 : Asie du Sud-Est ; GT7 : Afrique centrale ; GT8 : Inde (Pendjab).</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li>Réservoir <b>strictement humain</b> ; ≈ <b>50 M</b> de porteurs chroniques dans le monde (OMS) ; prévalence Algérie ≈ 0,5–1 % (donneurs ≈ 0,4 % ; ↑ hémodialysés, foyers à l'Est).</li>
<li>Transmission <b>parentérale (sang)</b> : <b>UDIV</b> (partage de matériel), transfusion / dérivés sanguins <b>avant dépistage (1990–92)</b>, <b>nosocomiale</b> (hémodialyse, endoscopie, matériel non jetable), tatouage / piercing / rasoir partagé ; <b>verticale ≈ 5 %</b> (↑ si VIH) ; <b>sexuelle rare</b> (↑ HSH VIH+). <span class="r">Allaitement non contre-indiqué</span> (sauf mamelons saignants). <b>AES percutané ≈ 2 %</b> (1,8 % CDC ; ≈ 0,2 % séries récentes).</li>
<li>Terrain : hémodialysés, hémophiles, polytransfusés, UDIV, détenus, VIH+ ; <b>co-infection VIH/VHB</b> aggravante.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li>Tropisme <b>hépatocytaire</b> (aussi lymphocytes B) ; <b>pas d'effet cytopathique direct majeur</b> : lésions <b>immuno-médiées</b> (LT CD8, cytokines).</li>
<li><b>Chronicisation 70–80 %</b> (guérison spontanée 20–30 %) : quasi-espèces (HVR1), épuisement T, lipoviroparticules.</li>
<li>Inflammation chronique + cellules étoilées ⇒ <b>fibrose</b> → <b>cirrhose</b> (≈ 20 % après 20–30 ans) → <b>CHC</b> (≈ 1–4 %/an sur cirrhose). Accélérateurs : <span class="r">alcool, VIH, VHB, obésité, âge &gt; 40 ans, sexe M</span>. <b>Stéatose virale (GT3)</b>.</li>
<li>Extra-hépatique : <b>cryoglobulinémie mixte type II</b> (IgM-FR) ⇒ vascularite, <b>GNMP</b> ; lymphome B ; <b>porphyrie cutanée tardive</b> ; lichen plan ; insulinorésistance.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Hépatite aiguë</b> : incubation 2–26 sem (≈ 6–8 sem) ; <b>asymptomatique &gt; 70 %</b>, ictère 20–30 % ; forme fulminante exceptionnelle ; ALAT ↑↑.</li>
<li><b>Chronique</b> (ARN+ ≥ 6 mois) : <span class="r">silencieuse</span> (asthénie), ALAT fluctuantes voire normales ⇒ découverte <b>tardive</b> (dépistage, bilan préopératoire, don du sang).</li>
<li><b>Cirrhose</b> : <span class="r">décompensation (ascite, ictère, hémorragie digestive par rupture de VO, encéphalopathie)</span> ; <b>CHC</b>.</li>
<li>Extra-hépatique : purpura vasculaire, arthralgies, neuropathie, atteinte rénale (cryoglobulinémie).</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : sérum / plasma EDTA ; séparer vite, congeler (–20 / –80 °C) pour l'ARN ; <span class="r">héparine proscrite (inhibe la PCR)</span>.</li>
<li><b>Dépistage</b> : <b>Ac anti-VHC</b> (ELISA 3e génération, Ac seuls ; 4e génération = test combiné Ag-Ac, fenêtre ↓) ; apparition <b>6–8 sem</b> après contamination ⇒ <span class="r">fenêtre sérologique : infection aiguë = ARN</span>.</li>
<li><b>ARN VHC</b> : RT-PCR temps réel (seuil ≈ 10–15 UI/mL), qualitatif puis quantitatif (UI/mL) ; détectable dès 1–2 sem ; <b>confirme l'infection active</b> (alternative : Ag core).</li>
<li><b>Génotypage</b> : séquençage NS5B / 5′UTR. <b>Fibrose</b> : <b>FibroScan</b> (≥ 12,5 kPa = cirrhose ; F2 ≥ 7 ; F3 ≥ 9,5), FIB-4, APRI ; PBH rarement.</li>
</ul>

<div class="box dr"><div class="bt">Antiviraux d'action directe (AAD) et résistance</div><div class="bb"><ul>
<li><b>Inhibiteurs NS3/4A</b> (-previr : glécaprévir) ; <b>NS5A</b> (-asvir : velpatasvir, daclatasvir, pibrentasvir) ; <b>NS5B</b> nucléotidique (-buvir : <b>sofosbuvir</b>). Ancien : IFN-PEG + ribavirine (obsolète ; <span class="r">ribavirine tératogène</span>).</li>
<li>Résistance : <b>RAS</b> (substitutions associées), surtout <b>NS5A</b> (Y93H, L31…) ; <b>sofosbuvir : barrière génétique élevée</b> (S282T rare) ; échec : GT3, cirrhose, prétraités ⇒ <b>génotypage de résistance après échec seulement</b>. Pas d'ATBg (virus).</li>
<li><span class="r">Interactions : amiodarone + sofosbuvir = bradycardie sévère (proscrit)</span> ; IPP ↓ absorption ; inducteurs (rifampicine, carbamazépine) contre-indiqués. <span class="r">Dépister le VHB avant : réactivation (HBsAg+ ou anti-HBc+)</span>.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Objectif</b> : <b>RVS12</b> (ARN indétectable 12 sem après arrêt) = guérison virologique (&gt; 95 %) ; <b>tout patient virémique</b> est traitable, quel que soit le stade.</li>
</ul>

<ul>
<li><b>Cirrhose décompensée</b> : sofosbuvir/velpatasvir + <b>ribavirine</b> 12 sem ; <span class="r">antiprotéases (glécaprévir) contre-indiqués (Child B/C)</span>.</li>
<li><b>Suivi</b> : ARN à S12 post-traitement ; échographie ± AFP /6 mois si F3-F4, même après RVS ; <span class="r">RVS ≠ immunité (réinfection possible)</span>.</li>
<li><b>Vaccin</b> : <span class="r">aucun contre le VHC</span> ; vacciner contre VHA/VHB (PEV algérien : VHB monovalent à la naissance &lt; 24 h + hexavalent à 2, 4, 12 mois). Dépistage des dons (Ac ± ARN), matériel à usage unique, réduction des risques (échange de seringues).</li>
<li><b>AES</b> : pas de prophylaxie ; J0 : Ac anti-VHC du soignant + statut de la source (ARN) ; si source ARN+ / inconnue : ARN à 3–6 sem, puis Ac à 4–6 mois. Enfant de mère VHC+ : ARN dès 2–6 mois ; sinon Ac anti-VHC ≥ 18 mois. Dépistage VIH/VHB associé et de l'entourage ; <b>déclaration</b> : hépatites virales (MDO).</li>
</ul></div></div>
