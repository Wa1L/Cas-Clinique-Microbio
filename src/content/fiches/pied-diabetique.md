<div class="col">

<div class="box br"><div class="bt">Généralités</div><div class="bb"><ul>
<li>Complication fréquente de l'<b>ulcère du pied diabétique</b> ; première cause d'<b>amputation non traumatique</b> des membres inférieurs.</li>
<li>Triade pathogène : <b>neuropathie · AOMI · infection</b> (± œdème, hyperpressions).</li>
<li><span class="r">La plaie précède toujours l'infection</span> : pas de plaie → pas d'infection du pied.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><span class="h">Neuropathie</span> sensitivo-motrice-autonome → plaie méconnue, points d'hyperpression, peau sèche fissurée.</li>
<li><span class="h">Porte d'entrée</span> → colonisation → <b>biofilm</b> (tolérance aux ATB, cicatrisation retardée) → infection.</li>
<li><span class="h">Ischémie</span> : O₂ et diffusion des ATB ↓ → échec thérapeutique, gangrène.</li>
<li><span class="h">Immunité</span> : fonction des PNN ↓ (chimiotaxie, phagocytose) en hyperglycémie.</li>
<li><span class="h">Propagation</span> le long des gaines tendineuses et loges plantaires → abcès profonds ; <b>ostéite par contiguïté</b> (têtes métatarsiennes, talon).</li>
<li><span class="r">Signes systémiques trompeurs</span> : fièvre et hyperleucocytose souvent absentes malgré une infection profonde.</li>
</ul></div></div>

<div class="box br"><div class="bt">Étiologie bactérienne</div><div class="bb">
<table class="mt">
  <tr><th>Contexte</th><th>Germes</th></tr>
  <tr><td>Plaie récente, ATB-naïf</td><td><i>S. aureus</i> (SAMS/SARM), streptocoques β-hémolytiques (A, B)</td></tr>
  <tr><td>Ulcère chronique, ATB antérieurs</td><td>Polymicrobien : + entérobactéries (<i>E. coli, Proteus, Klebsiella</i>), entérocoques</td></tr>
  <tr><td>Nécrose, ischémie, gangrène</td><td>+ <b>anaérobies</b> (<i>Bacteroides, Peptostreptococcus, Clostridium</i>)</td></tr>
  <tr><td>Macération, eau, climat chaud</td><td><i>Pseudomonas aeruginosa</i></td></tr>
</table>
<p><i>S. aureus</i> = germe le plus fréquent ; flore souvent <b>polymicrobienne</b> si chronique.</p>
</div></div>

<div class="box dr"><div class="bt">Résistance / limites</div><div class="bb"><ul>
<li><b>SARM</b> : ATCD de SARM, hospitalisation ou ATB récents, prévalence locale élevée → à couvrir dans le probabiliste.</li>
<li><b>BLSE</b> (entérobactéries) : ATB antérieurs, hospitalisation → carbapénème.</li>
<li><b>Biofilm</b> : tolérance aux ATB → <b>débridement</b> indispensable.</li>
<li><span class="r">ATB prolongés sans justification</span> → sélection de BMR.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><span class="h">Clinique</span> : ≥ 2 signes inflammatoires locaux (cf. schéma) ; signes secondaires : écoulement non purulent, odeur, tissu de granulation friable, retard de cicatrisation.</li>
<li><span class="r">Neuropathie/ischémie masquent les signes</span> : l'absence de fièvre ou d'hyperleucocytose n'exclut pas l'infection.</li>
<li><span class="h">Biologie</span> : NFS, CRP, ± procalcitonine, glycémie/HbA1c, créatinine. <b>VS élevée (&gt; 70 mm/h)</b> évoque une ostéite.</li>
<li><span class="h">Prélèvement</span> : <b>après débridement</b>, tissu profond (biopsie ou curetage du fond) ; hémocultures si sepsis. <span class="r">Écouvillon superficiel proscrit</span> (colonisants).</li>
<li><span class="h">Ostéite</span> : biopsie osseuse = référence (culture + histologie).</li>
</ul>
<table class="mt">
  <tr><th>Examen</th><th>Apport</th><th>Piège</th></tr>
  <tr><td>Sonde (PTB)</td><td>Contact osseux → forte probabilité d'ostéite</td><td>Valeur selon prévalence</td></tr>
  <tr><td>Rx pied</td><td>1ère intention : lyse, périostite, séquestre, gaz</td><td>Normale les 2–4 1ères sem.</td></tr>
  <tr><td>IRM</td><td>Meilleure imagerie ; abcès, extension</td><td>Œdème du Charcot ≈ ostéite</td></tr>
  <tr><td>Scinti. leuco / TEP</td><td>Si IRM impossible</td><td>Disponibilité limitée</td></tr>
</table>
<p><span class="h">Bilan vasculaire</span> : pouls, IPS/IPSO (<span class="r">IPS faussement normal si médiacalcose</span>), écho-Doppler, TcPO₂.</p>
</div></div>

<div class="box gr"><div class="bt">Traitement</div><div class="bb"><ul>
<li><b>Chirurgie</b> : débridement, drainage des collections, résection de l'os infecté ; <b>décharge</b>, équilibre glycémique, <b>revascularisation</b> si AOMI.</li>
<li><b>ATB</b> probabiliste selon le grade puis adapté à la culture ; relais oral dès amélioration.</li>
</ul>
<table class="mt">
  <tr><th>Grade</th><th>Cible</th><th>Exemples</th></tr>
  <tr><td>2 léger</td><td>SAMS, strepto</td><td>Céphalexine ou amox-clav ; clindamycine si allergie. SARM : doxycycline ou TMP-SMX</td></tr>
  <tr><td>3 modéré</td><td>+ BGN ± anaérobies</td><td>Amox-clav ; ou IV : ceftriaxone + métronidazole (± anti-SARM)</td></tr>
  <tr><td>4 sévère</td><td>Large spectre, IV</td><td>Pip-tazo ; BLSE : ertapénème (sauf risque <i>Pseudomonas</i> : méropénème) ; + vancomycine ou linézolide si SARM</td></tr>
</table>
<ul>
<li><b>Pseudomonas</b> : pas de couverture systématique ; à envisager si grade 3–4 et isolement récent sur le site ou climat tropical/subtropical (Afrique du Nord, Asie).</li>
<li><span class="h">Durée</span> : tissus mous <b>1–2 sem</b> (3–4 si évolution lente) ; ostéite sans résection <b>6 sem</b> ; résection avec marge positive <b>3 sem</b> ; marge saine : <b>2–5 j</b>.</li>
<li><span class="r">Ni antibiotique ni prophylaxie sur plaie non infectée.</span></li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">Diagnostic clinique</span> : on ne traite pas une culture positive sur plaie non infectée.</li>
<li><span class="r">Prélèvement profond après débridement</span> ; écouvillon superficiel = faux amis.</li>
<li>Ostéite : sonde, Rx (tardive), <b>IRM</b>, <b>biopsie osseuse</b> ; durée 6 sem si pas de résection.</li>
<li>Pied ischémique infecté = <b>urgence</b> : revascularisation + chirurgie + ATB.</li>
</ul></div></div>
