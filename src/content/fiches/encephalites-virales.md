<div class="box br"><div class="bt">Généralités / Épidémiologie</div><div class="bb">
<p><span class="h">Définition</span> : inflammation du <b>parenchyme cérébral</b> → fièvre + trouble de conscience/comportement ± <b>convulsions</b>, signes focaux. <b>Méningo-encéphalite</b> si pléocytose + signes méningés.</p>
<p><span class="h">Incidence</span> : ≈ 3,5–7,5/100 000, plus élevée aux âges extrêmes. Virus = cause identifiée la plus fréquente, mais <span class="r">étiologie inconnue dans &gt; 50 % des cas</span>.</p>
<p><span class="h">Terrain</span> : HSV = 1re cause sporadique (toute saison ; pics &lt; 20 ans (primo-infection) et &gt; 50 ans (réactivation)) · arbovirus <b>saisonniers</b> · EV : nourrisson/enfant · rage : exposition animale (chien, endémique en Algérie) · immunodéprimé : HHV-6, CMV, VZV, JCV, VIH.</p>
</div></div>

<div class="box rd"><div class="bt">Physiopathologie — voies d'atteinte</div><div class="bb"><ul>
<li><b>Neurale</b> : HSV (réactivation, ganglion trijumeau), rage (nerfs périphériques → SNC).</li>
<li><b>Hématogène</b> : arbovirus (virémie après piqûre), entérovirus.</li>
<li><b>Réactivation</b> : HSV, VZV, HHV-6, CMV, JCV en cas d'immunodépression.</li>
<li><b>Immuno-médiée</b> : ADEM ; anti-NMDAR dans les semaines suivant une encéphalite herpétique.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Phase pré-analytique (clé de la sensibilité)</div><div class="bb"><ul>
<li><b>LCR</b> : tubes stériles numérotés (cytochimie, bactériologie, virologie) ; <b>réserver un aliquote congelé</b> pour examens différés (PCR, Ac).</li>
<li><b>Sérum + LCR le même jour</b> (index d'Ac, avec albuminorachie/albuminémie) ; <b>2e sérum à 10–14 j</b> (séroconversion).</li>
<li>Ne <span class="r">jamais retarder l'aciclovir</span> pour attendre la PL ou la PCR.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Orientation clinique et imagerie</div><div class="bb"><ul>
<li><b>HSV</b> : fièvre, aphasie, troubles du comportement/mémoire, convulsions, aura olfactive (odeurs nauséabondes) → <b>lobe temporal</b>.</li>
<li><b>IRM</b> = examen de choix : œdème temporal interne + orbitofrontal ; <span class="r">scanner peu sensible</span> (sert à éliminer une contre-indication à la PL). EEG : anomalies temporales.</li>
<li><b>Arbovirus</b> : noyaux gris, thalamus, tronc cérébral.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Interprétation et limites</div><div class="bb"><ul>
<li><b>LCR</b> : pléocytose lymphocytaire, glycorachie N, protéines ↑ modérées, Gram/culture négatifs ; <span class="r">≈ 10 % de LCR normaux</span> ; anomalies parfois seulement 8–24 h après le début.</li>
<li><b>Glycorachie ↓</b> : VZV, ourlien, LCMV → éliminer TB, bactérie, champignon.</li>
<li><b>PCR</b> : prélèvement précoce ou sang dans le LCR → <span class="r">faux négatif</span> ; multiplex rapide mais à confirmer.</li>
<li><b>Sérum seul</b> ne suffit pas : IgM WNV persistantes, réactions croisées.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">PCR HSV négative &lt; 72 h n'exclut pas</span> → répéter J3–7 ; aciclovir IV débuté <b>sans attendre</b> (≈ 10 mg/kg/8 h, 14–21 j).</li>
<li>PCR LCR = test de choix (HSV, VZV, CMV, EV, JCV) ; arbovirus → <b>IgM LCR</b> ; rage → salive + biopsie de nuque.</li>
<li>Réactions croisées flavivirus → <b>séroneutralisation</b>.</li>
<li>Cause inconnue &gt; 50 % ; penser aux encéphalites auto-immunes (anti-NMDAR post-HSV).</li>
</ul></div></div>
