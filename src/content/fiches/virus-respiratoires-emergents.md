Bleu foncé = coronavirus ; rouge foncé = influenza A. Pointillés = hôte non établi. HPAI/LPAI = influenza aviaire hautement/faiblement pathogène ; SIA = acide sialique ; H→H = interhumaine ; CFR = létalité parmi les cas confirmés (surestimée si cas bénins non détectés).</div>

<div class="box br"><div class="bt">Généralités</div><div class="bb">
<p><span class="h">Définition</span> : virus <b>émergent</b> = nouvellement identifié ou en augmentation d'incidence / d'aire géographique. <b>Spillover</b> = franchissement de la barrière d'espèce animal → Homme.</p>
<p><span class="h">Origine</span> : ≈ 70 % des pathogènes émergents sont d'origine animale (zoonoses) → approche <b>One Health</b>.</p>
<p><span class="h">Priorité</span> : MERS-CoV = pathogène prioritaire OMS (R&amp;D). <b>RSI 2005</b> : notification immédiate de tout cas humain d'un nouveau sous-type grippal.</p>
<p><span class="h">Contexte algérien</span> : cas importés de MERS signalés au Maghreb (Algérie, Tunisie) → vigilance <b>Hajj / Omra</b>.</p>
</div></div>

<div class="box rd"><div class="bt">Mécanismes d'émergence</div><div class="bb"><ul>
<li><b>Étapes</b> : exposition → fixation sur récepteur (RBD de S / HA) → adaptation (mutations) → transmission interhumaine soutenue (R0 &gt; 1).</li>
<li><b>Grippe</b> : passage α2,3-SIA (aviaire) → <b>α2,6-SIA</b> (voies aériennes hautes) = condition de transmissibilité ; <b>réassortiment</b> avec une souche saisonnière → risque pandémique.</li>
<li><b>HPAI (H5, H7)</b> : site de clivage de HA <b>polybasique</b> → infection systémique chez l'oiseau.</li>
<li><b>Coronavirus</b> : grand génome ARN(+) (~30 kb) ; <b>recombinaison</b> ; RdRp avec relecture (nsp14) → moins de dérive que la grippe.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Définition de cas</b> = clinique + <b>épidémiologique</b> (voyage Moyen-Orient, contact camélidés / volailles, soins).</li>
<li><b>RT-PCR</b> sur prélèvement respiratoire, <b>profond</b> (aspiration trachéale, LBA) si bas appareil ; grippe aviaire : RT-PCR M puis sous-typage HA/NA.</li>
<li>Cibles : SARS-CoV-2 (RdRp, E, N) ; MERS-CoV (upE, ORF1a).</li>
<li>Sérologie (séroconversion) : rétrospectif / enquête.</li>
<li><span class="r">Isolement viral = laboratoire P3 uniquement</span> : 3 des 4 réapparitions du SARS (2003-04) = fautes de biosécurité.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement / Prévention</div><div class="bb"><ul>
<li><b>MERS, SARS</b> : <span class="r">aucun traitement spécifique ni vaccin homologué</span> ; soins de support.</li>
<li><b>SARS-CoV-2</b> : vaccins ARNm ; antiviraux = nirmatrelvir (anti-Mpro), remdésivir (RdRp).</li>
<li><b>Grippe aviaire</b> : oseltamivir (anti-NA) précoce ; vaccins H5 candidats.</li>
<li><b>Prévention</b> : isolement, précautions gouttelettes / air + contact, EPI ; éviter lait cru, urine, viande insuffisamment cuite de camélidés ; contrôle des marchés d'oiseaux vivants ; surveillance <b>One Health</b>.</li>
<li>Voyageur : consulter si signes respiratoires dans les 14 j au retour.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">Récepteurs</span> : ACE2 (SARS-CoV, SARS-CoV-2) ≠ <b>DPP4</b> (MERS-CoV).</li>
<li>Hôtes : SARS ← <b>civette</b> ; MERS ← <b>dromadaire</b> ; <span class="r">SARS-CoV-2 : hôte intermédiaire non établi</span>.</li>
<li>Létalité : H5N1 ≈ 48 % &gt; MERS ≈ 37 % &gt; SARS 9,6 % ; mais H5N1 / H7N9 = <b>pas de transmission interhumaine soutenue</b>.</li>
<li>Pandémie grippale = HA adaptée à α2,6-SIA + transmission interhumaine soutenue.</li>
</ul></div></div>
