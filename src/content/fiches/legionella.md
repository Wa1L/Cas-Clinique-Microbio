<div class="box bl"><div class="bt">Caractères bactériologiques</div><div class="bb">
<p><span class="h">Morphologie</span> : bacille Gram – <b>grêle</b> (0,3–0,9 × 2–20 µm), mobile (flagelle polaire), non sporulé, <b>intracellulaire facultatif</b> ; <span class="r">Gram très faible</span> (contre-coloration prolongée) ⇒ Gimenez, Dieterle / Warthin-Starry, IFD.</p>
<p><span class="h">Exigences</span> : <b>L-cystéine</b> + <b>fer</b> (pyrophosphate ferrique) ; <span class="r">pas de pousse sur gélose ordinaire / au sang</span> (test de repiquage : pousse sur BCYE avec cystéine, pas sans).</p>
<p><span class="h">Culture</span> : <b>BCYE</b> (charbon-extrait de levure tamponné, α-cétoglutarate, pH 6,9) ; sélectif <b>GVPC</b> (glycine, vancomycine, polymyxine B, cycloheximide) ; 35–37 °C, atmosphère humide, CO₂ 2,5 % ; <b>3–5 j</b> (lecture jusqu'à 10–14 j) ; colonies grises, <b>« verre dépoli »</b> iridescent. Prélèvements polymicrobiens : <b>traitement acide</b> (pH 2,2) ou chaleur 50 °C.</p>
<p><span class="h">Biochimie</span> : asaccharolytique ; catalase +, <b>oxydase variable</b>, gélatinase +, nitrate –, uréase –.</p>
<p><span class="h">Antigénie</span> : <b>LPS</b> (sérogroupes) ; <i>L. pneumophila</i> sg 1 : Mab 3/1 (souches virulentes) ; <b>MOMP</b>, Mip (infectivité macrophage), flagelline.</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li>Réservoir <b>hydro-tellurique</b> : eaux douces, <b>biofilms</b>, <b>amibes libres</b> (<i>Acanthamoeba</i>, <i>Naegleria</i>, <i>Hartmannella</i>) ⇒ multiplication et protection.</li>
<li>Croissance <b>25–45 °C</b> (optimum 35–40 °C) ; stagnation, tartre ; détruite à <b>≥ 60 °C</b>. Sources : <b>eau chaude sanitaire</b>, <b>tours aéroréfrigérantes</b>, spas, humidificateurs, fontaines, nébuliseurs.</li>
<li>Transmission par <b>inhalation d'aérosols</b> (&lt; 5 µm) ou micro-aspiration ; <span class="r">jamais interhumaine</span>.</li>
<li>Terrain : âge &gt; 50 ans, <b>tabac</b>, éthylisme, BPCO, diabète, IRC, <b>immunodépression</b> (corticoïdes, anti-TNF, greffe) ; ♂ &gt; ♀. Cas communautaires, <b>nosocomiaux</b>, voyages (hôtels, croisières) ; cas groupés possibles.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li>Inhalation ⇒ alvéole ⇒ <b>phagocytose par macrophages alvéolaires</b> (« coiling phagocytosis ») ⇒ <b>vacuole LCV</b> : <span class="r">pas de fusion phagolysosome</span>.</li>
<li><b>Système de sécrétion de type IV Dot/Icm</b> (≈ 300 effecteurs) : détourne le trafic vésiculaire (RE, mitochondries) ⇒ multiplication intracellulaire ⇒ <b>lyse</b> du macrophage, cycle répété.</li>
<li>Autres : <b>Mip</b>, métalloprotéase, LPS, biofilm, résistance aux amibes. Lésions : <b>pneumonie fibrino-leucocytaire</b>, alvéolite, rare abcédation.</li>
<li>Défense : <b>immunité cellulaire</b> (Th1, IFN-γ) ; anticorps peu protecteurs. Dissémination hématogène possible.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Maladie des légionnaires</b> : incubation <b>2–10 j</b> (jusqu'à 14) ; début progressif, <b>fièvre 39–40 °C</b>, toux sèche, dyspnée, douleur thoracique ; <b>pouls dissocié</b>.</li>
<li><b>Signes extra-respiratoires</b> : diarrhée, vomissements, <b>confusion</b>, céphalées, myalgies. Biologie : <b>hyponatrémie</b>, ↑ CPK, cytolyse hépatique, IR, lymphopénie.</li>
<li>Radio : condensation alvéolaire <b>extensive</b>, parfois bilatérale. <span class="r">Échec des β-lactamines</span> = signe d'orientation. Mortalité 5–10 % (<span class="r">jusqu'à 30 % si traitement tardif / nosocomial</span>).</li>
<li><b>Fièvre de Pontiac</b> : incubation <b>1–2 j</b>, syndrome pseudo-grippal, sans pneumonie, guérison spontanée en 2–5 j.</li>
<li>Formes extra-pulmonaires rares : endocardite, péricardite, abcès, arthrite, sinusite.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : expectoration, aspiration trachéale, <b>LBA</b>, biopsie ; urines ; sérum. <span class="r">Hémocultures standard inutiles</span> ; <b>conservation</b> : +2 à +8 °C si délai (24–48 h), <b>–70 / –80 °C si &gt; 48 h</b> ; <span class="r">éviter T° ambiante prolongée et congélation–décongélation répétées</span>.</li>
<li><b>Direct</b> : Gram = nombreux PNN, <b>pas de bactéries / flore pauvre</b> ; IFD (Ac monoclonaux, Se 25–70 %).</li>
<li><b>Antigénurie</b> (LPS sg 1) : rapide, Se ≈ 70–80 %, positive dès J2–3 ; <span class="r">détecte seulement <i>L. pneumophila</i> sg 1</span> ⇒ faux négatifs.</li>
<li><b>Culture</b> BCYE / GVPC (référence, indispensable pour le typage) ; <b>PCR temps réel</b> (<i>mip</i>, 5S/16S) : plus sensible que la culture.</li>
<li><b>Sérologie</b> : rétrospective, ↑ ×4 du titre (IFI) ; peu utile en urgence.</li>
<li><b>Typage</b> : sérogroupage, <b>SBT</b> (ESGLI) pour comparer souche clinique / environnementale ; enquête sur l'eau (1 L + thiosulfate).</li>
<li><b>ATBg</b> : <span class="r">non réalisé en routine</span> : CLSI (M100, M45) = <b>aucune méthode standardisée, aucun breakpoint, aucune souche QC</b> pour <i>Legionella</i> ; <span class="r">dilution en gélose BCYE non fiable</span> (le <b>charbon fixe</b> macrolides, FQ, rifampicine ⇒ CMI faussement ↑) ; recherche : microdilution en bouillon BYE sans charbon. <b>ATCC 33152</b> (Philadelphia-1) = souche type, QC des milieux / culture (pas QC d'ATBg).</li>
</ul></div></div>

<div class="box dr"><div class="bt">Résistance aux antibiotiques</div><div class="bb"><ul>
<li><b>Naturelle</b> : <b>β-lactamines</b> (C3G, pénicillines) et <b>aminosides</b> inefficaces <i>in vivo</i> : <span class="r">mauvaise pénétration intracellulaire</span> ; β-lactamase (<i>L. pneumophila</i>). Cible = antibiotique à <b>forte concentration intracellulaire</b>.</li>
<li><b>Acquise</b> : exceptionnelle ; FQ : mutations <i>gyrA</i> (sous traitement, rares) ; macrolides : efflux (<i>lpeAB</i>) ; pas de problème clinique majeur.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>1<sup>re</sup> intention</b> : <b>fluoroquinolone</b> (lévofloxacine) <b>ou macrolide</b> (azithromycine) ; forme grave : hospitalisation / réanimation, FQ ± macrolide (association à discuter).</li>
</ul>
