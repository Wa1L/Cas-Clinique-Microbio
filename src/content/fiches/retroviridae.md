<div class="box bl"><div class="bt">Caractères virologiques</div><div class="bb">
<p><span class="h">Virion</span> : sphérique 80–120 nm, <b>enveloppé</b> (gp120 SU / gp41 TM), matrice p17, capside <b>p24</b> ; contient <b>RT, intégrase, protéase</b>.</p>
<p><span class="h">Génome</span> : <b>diploïde</b>, 2 copies d'ARN ss +, coiffé/polyadénylé ; <b>LTR</b> aux extrémités du provirus (R-U5 / U3-R sur l'ARN) ; <i>gag</i> (structure), <i>pol</i> (enzymes), <i>env</i> (enveloppe) ; VIH : régulateurs <i>tat, rev</i> ; accessoires <i>nef, vif, vpr, vpu</i>.</p>
<p><span class="h">Réplication</span> : fixation CD4 + corécepteur (<b>CCR5</b>/CXCR4) → fusion (gp41) → <b>RT : ARN → ADN</b> → <b>intégration</b> (provirus) → transcription → assemblage → bourgeonnement → <b>maturation par protéase</b>.</p>
<p><span class="h">Variabilité</span> : RT sans activité de relecture (≈ 10<sup>-4</sup> erreur/base) + recombinaison ⇒ <b>quasi-espèces</b>, échappement immun et aux ARV.</p>
<p><span class="h">Culture</span> : PBMC stimulées (PHA) / lignées T ; ECP : <b>syncytia</b> ; niveau P3 ; pas de diagnostic de routine.</p>
<p><span class="h">Antigénie</span> : <b>p24</b> (Ag diagnostique), gp41 (conservée), <b>gp120</b> (boucle V3 très variable ; cible Ac neutralisants).</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li><b>VIH</b> : sexuelle (1re voie), sanguine (UDI, transfusion, AES), <b>verticale</b> (in utero, accouchement, <b>allaitement</b>) ; <span class="r">pas de transmission par salive, sueur, piqûre d'insecte</span>.</li>
<li>Fluides infectants : sang, sperme, sécrétions génitales, lait.</li>
<li>Algérie : faible prévalence (≈ 0,1 % des 15–49 ans), épidémie <b>concentrée</b> (TS, HSH, UDI, migrants).</li>
<li><b>HTLV-1</b> : porteurs ≈ 5–10 millions ; transmission surtout <b>cellule à cellule</b> (lymphocytes infectés) ; allaitement &gt; 6 mois.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>VIH</b> : tropisme CD4 → <b>déplétion progressive des LT CD4</b> (cytolyse, apoptose, activation immune chronique) ⇒ déficit de l'immunité cellulaire.</li>
<li><b>Réservoir latent</b> : provirus intégré dans LT CD4 mémoire ⇒ <span class="r">jamais éradiqué, rebond à l'arrêt du TAR</span>.</li>
<li><i>Nef</i> : baisse du CMH-I et de CD4 ; <i>Vif</i> : inhibe APOBEC3G ; <i>Vpu</i> : antagonise la tétherine.</li>
<li><b>HTLV-1</b> : <i>Tax / HBZ</i> → prolifération clonale des LT → <b>LTA</b> (2–5 % des porteurs) ; inflammation médullaire → PET/HAM.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Primo-infection VIH</b> (2–4 sem) : syndrome pseudo-grippal/mononucléosique, rash, adénopathies, ulcérations muqueuses ; <span class="r">charge virale très élevée = très contagieux</span> ; souvent muette.</li>
<li><b>Latence clinique</b> (années) : asymptomatique, réplication active, CD4 en baisse.</li>
<li><b>Sida</b> (CD4 &lt; 200/mm³ ou maladie C) : <span class="r">pneumocystose</span> (<i>P. jirovecii</i>), <b>tuberculose</b> (tout taux de CD4), candidose œsophagienne, toxoplasmose cérébrale et cryptococcose (CD4 &lt; 100), CMV rétinien et MAC (CD4 &lt; 50), Kaposi (HHV-8), lymphomes.</li>
<li><b>HTLV-1</b> : <b>LTA</b> (pronostic sombre), <b>PET/HAM</b> (paraparésie spastique), uvéite, dermatite infective.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Dépistage</b> : test <b>Ag p24 + Ac combiné (4e génération)</b> ou test rapide ; <b>confirmation</b> : 2e test (immuno-blot / différentiel VIH-1/2) sur <b>nouveau prélèvement</b> ; <span class="r">fenêtre sérologique</span> : répéter si exposition récente ; <span class="r">primo-infection (p24 +, Ac absents)</span> : immuno-blot négatif/indéterminé ⇒ <b>PCR ARN</b> + contrôle sérologique.</li>
<li><span class="r">Nouveau-né de mère VIH + : sérologie inutile</span> (IgG maternelles jusqu'à 18 mois) ⇒ <b>PCR ARN / ADN proviral</b>.</li>
<li><b>Suivi</b> : <b>charge virale ARN</b> (RT-PCR ; indétectable &lt; 50 cop/mL), <b>CD4</b>, <b>génotypage de résistance</b> (RT, protéase, intégrase) avant TAR et en échec ; <b>HLA-B*57:01</b> avant abacavir.</li>
<li><b>HTLV</b> : ELISA + Western blot ; PCR provirale.</li>
</ul>

<div class="box dr"><div class="bt">Résistance aux antiviraux</div><div class="bb"><ul>
<li><b>Naturelle</b> : <b>VIH-2</b> et VIH-1 groupe <b>O</b> : INNTI ; VIH-2 : enfuvirtide.</li>
<li><b>Acquise</b> : erreurs de la RT + monothérapie/mauvaise observance ⇒ sélection de mutants ; résistance <b>transmise</b> possible ; lecture par <b>génotypage</b>.</li>
</ul>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>TAR à vie, dès le diagnostic</b> quel que soit le taux de CD4 ; <b>1re ligne (OMS)</b> : <b>TDF + 3TC (ou FTC) + dolutégravir</b> ; objectif : charge virale indétectable (<b>I = I</b>, pas de transmission sexuelle).</li>
<li><b>Prophylaxie des IO</b> : <b>cotrimoxazole</b> si CD4 &lt; 200 (pneumocystose, toxoplasmose) ; <span class="r">TB : bilan avant TAR, syndrome IRIS</span>.</li>
<li><b>PTME</b> : TAR de la mère, prophylaxie du nouveau-né (4–6 sem), <b>allaitement artificiel</b> ; césarienne si CV élevée à l'accouchement.</li>
<li><b>PEP</b> : après exposition, <b>dès que possible (≤ 48–72 h)</b>, 28 j ; <b>PrEP</b> : TDF/FTC.</li>
<li><span class="r">Pas de vaccin VIH</span> ; préservatif, dépistage, réduction des risques ; <b>MDO catégorie 1</b> (déclaration anonymisée) ; prise en charge gratuite en <b>centre de référence</b> (Algérie).</li>
</ul></div></div>
