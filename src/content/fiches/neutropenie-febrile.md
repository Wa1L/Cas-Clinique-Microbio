<div class="box bl"><div class="bt">Définitions et stratification du risque</div><div class="bb">
<p><span class="h">Neutropénie</span> : PNN &lt; 500/mm³, ou &lt; 1000/mm³ avec chute attendue &lt; 500 en 48 h ; <b>profonde</b> si &lt; 100/mm³.</p>
<p><span class="h">Fièvre</span> (IDSA) : T° orale ≥ 38,3 °C une fois, ou ≥ 38,0 °C pendant ≥ 1 h.</p>
<table class="mt">
  <tr><th>Critère</th><th>Bas risque</th><th>Haut risque</th></tr>
  <tr><td>Durée aplasie</td><td>≤ 7 j</td><td>&gt; 7 j (LA, allogreffe)</td></tr>
  <tr><td>Profondeur</td><td>PNN 100–500/mm³</td><td>PNN ≤ 100/mm³</td></tr>
  <tr><td>Score MASCC</td><td>≥ 21</td><td>&lt; 21</td></tr>
  <tr><td>Score CISNE*</td><td>0</td><td>≥ 1 (interm./haut)</td></tr>
  <tr><td>Terrain</td><td>Tumeur solide</td><td>Comorbidités, mucite, instabilité</td></tr>
</table>
<p>*CISNE : tumeur solide <b>apparemment stable</b> ; complète le MASCC qui peut sous-estimer le risque.</p>
</div></div>

<div class="box rd"><div class="bt">Physiopathologie et portes d'entrée</div><div class="bb"><ul>
<li><b>Mucite</b> chimio-induite → translocation digestive (BGN, entérocoques, Candida) ; muqueuse buccale → streptocoques oraux.</li>
<li><b>KTC</b> → biofilm : SCN, S. aureus, Candida, BGN non fermentants.</li>
<li><b>Flore endogène</b> = principale source ; <b>colonisation</b> préalable (BLSE, EPC, Candida) prédit l'agent.</li>
<li>Absence de PNN → <span class="r">pas de pus</span> : pneumonie à RX normale, ECBU sans leucocyturie, cellulite discrète.</li>
<li>Facteurs associés : corticoïdes, lymphopénie (→ CMV, <i>Pneumocystis</i>), analogues des purines.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Prophylaxies qui modifient l'écologie</div><div class="bb"><ul>
<li><b>Fluoroquinolones</b> → BGN résistants, ↑ streptocoques oraux, ↑ <i>C. difficile</i> ; à réserver aux aplasies prolongées à haut risque si résistance locale faible.</li>
<li><b>Fluconazole</b> → <i>Nakaseomyces glabratus</i> (ex-<i>C. glabrata</i>), <i>Pichia kudriavzevii</i> (ex-<i>C. krusei</i>) ; <b>posaconazole</b> → moisissures émergentes (Mucorales).</li>
<li><b>Cotrimoxazole</b> → prévient <i>Pneumocystis</i> ; <b>aciclovir/valaciclovir</b> → HSV/VZV.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic bactériologique</div><div class="bb">
<table class="mt">
  <tr><th>Prélèvement</th><th>Règle / interprétation</th></tr>
  <tr><td>Hémocultures</td><td>≥ 2 paires avant ATB (KTC + périph., 40 mL au total chez l'adulte) ; répéter si fièvre persiste (pas en routine quotidienne au-delà)</td></tr>
  <tr><td>KTC</td><td>Flacon KTC positif ≥ 2 h <b>avant</b> le périph. (DDP) → infection liée ; culture du KT si retiré</td></tr>
  <tr><td>SCN</td><td><span class="r">1 seule hémoculture = contaminant probable</span> ; ≥ 2 positives = infection</td></tr>
  <tr><td>ECBU</td><td>Uroculture significative même <b>sans leucocyturie</b></td></tr>
  <tr><td>Selles</td><td>GDH + toxines <i>Clostridioides difficile</i> si diarrhée</td></tr>
</table>
<p><span class="h">Biomarqueurs</span> : CRP, PCT → valeur limitée, ne retardent jamais l'ATB. <span class="r">Piège</span> : CRS après CAR-T / bispécifiques → fièvre + CRP/PCT ↑ sans infection.</p>
</div></div>

<div class="box db"><div class="bt">Diagnostic mycologique (IFI)</div><div class="bb"><ul>
<li><b>Galactomannane</b> (Aspergillus) : dépistage sérique bi-hebdomadaire si haut risque sans prophylaxie anti-moisissures ; LBA plus sensible.</li>
<li><span class="r">GM faussement négatif</span> sous prophylaxie active (posaconazole…) ; faux + : nutrition parentérale / solutés à gluconate, mucite sévère (translocation alimentaire), réactions croisées (<i>Fusarium</i>, <i>Histoplasma</i>, <i>Talaromyces</i>).</li>
<li><b>β-D-glucane</b> : pan-fongique (Candida, Aspergillus, <i>Pneumocystis</i>) mais <span class="r">négatif pour Mucorales et Cryptococcus</span> ; faux + : IgIV, albumine, dialyse sur cellulose.</li>
<li><b>TDM thorax</b> : <b>signe du halo</b> (précoce, Aspergillus) ; croissant gazeux = tardif (sortie d'aplasie) ; <b>halo inversé</b> → <span class="r">mucormycose</span>.</li>
<li>Hémocultures : Candida + ; <span class="r">Aspergillus quasi jamais en hémoculture</span> (Fusarium : oui).</li>
</ul></div></div>

<div class="box dr"><div class="bt">Résistances à rechercher</div><div class="bb"><ul>
<li><b>Entérobactéries BLSE / EPC</b>, <i>P. aeruginosa</i> MDR, <b>SARM</b>, <b>ERV</b> → adapter le probabiliste à l'écologie locale.</li>
<li><b>Écouvillon rectal</b> = dépistage systématique (admission, puis hebdo), pas un prélèvement de la fièvre ; il guide le probabiliste (ECIL) : stable non colonisé → <b>escalade</b> (C3G/C4G antipyo. ou pipé-tazo) ; instable ou colonisé BLSE → <b>désescalade</b> (carbapénème d'emblée).</li>
<li><i>S. maltophilia</i> : résistance naturelle aux carbapénèmes ; <i>N. glabratus</i> / <i>P. kudriavzevii</i> : azolés.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li>NF = <b>urgence</b> : hémocultures puis ATB dans l'heure ; ne jamais attendre les résultats.</li>
<li>BGN = mortalité précoce ; cocci Gram + = plus fréquents (KTC) ; <b>champignons après J7–J10</b>.</li>
<li>Signes atténués sans PNN : <span class="r">ECBU sans leucocyturie ≠ ECBU négatif</span>.</li>
<li>Fièvre persistante &gt; 4–7 j sous ATB → <b>Aspergillus</b> : TDM + GM/LBA.</li>
</ul></div></div>
