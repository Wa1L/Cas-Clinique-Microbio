<div class="box br"><div class="bt">Contexte / Physiopathologie</div><div class="bb"><ul>
<li><span class="h">Principe</span> : déficit de l'immunité <b>cellulaire T</b> (CD4, CD8) et de l'IFN → <b>réactivation</b> de virus latents plutôt que primo-infection.</li>
<li><span class="h">Latence</span> : HSV/VZV = ganglions sensitifs ; CMV/EBV/HHV-6 = cellules lymphoïdes-monocytaires ; JCV = rein, moelle osseuse, tissu lymphoïde.</li>
<li><span class="h">Déficit humoral</span> (XLA, anti-CD20) → entérovirus ; <span class="h">déficit T</span> → herpèsvirus, JCV.</li>
</ul></div></div>

<div class="box or"><div class="bt">Clinique : atypique</div><div class="bb"><ul>
<li>Triade fièvre-céphalées-confusion <span class="r">souvent incomplète</span> ; début subaigu, évolution trompeuse.</li>
<li>Signes focaux, crises, troubles cognitifs ou de vigilance ; myélite, radiculite (CMV, VZV).</li>
<li>Co-infections et causes non virales fréquentes.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Mimics non viraux à éliminer</div><div class="bb"><ul>
<li>Toxoplasmose, cryptococcose, tuberculose (tuberculome), <i>Listeria</i>, lymphome.</li>
<li><span class="r">PRES</span> sous tacrolimus/ciclosporine ; toxicité médicamenteuse ou post-chimiothérapie.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Prévention</div><div class="bb"><ul>
<li>Greffe : prophylaxie CMV (valganciclovir ; létermovir en CSH) ou surveillance PCR sanguine CMV/EBV avec traitement préemptif.</li>
<li>VIH : TARV précoce ; vaccin zona recombinant chez l'immunodéprimé ; vaccins vivants contre-indiqués si déficit profond.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box db"><div class="bt">Démarche diagnostique</div><div class="bb"><ul>
<li><b>IRM</b> (FLAIR, DWI, injectée) avant ou parallèlement à la <b>PL</b> si déficit focal ou trouble de conscience.</li>
<li><b>LCR</b> : pléocytose faible, voire absente chez l'immunodéprimé ; protéinorachie souvent ↑. Un LCR normal n'exclut rien.</li>
<li><b>PCR LCR ciblée</b> : HSV, VZV, CMV, EBV, HHV-6, JCV, entérovirus ; panel multiplex pratique mais sensibilité imparfaite.</li>
<li><b>Sérologie sérique</b> peu fiable (réponse anticorps altérée) ; anticorps intrathécaux (VZV) utiles pour la vasculopathie.</li>
<li>Étiologie non établie : <b>métagénomique</b> ; <b>biopsie cérébrale</b> si lésion focale accessible.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Pièges d'interprétation des PCR</div><div class="bb"><ul>
<li><span class="r">PCR HSV négative précoce</span> (&lt; 72 h) : répéter si suspicion forte, ne pas arrêter l'aciclovir.</li>
<li><span class="r">PCR JCV négative n'exclut pas la LEMP</span> : confronter à l'IRM, répéter, biopsie si besoin.</li>
<li><span class="r">HHV-6 : ciHHV-6</span> (génome intégré, 1 copie/cellule) → PCR sang total très élevée (≈ 10<sup>6</sup> copies/mL ; ratio ADN HHV-6/ADN cellulaire ≈ 1) = <b>intégration, pas réactivation</b>. Confirmer (cheveux/ongles) ; en cas d'encéphalite : IRM limbique ± ARNm viral.</li>
<li>CMV, EBV, HHV-6 dans le LCR : réactivation possible sans causalité → corréler clinique + imagerie.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">Suspicion d'encéphalite = aciclovir IV d'emblée</span>, sans attendre la PCR.</li>
<li>Immunodéprimé : <b>clinique atypique, LCR pauvre</b> ; réactivation &gt; primo-infection.</li>
<li><b>LEMP</b> : JCV, apyrétique, sans effet de masse ; pas d'antiviral → restaurer l'immunité.</li>
<li><b>CMV</b> si CD4 &lt; 50 ; <b>HHV-6</b> limbique post-CSH ; toujours éliminer toxo/crypto.</li>
</ul></div></div>
