<div class="box br"><div class="bt">Enjeux pour le laboratoire</div><div class="bb"><ul>
<li>Infections = l'une des 1<sup>res</sup> causes de morbi-mortalité et de <b>perte du greffon</b>.</li>
<li>Signes atténués (corticoïdes, anticalcineurines) → <b>fièvre parfois absente</b>, tableaux atypiques.</li>
<li><span class="r">Réponse humorale altérée → sérologie peu contributive après greffe</span> : privilégier le <b>diagnostic direct</b> (PCR quantitative, Ag, culture).</li>
<li>Dialogue clinicien–biologiste : préciser « transplanté » sur la demande (milieux, durée d'incubation, recherches ciblées).</li>
</ul></div></div>

<div class="box or"><div class="bt">Diagnostic des infections post-greffe</div><div class="bb"><ul>
<li><span class="h">IU</span> : 1<sup>re</sup> infection bactérienne ; pyélonéphrite du greffon → ECBU + hémocultures ; BMR fréquentes. <span class="r">Bactériurie asymptomatique : ni dépistage ni traitement après M1–M2 (après retrait de la JJ).</span></li>
<li><span class="h">Pneumopathie</span> : LBA → PCR <i>P. jirovecii</i>, galactomannane, culture ; β-D-glucane sérique ; Ag urinaire <i>Legionella</i> ; PCR multiplex respiratoire.</li>
<li><span class="h">SNC</span> : <i>Listeria</i> (culture LCR), Ag cryptococcique (LCR, sérum), PCR JCPyV.</li>
<li><span class="h">Digestif</span> : <i>C. difficile</i> ; norovirus chronique ; CMV : <span class="r">PCR sang négative ou faible possible dans la colite</span> → biopsie (histologie, IHC, PCR).</li>
<li><i>Nocardia</i> : <b>prévenir le labo</b> → incubation prolongée.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Résistances et interactions</div><div class="bb"><ul>
<li><b>CMV résistant</b> : charge ↑ après ≥ 2 sem. de traitement bien conduit → génotypage <b>UL97</b> (ganciclovir), <b>UL54</b> (ganciclovir, foscarnet, cidofovir), <b>UL56</b> (létermovir), <b>UL27</b> (maribavir ; aussi mutations UL97). Maribavir : référence des CMV réfractaires/résistants.</li>
<li><b>BMR</b> (EBLSE, EPC) : ATBg + CMI, posologie adaptée au DFG.</li>
<li><span class="r">Rifampicine ↓ tacrolimus/ciclosporine → risque de rejet</span> ; macrolides, azolés, <b>létermovir</b>, ritonavir (Paxlovid®) ↑ les taux (inhibition CYP3A4) ; aminosides, vancomycine : néphrotoxicité.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Prévention</div><div class="bb"><ul>
<li>Cotrimoxazole ≥ 6 mois ; prophylaxie CMV selon D/R (cf. schéma).</li>
<li><span class="r">Vaccins vivants (ROR, varicelle) contre-indiqués à vie sous anti-rejet</span> ; recommandés : grippe annuelle, COVID-19, pneumocoque (VPC20/VPC21), zona recombinant (Shingrix®), VHB.</li>
<li>Dépistage et isolement des BMR ; hygiène des mains.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><b>CMV D+/R–</b> = risque maximal (primo-infection) ; R+ = réactivation.</li>
<li><b>BKPyV</b> : &gt; 10³ c/mL &gt; 2 sem. = <i>probable</i> ; &gt; 10⁴ = <i>présomptive</i> ; <i>prouvée</i> = biopsie (IHC Ag T SV40) → ↓ IS sans attendre la biopsie.</li>
<li><span class="r">VHE chronique : sérologie faussement négative → PCR</span>.</li>
<li>Liquide de conservation : <i>Candida</i>, <i>P. aeruginosa</i> ou entérobactérie BMR → risque d'artérite / rupture anastomotique : <b>alerte immédiate</b>.</li>
</ul></div></div>
