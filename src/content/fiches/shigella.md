<div class="box bl"><div class="bt">Caractères bactériologiques</div><div class="bb">
<p><span class="h">Morphologie</span> : bacilles <b>Gram –</b> (2–3 × 0,5 µm), <b>immobiles</b> (sans flagelle ⇒ <b>pas d'antigène H</b>), non sporulés, non capsulés ; <span class="r">piège : immobilité = critère clé vs <i>E. coli</i> / <i>Salmonella</i></span>.</p>
<p><span class="h">Exigences</span> : aéro-anaérobie facultatif, non exigeant ; bactérie <span class="r">fragile dans les selles</span> (acidification, dessiccation) mais très résistante à l'acidité gastrique.</p>
<p><span class="h">Culture</span> : 35–37 °C, 18–24 h, aérobiose ; <b>Hektoen / SS / désoxycholate-citrate</b> : colonies <b>lactose –</b>, <b>H₂S –</b> (vertes sur Hektoen, sans centre noir) ; Drigalski/MacConkey : incolores, 1–2 mm, lisses ; <i>S. sonnei</i> : colonies plates, lactose + tardif. <span class="r">Pas de milieu d'enrichissement efficace</span> (≠ Salmonella).</p>
<p><span class="h">Biochimie</span> : oxydase –, catalase + (<i>S. dysenteriae</i> 1 : catalase –), glucose <b>sans gaz</b>, lactose –, <b>LDC –</b>, urée –, citrate –, H₂S –, TDA –, VP –, indole var. (<i>S. flexneri</i>).</p>
<p><span class="h">Antigénie</span> : <b>Ag O uniquement</b> → 4 sérogroupes A–D ; <b>Ag K</b> thermolabile masquant l'agglutination ⇒ <span class="r">chauffer 100 °C / 15–30 min</span> avant sérotypage. Communautés antigéniques avec <i>E. coli</i> (O124…).</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li>Réservoir <b>strictement humain</b> (malade, convalescent, porteur) ; pas de réservoir animal ni hydrique durable.</li>
<li>Transmission <b>féco-orale</b> : mains sales (péril fécal, voie directe ++), eau et aliments souillés, mouches, <b>HSH</b>.</li>
<li><b>Inoculum infectant très faible : 10–100 bactéries</b> ⇒ contagiosité majeure, épidémies en collectivités (crèches, casernes, camps).</li>
<li>Terrain : <b>enfant &lt; 5 ans</b>, malnutrition, promiscuité, péril fécal ; 2<sup>e</sup> cause de décès par diarrhée dans le monde.</li>
<li>Algérie / Maghreb : <i>S. flexneri</i> prédominante, recrudescence estivale ; <span class="r"><i>S. dysenteriae</i> 1 = potentiel épidémique majeur</span>.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>Bactérie entéro-invasive stricte du côlon</b> ; <b>plasmide de virulence pINV 220 kb</b> : <b>SST3</b> (mxi-spa) + effecteurs <b>Ipa A–D</b>.</li>
<li>Traversée des <b>cellules M</b> → apoptose du macrophage (IL-1β) → invasion <b>basolatérale</b> des entérocytes → multiplication intracytoplasmique → <b>motilité actine (IcsA/VirG)</b> → diffusion de cellule à cellule.</li>
<li>Réaction inflammatoire (PNN) → <b>abcès, ulcérations, nécrose muqueuse</b> ⇒ selles glairo-sanglantes. <span class="r">Pas d'invasion profonde ⇒ bactériémie rare</span> (dénutri, VIH, drépanocytaire).</li>
<li><b>Toxine Shiga</b> (<i>S. dysenteriae</i> 1) : inhibition du ribosome 60S (ARNr 28S), cytotoxicité endothéliale ⇒ <span class="r">SHU</span>. Entérotoxines ShET1/2 ⇒ phase diarrhéique aqueuse initiale.</li>
<li>Immunité sérotype-spécifique, locale (IgA), courte ⇒ réinfections.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li>Incubation 1–3 j. <b>Phase 1</b> : diarrhée aqueuse fébrile. <b>Phase 2</b> : <b>syndrome dysentérique</b> = selles afécales <b>glairo-sanglantes</b>, nombreuses, + <b>épreintes, ténesme</b>, fièvre 38–39 °C.</li>
<li><b>Enfant</b> : <span class="r">convulsions</span>, déshydratation, prolapsus rectal, dénutrition.</li>
<li>Compl. : <span class="r">SHU (Stx) : anémie hémolytique + thrombopénie + IRA</span> ; colectasie, perforation, septicémie du dénutri.</li>
<li>Tardif : <b>arthrite réactionnelle</b> (Fiessinger-Leroy-Reiter, HLA-B27).</li>
<li><i>S. sonnei</i> : souvent diarrhée banale non dysentérique ⇒ <span class="r">sous-diagnostic</span>.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Coproculture</b> (ou écouvillon rectal) : <span class="r">selles fraîches &lt; 2 h</span> (fragile, acidification) sinon <b>Cary-Blair</b> ; prélever les <b>glaires sanglantes</b>, avant ATB. <span class="r">Pas de sérologie ; hémoculture inutile (sauf dénutri/VIH)</span>.</li>
<li><b>Direct</b> : PNN altérés + hématies ; Gram sans intérêt.</li>
<li><b>Isolement</b> : Drigalski/MacConkey + Hektoen ou SS ; colonies lactose – → Kligler : <b>glucose + sans gaz, lactose –, H₂S –, urée –</b>.</li>
<li><b>Identification</b> : galerie ; <span class="r">MALDI-TOF ne sépare pas <i>Shigella</i> de <i>E. coli</i></span> ⇒ biochimie + <b>agglutination O polyvalents A–D</b> puis monovalents.</li>
<li>Différenciation :

<div class="box dr"><div class="bt">Résistance aux antibiotiques</div><div class="bb"><ul>
<li><b>Naturelle</b> (<b>groupe 1</b> CA-SFM, comme <i>E. coli</i> ; ≠ groupe 0 = <i>Salmonella</i>, <i>P. mirabilis</i>) : péni G, oxacilline, macrolides, lincosamides, glycopeptides, ac. fusidique ; <b>céphalosporinase chromosomique non inductible, bas niveau</b> ⇒ sauvage : ampicilline S.</li>
<li><b>Acquise</b> : <b>multirésistance fréquente</b> — ampicilline (<b>TEM-1</b>/OXA-1), <b>SXT</b> (<i>sul</i>, <i>dfrA</i>), tétracyclines, chloramphénicol ; <b>BLSE CTX-M-15</b> en progression (image de synergie, C3G R) ; quinolones : <b><i>gyrA</i> + <i>parC</i></b> (<i>S. sonnei</i> ++) ; <b>azithromycine</b> : <i>mphA</i>, <i>ermB</i> ; <span class="r">pas de S/R clinique : ECOFF (CMI/diamètre) seulement — valeurs à vérifier</span>.</li>
<li>Support : plasmides / <b>intégrons de classe 1</b> (<i>S. dysenteriae</i> 1 épidémique multi-R).</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Toujours traiter</b> (≠ salmonelloses mineures) : ↓ durée, ↓ contagiosité et portage.</li>
<li><b>Adulte</b> : <b>ciprofloxacine 500 mg × 2/j, 3 j</b> PO ; alternative <b>azithromycine 500 mg J1 puis 250 mg × 4 j</b>.</li>
<li><b>Enfant</b> : <b>azithromycine 12 mg/kg J1 puis 6 mg/kg/j × 4 j</b> ; forme sévère ou souche R : <b>ceftriaxone 50 mg/kg/j IV, 3–5 j</b>.</li>
<li><b>SRO</b> ± zinc (enfant 20 mg/j, 10–14 j) ; renutrition précoce.</li>
<li><span class="r">Proscrits : ralentisseurs du transit (lopéramide) ⇒ mégacôlon toxique</span>. ATB <b>indiquée même si Stx+</b> (↓ toxine fécale) ; <span class="r">≠ STEC/EHEC : ATB contre-indiquée (↑ risque de SHU)</span>.</li>
<li><b>Vaccin</b> : <span class="r">aucun ; absent du PEV algérien</span> (candidats conjugués en essai).</li>
<li><b>Prévention</b> : hygiène des mains, eau potable, lutte anti-mouches ; éviction collectivités / manipulateurs d'aliments jusqu'à <b>2 coprocultures négatives</b> ; <span class="r">pas d'antibioprophylaxie de l'entourage</span> (dépistage des symptomatiques). <b>MDO</b> (dysenterie bacillaire ; TIAC si groupée) + enquête.</li>
</ul></div></div>
