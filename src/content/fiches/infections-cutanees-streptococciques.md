<div class="box br"><div class="bt">Contexte / épidémiologie</div><div class="bb">
<p><span class="h">Agent</span> : <i>Streptococcus pyogenes</i> (SGA) ; réservoir strictement humain (gorge, peau). <span class="h">Porte d'entrée</span> : excoriation, piqûre, plaie, intertrigo, ulcère.</p>
<p><span class="h">Impétigo</span> : enfant &lt; 10 ans, été, climat chaud/humide, promiscuité ; très contagieux (contact direct, autoinoculation). <i>S. aureus</i> prédomine dans les pays développés ; SGA plus fréquent en zones tropicales, souvent <b>associés</b>.</p>
<p><span class="h">emm-typage</span> : pattern D = tropisme cutané ; A–C = gorge ; E = généraliste.</p>
</div></div>

<div class="box or"><div class="bt">Clinique</div><div class="bb">
<table class="mt">
  <tr><th>Forme</th><th>Aspect</th><th>Terrain / piège</th></tr>
  <tr><td>Impétigo</td><td>vésicule → croûtes mélicériques (jaune miel), péri-orificiel</td><td>enfant ; <i>bulleux</i> = <i>S. aureus</i> (exfoliatine)</td></tr>
  <tr><td>Ecthyma</td><td>ulcération creusante, croûte noirâtre, cicatrice</td><td>jambes ; <b>forme grave</b></td></tr>
  <tr><td>DHB non nécrosante</td><td>placard rouge, chaud, douloureux, bien limité, fièvre</td><td>adulte ; OMI, lymphœdème</td></tr>
  <tr><td>DHB nécrosante</td><td>douleur disproportionnée, bulles hémorragiques, nécrose, choc</td><td class="r">urgence chirurgicale</td></tr>
</table>
<p><span class="h">Post-streptococcique</span> : <b>GNA post-streptococcique</b> après impétigo comme après angine (latence ≈ 3 sem après impétigo, 1–2 sem après angine) ; <span class="r">RAA : post-angine, pas post-impétigo</span>.</p>
</div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>DHB non nécrosante</b> : diagnostic <b>clinique</b> ; <span class="r">prélèvement cutané superficiel non recommandé</span>.</li>
<li><b>Impétigo</b> : pas de prélèvement si peu étendu et 1ʳᵉ poussée ; sinon pus / liquide de bulle → culture + ATBg.</li>
<li><b>Bactério</b> : Gram → cocci Gram+ en <b>chaînes</b> ; gélose au sang → colonies <b>β-hémolytiques</b> ; catalase – (≠ <i>S. aureus</i> : grappes, catalase +, coagulase +) ; <b>groupage Lancefield A</b> (latex) ; PYR + ; bacitracine S.</li>
<li><b>Forme sévère / nécrosante</b> : hémocultures, prélèvements chirurgicaux profonds ; diagnostic <b>chirurgical</b>, ne pas attendre.</li>
<li><b>Sérologie rétrospective</b> (GNA) : ASLO souvent faible après infection cutanée → <b>anti-DNase B</b> plus fiable.</li>
</ul></div></div>

<div class="box bl"><div class="bt">Diagnostic différentiel : SGA vs <i>S. aureus</i></div><div class="bb">

  <tr><th>Critère</th><th>SGA</th><th><i>S. aureus</i></th></tr>

<div class="box gr"><div class="bt">Traitement antibiotique (HAS / SPILF 2019, MAJ 2021–2024)</div><div class="bb">
<table class="mt">
  <tr><th>Forme</th><th>Traitement</th><th class="c">Durée</th></tr>
  <tr><td>Impétigo localisé (&lt; 2 % SC, &lt; 6 sites, pas d'extension rapide)</td><td>toilette eau + savon ; <b>mupirocine 2 %</b> locale 2–3×/j ; pas d'ATB général</td><td class="c">5 j</td></tr>
  <tr><td>Impétigo grave / ecthyma, adulte</td><td><b>pristinamycine</b> 1 g ×3/j PO ; prélèvement avant, réévaluer selon ATBg</td><td class="c">7 j</td></tr>
  <tr><td>Impétigo grave, enfant</td><td>amoxicilline-ac. clavulanique 80 mg/kg/j (max 3 g/j) ou céfalexine 50 mg/kg/j (max 4 g/j)</td><td class="c">7 j</td></tr>
  <tr><td>DHB non nécrosante, adulte</td><td><b>amoxicilline</b> 50 mg/kg/j en 3 prises (max 6 g/j) PO ; allergie : pristinamycine 1 g ×3/j ou clindamycine 600 mg ×3/j</td><td class="c">7 j</td></tr>
  <tr><td>DHB / fasciite nécrosante</td><td>hospitalisation en urgence : <b>chirurgie</b> + ATB IV large spectre + clindamycine (anti-toxinique)</td><td class="c">—</td></tr>
</table>
<ul>
<li><span class="r">Jamais d'ATB local associé à un ATB général</span> ; mupirocine préférée à l'acide fusidique (le préserver).</li>
<li>Impétigo : ongles courts, éviction scolaire 3 j après début du traitement si lésions non protégeables.</li>
<li>DHB : traiter porte d'entrée, compression si lymphœdème ; régression cutanée lente (2–3 sem) → <b>ne pas prolonger</b> l'ATB ; <span class="r">pas d'AINS ni corticoïdes</span> ; récidives fréquentes → antibioprophylaxie (pénicilline V / benzathine pénicilline G).</li>
</ul>
</div></div>

<div class="box dr"><div class="bt">Résistance / limites</div><div class="bb"><ul>
<li>SGA : <b>pénicilline = référence</b>, aucune résistance clinique confirmée (CLSI : S ≤ 0,12 µg/mL ou ≥ 24 mm) ; rares isolats à sensibilité diminuée (mutations <i>pbp2x</i>).</li>
<li><b>Macrolides / lincosamides</b> : résistance variable (<b>erm</b> : MLS<sub>B</sub> constitutif ou inductible ; <b>mef</b> : macrolides seuls) → <b>D-test</b> : érythromycine 15 µg + clindamycine 2 µg, <b>12 mm</b> bord à bord (15–26 mm chez les staphylocoques).</li>
<li>ATBg (CLSI M100) : MHA + 5 % sang de mouton (diffusion) ou CAMHB + sang de cheval lysé (CMI), 0,5 McFarland, 35 ± 2 °C, 5 % CO₂, 20–24 h ; CQ : <i>S. pneumoniae</i> ATCC 49619. <span class="r">Cyclines inadaptées ; cotrimoxazole non testable sur gélose au sang (thymidine)</span>.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">Durées courtes : impétigo 5 j (local) ou 7 j (général) ; DHB non nécrosante 7 j</span> ; « érysipèle » n'est plus employé.</li>
<li><b>SpeA / SpeC</b> = superantigènes (scarlatine, SCTS) ; <b>SLO</b> → ASLO ; après impétigo, doser l'<b>anti-DNase B</b>.</li>
<li><span class="r">Douleur disproportionnée + bulles hémorragiques = DHB nécrosante → chirurgie en urgence.</span></li>
<li><span class="r">GNA possible après impétigo, RAA non</span> ; SGA toujours sensible aux β-lactamines.</li>
</ul></div></div>
