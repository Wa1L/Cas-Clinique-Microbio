<div class="box bl"><div class="bt">Prélèvement et pré-analytique</div><div class="bb"><ul>
<li>Écouvillon : amygdales + pharynx postérieur, <span class="r">sans toucher langue / luette</span> (flore commensale).</li>
<li><b>Avant</b> toute antibiothérapie ; milieu de transport si délai.</li>
<li>Renseignements : clinique, ATCD de RAA, statut vaccinal (diphtérie), voyage.</li>
<li>Gonocoque : <b>TAAN / PCR</b> de référence ; culture (milieu sélectif, CO₂) pour l'ATBg.</li>
</ul></div></div>

<div class="box bl"><div class="bt">Principes des techniques</div><div class="bb"><ul>
<li><b>TDR</b> : immunochromatographie, anticorps anti-antigène du groupe A de la paroi, lecture visuelle.</li>
<li><b>Culture</b> : référence pour tous les agents bactériens ; permet identification (Lancefield, MALDI-TOF) et ATBg.</li>
<li><b>RT-PCR</b> : amplification d'acides nucléiques (ARN viraux après rétro-transcription) ; rapide, sensible, plusieurs cibles à la fois.</li>
<li><b>Sérologie</b> : diagnostic indirect (EBV, ASLO) ; interpréter sur un ou deux prélèvements.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Pièges d'interprétation</div><div class="bb"><ul>
<li>Flore pharyngée normale (streptocoques α-hémolytiques, <i>Neisseria</i> non pathogènes) : <span class="r">ne pas les rendre comme pathogènes</span>.</li>
<li>Portage pharyngé de pneumocoque / <i>H. influenzae</i> / <i>M. catarrhalis</i> : <b>sans valeur</b> à l'écouvillon (sinusite, otite).</li>
<li>Portage asymptomatique de SGA possible : culture + ≠ forcément infection.</li>
<li><b>ASLO / ASDOR</b> : rétrospectifs, pour RAA / GNA, <span class="r">pas pour l'angine aiguë</span>.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box db"><div class="bt">Autres bactéries à connaître</div><div class="bb"><ul>
<li><b>F. necrophorum</b> : anaérobie strict ; angine puis <b>syndrome de Lemierre</b> (thrombophlébite jugulaire) → hémocultures anaérobies.</li>
<li><b>A. haemolyticum</b> : adolescent, angine + éruption scarlatiniforme ; à évoquer si SGA négatif.</li>
<li><b>Streptocoques C/G</b> : culture seule (le TDR ne détecte que le groupe A).</li>
</ul></div></div>

<div class="box db"><div class="bt">Mononucléose infectieuse (EBV)</div><div class="bb"><ul>
<li>NFS / frottis : <b>syndrome mononucléosique</b> (lymphocytes hyperbasophiles).</li>
<li>MNI-test (anticorps hétérophiles) : rapide, moins sensible chez le jeune enfant.</li>
<li>Sérologie : primo-infection = <b>VCA IgM +, EBNA –</b> ; EBNA + = infection ancienne.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Conduite selon le résultat</div><div class="bb"><ul>
<li><b>SGA</b> : β-lactamine (prévention du RAA).</li>
<li><b>Diphtérie</b> : sérothérapie antitoxinique + antibiotique, isolement, déclaration, enquête autour du cas ; prévention : anatoxine (PEV).</li>
<li><b>Virus</b> : pas d'antibiotique ; antiviral si grippe sévère / à risque.</li>
</ul></div></div>

<div class="box or"><div class="bt">Quand demander un examen ?</div><div class="bb"><ul>
<li><b>Angine</b> : McIsaac ≥ 2 → TDR ; pas de prélèvement si score bas (probable virose). Enfant 3–14 ans : TDR dès que l'angine est évoquée selon certaines recommandations ; <b>&lt; 3 ans</b> : en général ni TDR ni prélèvement (SGA / RAA exceptionnels).</li>
<li><b>Suspicion de diphtérie</b> (fausse membrane, non vacciné, séjour en zone d'endémie) : prélèvement immédiat.</li>
<li><b>Syndrome grippal</b> sévère, patient à risque ou contexte épidémique : RT-PCR.</li>
<li><b>Sinusite / otite</b> : seulement si échec, complication ou terrain fragile.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Limites des techniques</div><div class="bb"><ul>
<li><b>TDR</b> : faux négatifs possibles (faible inoculum, mauvais prélèvement) ; ne reconnaît que le groupe A.</li>
<li><b>Culture</b> : résultat en 24–48 h ; <span class="r">négativée par une antibiothérapie préalable</span>.</li>
<li><b>PCR</b> : détecte aussi des virus non infectieux ou un portage → <b>corréler à la clinique</b>.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">Le TDR ne détecte que le SGA</span> : spécificité élevée, sensibilité imparfaite ; strepto C/G et autres agents = culture.</li>
<li>Diphtérie : <span class="r">traiter avant les résultats</span> ; tellurite + <b>Elek / PCR <i>tox</i></b> pour la toxinogénèse.</li>
<li>Sinusite et otite : clinique d'abord ; <b>pas d'écouvillon pharyngé</b> pour chercher le germe.</li>
<li>ASLO : sérologie rétrospective (RAA / GNA), jamais pour l'angine aiguë.</li>
</ul></div></div>
