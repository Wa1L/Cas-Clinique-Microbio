<div class="box br"><div class="bt">Contexte</div><div class="bb"><ul>
<li><b>VHC</b> : <i>Flaviviridae</i>, genre <i>Hepacivirus</i> ; ARN(+) monocaténaire ≈ 9,6 kb ; <b>8 génotypes</b>. Réplication cytoplasmique, <b>sans intégration</b> ni réservoir nucléaire → <b>guérison possible</b> (≠ VHB, VIH).</li>
<li>Objectif OMS : élimination des hépatites virales d'ici 2030 ; <span class="r">pas de vaccin</span>.</li>
</ul></div></div>

<div class="box bl"><div class="bt">Marqueurs virologiques et techniques</div><div class="bb">
<table class="mt">
  <tr><th>Marqueur</th><th>Intérêt dans le suivi</th><th>Limite / piège</th></tr>
  <tr><td>ARN VHC quantitatif (RT-PCR temps réel)</td><td><b>Référence</b> : virémie initiale, RVS, échec</td><td>Exprimé en <b>UI/mL</b> (standard OMS) ; même trousse pour comparer</td></tr>
  <tr><td>Ag core VHC (immunoessai)</td><td>Alternative moins coûteuse : virémie, RVS</td><td><span class="r">Faux négatifs si faible virémie</span></td></tr>
  <tr><td>Anti-VHC (EIA)</td><td>Dépistage uniquement</td><td><span class="r">Reste + après guérison : aucune valeur de suivi</span></td></tr>
  <tr><td>Génotypage / sous-typage (séquençage NS5B ou génome entier)</td><td>AAD non pangénotypique ; rechute vs réinfection (phylogénie)</td><td><span class="r">5′NC seule insuffisante</span> pour le sous-type</td></tr>
  <tr><td>Séquençage RAS (NS5A, NS3, NS5B)</td><td>Échec d'AAD ; <b>G3 + cirrhose compensée</b> avant SOF/VEL (NS5A <b>Y93H</b> → + RBV ou G/P)</td><td>Non systématique hors ces cas</td></tr>
</table>
<p><span class="h">Lecture d'un résultat</span> : « cible non détectée » (TND) ; « détectée &lt; LIQ » (non quantifiable) ; valeur quantifiée. Variation significative si <b>&gt;&nbsp;0,5&nbsp;log</b>.</p>
<p><span class="h">Pré-analytique</span> : sérum ou plasma EDTA, séparation rapide (ARN labile), congélation si analyse différée. <span class="h">Point-of-care</span> (ARN sur cartouche, sang capillaire) : test-and-treat décentralisé.</p>
</div></div>

<div class="box rd"><div class="bt">Définitions des réponses virologiques</div><div class="bb">
<table class="mt">
  <tr><th>Terme</th><th>Définition</th></tr>
  <tr><td>RVS12</td><td>ARN indétectable ≥ 12 sem après FdT = <b>guérison</b> (rechute tardive exceptionnelle)</td></tr>
  <tr><td>Échappement (breakthrough)</td><td>Sous ttt : ↑ ≥ 1 log/nadir, ou ARN redevenu détectable après indétectabilité</td></tr>
  <tr><td>Rechute (relapse)</td><td>ARN indétectable en FdT puis redevenu détectable</td></tr>
  <tr><td>Virémie persistante</td><td>ARN jamais indétectable sous ttt (rare sous AAD)</td></tr>
</table>
<p><span class="h">Ère PEG-IFN/RBV</span> (termes encore demandés) : RVR = ARN indétectable à S4 ; RVP = baisse ≥ 2 log à S12 ; répondeur nul = &lt; 2 log à S12 → <b>règles d'arrêt</b>. <span class="r">Ces règles ne s'appliquent pas aux AAD.</span></p>

<div class="box db"><div class="bt">Surveillance sous AAD : ce qui compte</div><div class="bb"><ul>
<li><span class="h">Classes d'AAD</span> : inh. NS3/4A protéase (-<i>prévir</i>), inh. NS5A (-<i>asvir</i>), inh. polymérase NS5B (-<i>buvir</i>) ; RVS &gt; 95 %.</li>
<li><span class="h">Observance</span> = 1<sup>er</sup> déterminant de succès → ARN si doute.</li>
<li><span class="h">ARN détectable &lt; LIQ en FdT</span> : n'est pas un échec ; <b>conclure sur la RVS12</b>.</li>
<li><span class="h">Tolérance</span> : ALAT &lt; 10× mais ictère, ↑ bilirubine, PAL ou INR → arrêt. Ribavirine : Hb, contraception pendant et 6 mois après.</li>
<li><span class="r">Interactions</span> : IPP/anti-acides (↓ absorption anti-NS5A), inducteurs enzymatiques ; <span class="r">sofosbuvir + amiodarone → bradycardie</span>.</li>
<li><span class="h">Clairance virale</span> : <b>hypoglycémies</b> chez le diabétique (adapter insuline/sulfamides) ; <b>INR à surveiller sous AVK</b>.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Échec thérapeutique et réactivation du VHB</div><div class="bb"><ul>
<li><span class="h">Échec</span> : vérifier observance ; distinguer <b>rechute</b> (même souche) et <b>réinfection</b> (génotype/sous-type différent, analyse phylogénétique).</li>
<li><span class="h">RAS</span> : NS5A <b>persistent des années</b> ; NS3 disparaissent en quelques mois.</li>
<li><span class="h">Retraitement</span> après échec d'AAD : <b>SOF/VEL/VOX 12 sem</b>. <span class="r">Inh. NS3/4A (-prévir) contre-indiqués si cirrhose décompensée (Child B/C)</span> → <b>SOF/VEL + RBV 24 sem</b>.</li>
<li><span class="h">Réactivation VHB</span> : AAD sans activité anti-VHB → <span class="r">réactivation possible, parfois fulminante</span>. AgHBs+ : ADN VHB, analogue (prophylaxie ou traitement). AgHBs– / anti-HBc+ : ALAT ; ADN VHB si ↑ ALAT.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Interprétation du contrôle à FdT + 12 sem</div><div class="bb">
<table class="mt">
  <tr><th>Résultat</th><th>Conclusion → conduite</th></tr>
  <tr><td>ARN indétectable</td><td><b>RVS12 = guérison</b> → arrêt du suivi virologique (sauf risque de réinfection ou cirrhose)</td></tr>
  <tr><td>ARN détectable</td><td>Échec → <b>contrôler</b> ; rechute vs réinfection (génotype) ; RAS si retraitement</td></tr>
  <tr><td>Ag&nbsp;core&nbsp;+ ARN&nbsp;–</td><td>Discordance rare → <b>l'ARN prime</b></td></tr>
</table>
</div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><b>Critère de guérison = RVS12</b> (ARN indétectable ≥ 12 sem après FdT), pas la négativation en cours de traitement.</li>
<li><span class="r">Anti-VHC ne se négative pas</span> : la guérison et la réinfection se jugent sur l'<b>ARN</b> (ou Ag core) ; pas d'immunité protectrice.</li>
<li><span class="r">Ne pas changer de trousse</span> entre deux mesures de charge virale ; Ag core négatif + forte suspicion → ARN.</li>
<li>Toujours dépister le <b>VHB</b> (AgHBs, anti-HBc) avant AAD.</li>
</ul></div></div>
