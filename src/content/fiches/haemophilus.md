<div class="box bl"><div class="bt">Caractères bactériologiques</div><div class="bb">
<p><span class="h">Morphologie</span> : coccobacilles / petits bacilles <b>Gram –</b> (0,3×1 µm), immobiles, asporulés ; <b>polymorphisme marqué</b> (filaments sous β-lactamine) ; <span class="r">Gram faible</span> ⇒ contre-coloration prolongée ; <b>capsule</b> chez les souches typables (halo à l'encre de Chine), absente chez les NTHi.</p>
<p><span class="h">Exigences</span> : <b>facteur X</b> = hémine (thermostable) ; <b>facteur V</b> = NAD (thermolabile, intra-érythrocytaire). Gélose au sang non chauffée : NAD séquestré ⇒ pas de pousse ; chauffage 80 °C ⇒ <b>gélose chocolat</b>. <b>Satellitisme</b> autour de <i>S. aureus</i> (apport de V) ; disques X, V, XV.</p>
<p><span class="h">Culture</span> : chocolat + supplément polyvitaminique (+ bacitracine pour prélèvements respiratoires) ; 35–37 °C, <b>CO₂ 5–10 %</b>, atmosphère humide ; colonies 1–2 mm grises, translucides, « gouttes de rosée », <b>odeur spermatique / murine</b> ; pas de pousse à 25 ni 42 °C ; lecture 24 et 48 h.</p>
<p><span class="h">Biochimie</span> : <b>oxydase +, catalase +</b> ; <b>test porphyrine (ALA)</b> : positif = X non requis (plus fiable que les disques) ; <i>H. haemolyticus</i> : β-hémolyse (gélose cheval/lapin) ; MALDI-TOF, gènes <i>fucK</i> / <i>hpd</i>.</p>
<p><span class="h">Antigénie</span> : <b>capsule polysaccharidique</b> (6 sérotypes a–f ; <b>Hib = PRP</b>, polyribosylribitol-phosphate) ; <b>LOS</b> (endotoxine sans chaîne O) ; protéines de membrane externe : <b>porine P2</b> (variable, typage), <b>P6</b> (conservée, cible vaccinale NTHi) ; gène <i>bexA</i> (absent = NTHi).</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li>Réservoir <b>strictement humain</b> ; commensal des VAS ; portage NTHi fréquent chez l'enfant, portage Hib devenu exceptionnel sous vaccin.</li>
<li>Transmission interhumaine par <b>gouttelettes de Flügge</b> (collectivités).</li>
<li>Terrain : <b>nourrisson 3 mois–3 ans non vacciné</b> (Hib invasif) ; bronchopathe chronique, sujet âgé, splénectomisé, déficit en complément.</li>
<li>Post-vaccination : sérotypes non b (a, f) et <b>NTHi</b>. <span class="r">Méningite chez un enfant vacciné</span> ⇒ sérotypage (non b / NTHi, ou rare échec vaccinal).</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>Capsule PRP</b> : facteur majeur, anti-phagocytose, bloque la voie alterne du complément. <b>Protéases IgA1</b>. Variation antigénique (P2, LOS).</li>
<li>Adhésines HMW1/2, Hia, pili ; <b>LOS</b> ⇒ ciliostase ; <b>biofilm</b> (oreille, bronches : chronicité, rechutes) ; captation du fer.</li>
<li><b>Voie invasive</b> (capsulées) : rhinopharynx → bactériémie → méninges, articulations, peau. <b>Voie de contiguïté</b> (NTHi) : oreille, sinus, bronches, <b>sans bactériémie</b> (hémoculture utile seulement dans la 1<sup>re</sup>).</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Méningite purulente</b> (3 mois–3 ans) : début brutal, <span class="r">séquelles fréquentes (surdité)</span>.</li>
<li><b>Épiglottite</b> : urgence vitale, enfant penché en avant, bavant ; <span class="r">abaisse-langue proscrit</span>. Arthrite septique, cellulite faciale.</li>
<li>NTHi : <b>OMA</b> (syndrome otite-conjonctivite), sinusite, <b>exacerbation de BPCO</b> (1<sup>re</sup> cause bactérienne), pneumonie du sujet âgé / éthylique.</li>
<li><i>H. ducreyi</i> : <b>chancre mou</b> (ulcération douloureuse à fond sale, adénopathie inguinale fistulisée).</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><span class="r">LCR jamais réfrigéré</span> (bactérie fragile) : température ambiante / étuve ; milieu au plus tard sous 1 h.</li>
<li><b>Direct</b> : Gram (coccobacilles polymorphes, faible) ; latex PRP b seulement si antibiothérapie préalable. <b>Culture</b> : chocolat enrichi ; <b>identification</b> : X/V/XV, porphyrine, MALDI-TOF, PCR (<i>ompP2</i>, <i>hpd</i>) ; <span class="r">aucune cible unique 100 % sensible</span> (≈ 10–15 % de NTHi <i>fucK</i>– : à vérifier).</li>
<li><b>Sérotypage</b> / <i>bexA</i> obligatoire pour toute souche invasive.</li>
<li><b>ATBg</b> (CLSI M100 Tab. 2E : <i>H. influenzae</i> et <i>H. parainfluenzae</i> seulement) : gélose HTM, McFarland 0,5, 35 ± 2 °C, CO₂ 5 %, 16–18 h ; CMI en bouillon HTM, air ambiant, 20–24 h. <b>AMC : CMI seule, pas de disque</b> (S ≤ 2/1, I 4/2, R ≥ 8/4). Contrôles : ATCC 49247 (BLNAR), 49766 ; <i>E. coli</i> ATCC 35218 pour les associations avec inhibiteur.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Méningite / invasives</b> : <b>céfotaxime ou ceftriaxone IV</b> forte dose, sans attendre l'ATBg + <b>dexaméthasone</b> avant ou avec la 1<sup>re</sup> dose (moins de séquelles auditives).</li>
<li><b>Épiglottite</b> : urgence, matériel d'intubation prêt, C3G IV. <b>OMA, sinusite, EA-BPCO : amoxicilline-acide clavulanique</b>. Allergie : C2/C3G orale, azithromycine, FQ (adulte).</li>
<li><b>Chancre mou</b> : azithromycine dose unique ou ceftriaxone IM unique, traiter les partenaires.</li>
<li><b>Vaccin</b> conjugué anti-Hib (PRP-T), Hib seul : pas de vaccin contre non b / NTHi. <b>Pentavalent DTC-HepB-Hib</b> au PEV algérien : 2, 4 et 12 mois ; calendrier révisé par l'arrêté du 28/04/2026 (JO n°36) : hexavalent ? (à vérifier selon ton cours).</li>
<li><b>Prophylaxie de l'entourage</b> d'un cas invasif : <b>rifampicine 20 mg/kg/j</b> (max 600 mg) en 1 prise, 4 jours (<b>10 mg/kg/j si &lt; 1 mois</b>), <b>si enfant &lt; 4 ans non / incomplètement vacciné</b> (ou immunodéprimé) dans l'entourage ; précautions gouttelettes 24 h ; déclaration et enquête.</li>
</ul></div></div>
