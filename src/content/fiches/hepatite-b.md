<div class="box bl"><div class="bt">Caractères virologiques</div><div class="bb">
<p><span class="h">Virion</span> : <b>particule de Dane</b> 42–47 nm ; enveloppe (<b>HBsAg</b>) + nucléocapside icosaédrique (<b>HBcAg</b>, 27–34 nm). Particules <b>incomplètes</b> de 22 nm (sphères, filaments) en excès, non infectieuses. <span class="r">Très résistant</span> (sang séché 7 j) ; inactivé par hypochlorite, autoclave.</p>
<p><span class="h">Génome</span> : ADN circulaire <b>partiellement bicaténaire</b>, 4 cadres de lecture chevauchants : <b>S</b> (pré-S1, pré-S2, S → HBsAg), <b>C</b> (pré-C → <b>HBeAg</b> ; C → HBcAg), <b>P</b> (polymérase + transcriptase inverse), <b>X</b> (HBx, transactivateur).</p>
<p><span class="h">Réplication</span> : récepteur <b>NTCP</b> (hépatocyte) → noyau : <b>ADNccc</b> (minichromosome, matrice de transcription, <span class="r">non éliminé par les traitements</span>) → ARN prégénomique → <b>transcription inverse</b> dans la capside → ADN. Intégration possible dans le génome de l'hôte.</p>
<p><span class="h">Culture / ECP</span> : pas de culture de routine ; hépatocytes primaires, HepG2-NTCP. Pas d'ECP : lésions d'origine <b>immune</b>.</p>
<p><span class="h">Antigénie</span> : déterminant <b>a</b> commun (cible des Ac protecteurs) ; sous-types adw, adr, ayw, ayr ; <b>génotypes A–J</b> (8 principaux A–H ; A Europe/Afrique, B–C Asie, D bassin méditerranéen ; D ≈ 80–95 % en Algérie).</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li>Réservoir <b>humain strict</b> ; ≈ 250–300 millions de porteurs chroniques dans le monde ; endémicité intermédiaire en Algérie (HBsAg ≈ 2–3 %).</li>
<li><b>Parentérale</b> (UDI, transfusion, matériel souillé, tatouage, AES) ; <b>sexuelle</b> ; <b>verticale</b> (surtout <b>périnatale</b>, risque max si HBeAg+ / charge virale élevée) ; intrafamiliale. Allaitement non contre-indiqué (si sérovaccination à la naissance) ; <span class="r">pas de transmission alimentaire</span>.</li>
<li>Contagiosité ≈ <b>100 × VIH</b>. Risque professionnel (soignants, dialysés).</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li>Virus <b>non cytopathogène</b> : lésions par réponse immune (<b>LT CD8</b>, cytokines). Incubation <b>45–180 j</b> (moy. 60–90 j).</li>
<li><b>Chronicité</b> (HBsAg &gt; 6 mois) : réponse T insuffisante ; dépend de l'âge : nouveau-né 90 %, enfant 25–50 %, adulte &lt; 5 %.</li>
<li><b>Phases</b> : tolérance immune (= infection chronique HBeAg+ ; ADN élevé, ALAT N) → immuno-active HBeAg+ → <b>portage inactif</b> (= infection chronique HBeAg– selon EASL ; ADN &lt; 2 000 UI/mL, ALAT N) → hépatite chronique <b>HBeAg–</b> (mutant <b>pré-C</b>, G1896A) → HBsAg– (<b>occulte</b>, ADNccc persistant).</li>
<li>Fibrose → <b>cirrhose</b> → <b>CHC</b> (HBx, intégration ; <span class="r">possible sans cirrhose</span>). <span class="r">Réactivation</span> sous immunosuppression. Extra-hépatique : PAN, GN extramembraneuse.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Hépatite aiguë</b> : asymptomatique chez 70 % des adultes ; ictérique 30 % (prodrome pseudo-grippal, arthralgies, urticaire, puis ictère, ALAT ≫). Guérison &gt; 95 % chez l'adulte. <span class="r">Forme fulminante &lt; 1 % (TP &lt; 50 %, encéphalopathie, mortelle sans greffe)</span>.</li>
<li><b>Hépatite chronique</b> : le plus souvent asymptomatique ; <span class="r">cirrhose, décompensation, CHC</span> (surveillance : échographie ± AFP / 6 mois).</li>
<li><b>Co-infection / surinfection delta</b> : forme sévère, évolution rapide vers la cirrhose.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : sérum ou plasma (tube sec / EDTA) ; sérologie par <b>ELISA / chimiluminescence</b>. <span class="r">PCR</span> : sang total acheminé &lt; 24 h (2–25 °C), puis sérum/plasma à +2/+8 °C ou –20 °C si différé.</li>
<li><b>Marqueurs</b> : <b>HBsAg</b> (1<sup>er</sup> marqueur, infection) ; <b>anti-HBs</b> (guérison ou vaccin, protecteur si ≥ 10 mUI/mL) ; <b>anti-HBc</b> (contact, <span class="r">jamais induit par le vaccin</span>) ; <b>IgM anti-HBc</b> (infection récente ; réactivation) ; <b>HBeAg / anti-HBe</b> ; <b>ADN VHB</b> (PCR, UI/mL : diagnostic, suivi, indication thérapeutique).</li>
<li><span class="r">Fenêtre sérologique</span> : HBsAg – et anti-HBs – ; seuls marqueurs : IgM anti-HBc (± ADN). <b>Anti-HBc isolé</b> : guérison ancienne, VHB occulte, mutant d'échappement ou faux +.</li>
<li>Bilan : ALAT, TP, génotypage et mutations si résistance ; fibrose (Fibroscan, FibroTest).</li>
</ul>

<div class="box dr"><div class="bt">Antiviraux et résistance</div><div class="bb"><ul>
<li><b>Analogues nucléos(t)idiques</b> (inhibent la polymérase) : <b>ténofovir</b> (TDF, TAF) et <b>entécavir</b> = barrière génétique <b>élevée</b>, résistance quasi nulle. <b>Lamivudine</b> : résistance fréquente (mutation <b>YMDD</b>, rtM204V/I), croisée avec telbivudine et entécavir.</li>
<li>Aucun antiviral n'élimine l'ADNccc ⇒ traitement le plus souvent <b>prolongé</b>.</li>
<li>Mutants viraux : <b>pré-C</b> (HBeAg –) ; <b>échappement vaccinal</b> (G145R de HBsAg).</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Hépatite aiguë</b> : symptomatique ; antiviral seulement si forme sévère / fulminante (+ transplantation).</li>
<li><b>Chronique</b> (selon ADN, ALAT, fibrose) : <b>ténofovir ou entécavir</b> au long cours, ou <b>Peg-IFN α</b> 48 sem. <span class="r">Ne jamais arrêter sans avis</span> (rebond). <span class="r">Prophylaxie antivirale</span> avant chimiothérapie / rituximab / immunosuppresseurs.</li>
<li><b>Vaccin</b> recombinant (HBsAg), IM : 3 doses (0, 1, 6 mois). Contrôle anti-HBs chez le soignant. PEV algérien : HepB monovalent à la naissance (&lt; 24 h) puis <b>hexavalent</b> (DTCa-VPI-Hib-HBV) à 2, 4 et 12 mois (depuis oct. 2023).</li>
<li><b>Nouveau-né de mère HBsAg+</b> : <b>Ig anti-HBs + vaccin</b> dès la naissance (&lt; 12–24 h), sites différents. Dépistage HBsAg de la femme enceinte.</li>
<li><b>AES</b> non immunisé : Ig anti-HBs + vaccin. <b>Déclaration</b> obligatoire (MDO) ; dépistage de l'entourage.</li>
</ul></div></div>
