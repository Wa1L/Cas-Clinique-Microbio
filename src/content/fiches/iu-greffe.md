<div class="box br"><div class="bt">Généralités</div><div class="bb">
<p><span class="h">Fréquence</span> : IU = <b>1re infection bactérienne</b> après greffe rénale ; surtout la <b>1re année</b>, pic les premiers mois.</p>
<p><span class="h">Gravité</span> : pyélonéphrite du greffon → bactériémie, IRA, <b>dysfonction du greffon</b> ; ATB ↔ IS = interactions.</p>
<p><span class="h">Autres greffes</span> (foie, cœur, poumon) : IU surtout liées à la sonde (facteurs classiques). Greffe de <b>CSH</b> : problème dominant = <b>cystite hémorragique</b>.</p>
</div></div>

<div class="box db"><div class="bt">Diagnostic microbiologique</div><div class="bb">
<table class="mt">
  <tr><th>ECBU (REMIC / SPILF)</th><th>Seuil</th></tr>
  <tr><td>Leucocyturie</td><td>≥ 10<sup>4</sup>/mL (10/mm³) — <span class="r">peut manquer sous IS</span></td></tr>
  <tr><td><i>E. coli</i>, <i>S. saprophyticus</i></td><td>≥ 10<sup>3</sup> UFC/mL</td></tr>
  <tr><td>Autres bactéries</td><td>≥ 10<sup>3</sup> (homme) ; ≥ 10<sup>4</sup> (femme)</td></tr>
  <tr><td>Patient sondé</td><td>≥ 10<sup>5</sup> UFC/mL ; leucocyturie non contributive</td></tr>
</table>
<ul>
<li><b>ATBg</b> (CA-SFM/EUCAST) : lecture interprétative → BLSE (synergie), <b>carbapénémase</b> : algorithme de criblage CA-SFM (témocilline R → OXA-48-like fréquent au Maghreb, <span class="r">mais aussi KPC, NDM/VIM</span>) → confirmation (immunochromatographie, test colorimétrique, PCR).</li>
<li><span class="h">BKV</span> : cytologie urinaire (<b>decoy cells</b>), PCR urinaire (virurie, bonne VPN), <b>BKPyV-DNAémie</b> (PCR plasma, TTS 2024) : &gt; 10<sup>3</sup> copies/mL persistante &gt; 2–3 sem. = néphropathie <b>probable</b> ; &gt; 10<sup>4</sup> = <b>présumée</b> ; biopsie (IHC SV40) = <b>prouvée</b>, non requise chez l'adulte sans dysfonction du greffon ni haut risque immunologique.</li>
<li><span class="h">Adénovirus</span> : PCR urine + sang. <span class="h"><i>Candida</i></span> : culture, ± hémoc.</li>
<li><span class="h"><i>C. urealyticum</i></span> : bacille Gram+, <b>uréase +</b>, croissance lente (48–72 h) → <span class="r">prévenir le labo</span> ; multi-R, sensible aux glycopeptides.</li>
<li><span class="h">Tuberculose</span> : urines du matin ×3, Löwenstein-Jensen, PCR (Xpert MTB/RIF).</li>
</ul>
</div></div>

<div class="box or"><div class="bt">Greffe de CSH : cystite hémorragique</div><div class="bb"><ul>
<li><b>Précoce</b> (&lt; 72 h) : toxique (<b>acroléine</b>, métabolite du cyclophosphamide) → prévention mesna + hyperhydratation.</li>
<li><b>Tardive</b> : <b>BKV</b> (++), adénovirus (types 11, 34, 35 – espèce B) → PCR urine/sang ; traitement de support, cidofovir discuté.</li>
</ul></div></div>

<div class="col">

<div class="box dr"><div class="bt">Résistance — BMR</div><div class="bb"><ul>
<li><b>E-BLSE</b> fréquentes (hospitalisations, ATB itératives) ; <b>EPC</b> : OXA-48 prédominante au Maghreb, KPC, NDM.</li>
<li><span class="r">Cotrimoxazole et FQ : jamais en probabiliste</span> (prophylaxie SXT → sélection ; R aux FQ élevée).</li>
<li>Dépistage digestif BMR (écouvillon rectal) avant / après greffe → guide l'ATB probabiliste.</li>
<li><i>Enterococcus</i> : R naturelle aux C3G ; ERV rares.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Prévention</div><div class="bb"><ul>
<li><b>Cotrimoxazole</b> les premiers mois (anti-<i>Pneumocystis</i>, ↓ IU).</li>
<li>Retrait précoce sonde vésicale et <b>sonde JJ</b> ; correction reflux / sténose.</li>
<li><b>BKV</b> : dépistage PCR plasma mensuel jusqu'à M9, puis trimestriel jusqu'à 2 ans (3 ans chez l'enfant) (TTS 2024) ; si positif → <b>réduction de l'IS</b>. <span class="r">Cidofovir, léflunomide, FQ, IgIV : non soutenus</span>.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">Bactériurie asymptomatique &gt; 1 mois post-greffe : ne pas traiter</span> (sélection de BMR sans bénéfice) ; &lt; 1 mois : IDSA ne tranche pas.</li>
<li>Pyélonéphrite du greffon <b>mime le rejet aigu</b> (fièvre + ↑ créat.) → ECBU + hémoc <b>avant</b> tout bolus d'IS.</li>
<li><b>Decoy cells ≠ néphropathie</b> : la DNAémie BK guide, la biopsie prouve.</li>
<li>BK = 2 pièges : <b>bacille de Koch</b> (leucocyturie aseptique) vs <b>polyomavirus BK</b>.</li>
</ul></div></div>
