<div class="col">

<div class="box bl"><div class="bt">Caractères bactériologiques</div><div class="bb">
<p><span class="h">Morphologie</span> : cocci Gram + ovoïdes ; <b>pneumocoque</b> : diplocoques <b>lancéolés</b> (« flamme de bougie »), capsulés ; <b>viridans</b> : chaînettes. Immobiles, asporulés. <span class="r">Décoloration possible (Gram variable en culture âgée)</span>.</p>
<p><span class="h">Exigences</span> : bactéries <b>exigeantes</b> ; anaérobies facultatives, aérotolérantes ; CO₂ 5–10 % favorise le pneumocoque.</p>
<p><span class="h">Culture</span> : gélose au sang frais (ou chocolat), 35–37 °C, 18–24 h ; colonies <b>α-hémolytiques</b> (halo verdâtre, H₂O₂ → méthémoglobine). Pneumocoque : colonies <b>ombiliquées</b> (« bouton de col », autolyse), brillantes ou muqueuses (souches capsulées) ; viridans : petites colonies, non ombiliquées.</p>
<p><span class="h">Biochimie</span> : <b>catalase –</b>, oxydase –. Pneumocoque : <b>optochine S</b> (disque 5 µg, zone ≥ 14 mm en air ambiant ; sous CO₂ la zone diminue ⇒ <span class="r">zone douteuse : confirmer par bile-solubilité</span>), <b>bile-solubilité +</b> (désoxycholate), inuline +. Viridans : optochine R, bile –, tests VP / urée / arginine / esculine / sucres (voir tableau).</p>
<p><span class="h">Antigénie</span> : pneumocoque : <b>capsule polysaccharidique</b> (&gt; 90 sérotypes ; gonflement de Neufeld-Quellung) ; acide teichoïque à choline (antigène C) ; <span class="r">pas de groupage de Lancefield</span>. Viridans : en général <b>non groupables</b> (gr. <i>anginosus</i> : parfois A, C, F, G).</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li>Réservoir <b>strictement humain</b> : pneumocoque = nasopharynx (portage chez l'enfant surtout) ; viridans = <b>flore buccale</b> / digestive, commensaux.</li>
<li>Transmission du pneumocoque : <b>gouttelettes</b> / contact ; viridans : <b>bactériémie post-geste dentaire</b> ou brossage.</li>
<li>Terrain pneumocoque : <b>nourrisson &lt; 2 ans, sujet &gt; 65 ans</b>, <b>asplénie / splénectomie</b>, drépanocytose, VIH, myélome, alcoolisme, <b>post-grippe</b>, brèche ostéo-méningée. Viridans : <b>valvulopathie</b> / prothèse, mauvais état dentaire, neutropénie.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>Capsule</b> : facteur majeur, anti-phagocytose (⇒ sérotypes invasifs), cible vaccinale.</li>
<li><b>Pneumolysine</b> (cytolysine) ; <b>autolysine LytA</b> (libère les composants pro-inflammatoires) ; <b>protéase IgA1</b> ; PspA / PspC (inhibent le complément) ; adhésines ; acide teichoïque / <b>choline</b> (récepteur PAF).</li>
<li>Voies : <b>aspiration</b> → pneumonie ; contiguïté → otite, sinusite, méningite ; hématogène → bactériémie, méningite, arthrite.</li>
<li><b>Asplénie</b> : défaut d'opsonisation des bactéries capsulées ⇒ <span class="r">sepsis fulminant</span>.</li>
<li>Viridans : <b>dextranes / glucanes</b> (mutans, plaque) ; adhésines (FimA…) → fixation sur valve lésée → <b>végétation</b> (endocardite subaiguë).</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Pneumonie franche lobaire aiguë</b> (1<sup>re</sup> cause bactérienne de PAC) : début brutal, frissons solennels, fièvre, point de côté, crachat rouillé, foyer systématisé.</li>
<li><b>Méningite purulente</b> (nourrisson, adulte) : mortalité et <span class="r">séquelles (surdité, déficits neurologiques)</span> fréquentes.</li>
<li>OMA, sinusite, conjonctivite ; bactériémie ; péritonite, arthrite. <span class="r">Asplénique : infection foudroyante (OPSI), purpura.</span></li>
<li><b>Viridans</b> : <b>endocardite subaiguë</b> (Osler : fièvre prolongée, souffle, splénomégalie, faux panaris d'Osler, tache de Roth) ; abcès (gr. <i>anginosus</i>) ; caries (<i>mutans</i>) ; bactériémie du neutropénique (<i>mitis</i> : choc, SDRA).</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : hémocultures (endocardite : <b>≥ 3 paires</b>, avant ATB), LCR, ECBC, liquide pleural, pus d'oreille. <span class="r">LCR jamais réfrigéré</span> (autolyse du pneumocoque) : acheminement rapide à température ambiante.</li>
<li><b>Direct</b> : Gram (diplocoques lancéolés Gram +) ; <b>antigène soluble urinaire</b> (adulte) ; latex LCR ; PCR (<i>lytA</i>, multiplex méningite). <span class="r">Antigénurie : faux + chez l'enfant (portage).</span></li>
<li><b>Culture</b> : gélose sang / chocolat, CO₂ 5 %. <b>Identification</b> : optochine + bile-solubilité ; PCR <i>lytA</i> ; MALDI-TOF peu discriminant <i>S. pneumoniae</i> vs <i>S. mitis/oralis</i>. Typage : sérotypage (Quellung / latex).</li>
<li><b>ATBg (CLSI M100)</b> : <b>disques</b> : MH + 5 % sang de mouton, McF 0,5, 35 °C, CO₂ 5 %, 20–24 h ; <b>CMI</b> : CAMHB + 2,5–5 % sang de cheval lysé (LHB), 20–24 h ; contrôle <b>ATCC 49619</b>. <b>Disque oxacilline 1 µg</b> : dépistage <b>réservé à <i>S. pneumoniae</i></b> : ≥ 20 mm ⇒ sensible à la pénicilline ; &lt; 20 mm ⇒ <span class="r">mesurer la CMI</span> (pénicilline, céfotaxime / ceftriaxone). <span class="r">Viridans : diffusion en disque non validée pour pénicilline / oxacilline ⇒ CMI directe</span>.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Résistance aux antibiotiques</div><div class="bb"><ul>
<li><b>Naturelle</b> : aminosides bas niveau (synergie possible avec β-lactamine ⇒ endocardite) ; pneumocoque : pas de β-lactamase.</li>
<li><b>β-lactamines (pneumocoque)</b> : <b>PLP modifiées</b> (1a, 2x, 2b ; gènes mosaïques) ⇒ <b>PSDP</b> (CMI pénicilline &gt; 0,06 mg/L) ; <span class="r">pas de β-lactamase, donc l'acide clavulanique n'apporte rien</span>. <b>Seuils CLSI M100 (µg/mL)</b> : <i>S. pneumoniae</i> <b>méningite</b> : pénicilline G S ≤ 0,06 / R ≥ 0,12 ; céfotaxime / ceftriaxone S ≤ 0,5, I = 1, R ≥ 2. <b>Viridans</b> : pénicilline G S ≤ 0,12, I 0,25–2, R ≥ 4 ; céfotaxime / ceftriaxone S ≤ 1, I = 2, R ≥ 4. CMI pénicilline en hausse chez les viridans (même mécanisme).</li>
<li><b>Macrolides</b> : 2 mécanismes.</li>
</ul>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Pneumonie</b> : amoxicilline PO (3 g/j en 3 prises, adulte, à vérifier) ; formes graves : amoxicilline ou C3G IV. <b>OMA / sinusite</b> : amoxicilline 80–90 mg/kg/j.</li>
<li><b>Méningite</b> : <b>céfotaxime 300 mg/kg/j</b> ou <b>ceftriaxone 100 mg/kg/j</b> IV + <b>dexaméthasone</b> avant / avec la 1<sup>re</sup> dose ; si CMI C3G &gt; 0,5 µg/mL (I / R) : <b>+ vancomycine</b> ; 10–14 j. <span class="r">Jamais de monothérapie par macrolide / FQ en cas de doute</span>.</li>
<li><b>Endocardite à viridans</b> : pénicilline G ou amoxicilline IV 4 sem. (CMI pénicilline ≤ 0,12 µg/mL, S CLSI) ± gentamicine 2 sem. ; 6 sem. si prothèse (à vérifier selon les recommandations).</li>
<li><b>Vaccins</b> : conjugué <b>PCV13</b> au PEV algérien (2, 4, 12 mois, à vérifier) ; PPSV23 (≥ 2 ans, à risque : asplénie, immunodéprimés).</li>
<li><b>Prophylaxie</b> : asplénie → vaccin + pénicilline V ; endocardite : antibioprophylaxie <b>amoxicilline 2 g</b> 30–60 min avant le geste dentaire (cardiopathie à haut risque) ; <b>pas de prophylaxie de l'entourage</b> pour le pneumocoque ; déclaration : méningite = MDO (à vérifier).</li>
</ul></div></div>
