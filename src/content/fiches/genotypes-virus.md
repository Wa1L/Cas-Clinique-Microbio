<div class="box rd"><div class="bt">Origine de la diversité</div><div class="bb"><ul>
<li><b>Mutations</b> : polymérase sans relecture (ARN virus, RT du VIH) → quasi-espèces (VHC, VIH).</li>
<li><b>Réassortiment</b> : génomes segmentés (influenza, rotavirus) → nouveaux sous-types / combinaisons G/P.</li>
<li><b>Recombinaison</b> : VIH (CRF), norovirus, entérovirus ; VHB I = recombinant A/C/G ; recombinants B/C fréquents en Asie ; J = lignée divergente (proche du VHB de gibbon).</li>
<li><b>Géographie</b> : génotype ↔ histoire des migrations (VHB, VHC, VHE).</li>
</ul></div></div>

<div class="box or"><div class="bt">Génotype et clinique</div><div class="bb"><ul>
<li><span class="h">VHB</span> : C → CHC et séroconversion HBe tardive ; pré-core G1896A (HBe–) fréquent en génotype D.</li>
<li><span class="h">VHC</span> : GT3 → stéatose, progression fibreuse + CHC.</li>
<li><span class="h">VHD</span> : GT3 → fulminante ; GT2 → plus bénin. Toujours rechercher <b>HBsAg</b> (satellite).</li>
<li><span class="h">VHE</span> : GT1–2 → <span class="r">mortalité élevée chez la femme enceinte</span> ; GT3 → hépatite chronique (immunodéprimé).</li>
<li><span class="h">VHE du rat</span> (<i>Rocahepevirus ratti</i>) : zoonose émergente, <span class="r">non détectée par les RT-PCR ciblant <i>P. balayani</i></span>.</li>
<li><span class="h">Dengue</span> : ADE lors d'une 2e infection hétérologue.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Pièges et limites du typage</div><div class="bb"><ul>
<li><b>VIH-1 O</b> et <b>VIH-2</b> : INNTI inefficaces (résistance naturelle) ; VIH-2 aussi enfuvirtide.</li>
<li><b>HPV</b> : test « pool HR » sans typage ≠ génotypage 16/18.</li>
<li><b>Rougeole</b> : génotype A détecté après vaccin → éruption post-vaccinale, pas un cas sauvage ; N-450 peu discriminant (B3/D8) → séquençage étendu / génome entier.</li>
<li><b>VHC</b> : 5′NC seule peut mal sous-typer (1a/1b) → NS5B.</li>
<li><b>VHC</b> : sous-types rares (1l, 4r, 3b) à polymorphismes NS5A naturels → échec possible sofosbuvir/velpatasvir ; séquencer si échec.</li>
<li><b>Influenza</b> : drift ≠ shift ; B/Yamagata non détecté depuis 03/2020.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Conséquences thérapeutiques et vaccinales</div><div class="bb"><ul>
<li><b>VHC</b> : AAD pangénotypiques (sofosbuvir/velpatasvir, glécaprévir/pibrentasvir) → génotypage moins décisif en routine.</li>
<li><b>VHB</b> : réponse à l'IFN-peg meilleure en A/B qu'en C/D.</li>
<li><b>HPV</b> : Gardasil 9 = 6, 11, 16, 18, 31, 33, 45, 52, 58.</li>
<li><b>Rotavirus</b> : Rotarix (G1P[8]), RotaTeq (G1–G4, P[8]).</li>
<li><b>Rougeole</b> : 1 sérotype → 1 vaccin protège contre tous les génotypes.</li>
<li><b>Grippe</b> : vaccin actualisé selon HA/NA ; trivalent (A/H1N1, A/H3N2, B/Victoria).</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">Génotype ≠ sérotype</span> : sérotypes = dengue, polio ; génotypes = VHB, VHC, VHD, VHE, rougeole.</li>
<li>Particularités : <b>VHB-C</b> CHC · <b>VHD-3</b> fulminante · <b>VHE-1/2</b> femme enceinte · <b>VHC-3</b> stéatose · <b>VIH-1 O</b> INNTI-R.</li>
<li>Rougeole : 24 génotypes mais 1 sérotype ; polio : PV2 et PV3 sauvages éradiqués.</li>
</ul></div></div>
