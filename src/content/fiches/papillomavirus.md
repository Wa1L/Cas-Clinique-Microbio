<div class="box bl"><div class="bt">Caractères virologiques</div><div class="bb">
<p><span class="h">Virion</span> : <b>nu</b> (sans enveloppe) ⇒ résiste à la chaleur, à la dessiccation, à l'éthanol ⇒ <span class="r">transmission par fomites</span> ; capside icosaédrique 55 nm, 72 capsomères (pentamères de <b>L1</b> + L2 mineure).</p>
<p><span class="h">Génome</span> : <b>ADN db circulaire ≈ 8 kb</b>, associé aux histones cellulaires ; 3 régions : <b>LCR / URR</b> (non codante, régulation, ori), <b>E</b> précoce (E1, E2, E4, E5, <b>E6</b>, <b>E7</b>), <b>L</b> tardive (<b>L1</b>, L2) ; un seul brin codant.</p>
<p><span class="h">Réplication</span> : nucléaire ; infection des <b>cellules basales</b> (micro-lésions) → épisome ; amplification, expression de L1 / L2 et assemblage dans les couches superficielles (liée à la différenciation du kératinocyte) ; libération par desquamation, <b>sans lyse</b>.</p>
<p><span class="h">Culture / ECP</span> : <span class="r">non cultivable</span> en routine ; cytologie <i>in vivo</i> : <b>koïlocytes</b> (halo périnucléaire, noyau hyperchromatique, binucléation).</p>
<p><span class="h">Antigénie / typage</span> : <b>L1</b> type-spécifique (nouveau type : ≥ 10 % de divergence du gène L1) ; > 200 types, ≈ 40 génitaux ; pas d'immunité croisée entre types ; <b>VLP L1</b> = base des vaccins.</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li>Réservoir strictement <b>humain</b> ; <b>IST virale la plus fréquente</b> : ≈ 80 % des adultes actifs infectés ; pic 18-25 ans.</li>
<li>Transmission : <b>sexuelle</b> (contact muqueux / cutané, préservatif = protection partielle), <b>verticale</b> (→ papillomatose laryngée), fomites / eau (verrues).</li>
<li><b>Clairance ≈ 90 % en 1-2 ans</b> (immunité cellulaire) ; la <b>persistance</b> d'un HPV-HR = risque de cancer.</li>
<li>Cofacteurs : tabac, immunodépression (VIH, greffés), multiparité, contraception orale prolongée, coïnfections (<i>C. trachomatis</i>, HSV-2), début précoce des rapports.</li>
<li>Col utérin : 4<sup>e</sup> cancer de la femme (≈ 660 000 cas, 350 000 décès/an en 2022) ; HPV en cause dans > 95 % des cas.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>E6</b> : dégrade <b>p53</b> (via E6-AP) + active la télomérase ; <b>E7</b> : inactive <b>pRb</b> → libère E2F → prolifération. Affinité forte pour HR (16, 18), faible pour BR.</li>
<li><b>Intégration</b> de l'ADN viral : rupture de <b>E2</b> (répresseur de E6 / E7) ⇒ surexpression E6 / E7 ⇒ instabilité génomique. BR (6, 11) : reste <b>épisomal</b>.</li>
<li>Cible : <b>zone de jonction pavimento-cylindrique</b> (zone de transformation du col).</li>
<li>Histoire naturelle : infection → CIN1 (LSIL) → CIN2-3 (HSIL) → carcinome in situ → invasif ; <span class="r">10-20 ans</span> ⇒ fenêtre de dépistage.</li>
<li>Échappement immun : pas de virémie, pas de lyse, peu d'inflammation ; E5, E6 / E7 inhibent l'interféron.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Verrues cutanées</b> (vulgaires, planes, plantaires) : bénignes, régression spontanée en 1-2 ans.</li>
<li><b>Condylomes acuminés</b> (6, 11) : « crêtes de coq » vulve, verge, périnée, anus ; <span class="r">récidives fréquentes</span> ; croissance rapide pendant la grossesse ; forme géante : Buschke-Löwenstein.</li>
<li><b>Papillomatose laryngée récurrente</b> (6, 11) : enfant né de mère à condylomes ; dysphonie, stridor ; <span class="r">obstruction des voies aériennes</span>.</li>
<li><b>Lésions précancéreuses</b> : CIN, VaIN, VIN, AIN ; <span class="r">asymptomatiques</span> ⇒ dépistage.</li>
<li><b>Cancers HR</b> (16, 18) : col (<span class="r">métrorragies post-coïtales</span>, leucorrhées), anus, vulve, vagin, pénis, <b>oropharynx</b> (amygdale, base de langue).</li>
<li><b>EV</b> (β) : transmission génétique (<i>EVER1/2</i>) ; carcinomes cutanés sur zones photoexposées.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : frottis cervico-utérin (cytobrosse, endocol + exocol), milieu liquide ; <span class="r">pas pendant les règles, ni rapports / ovules / toilette intravaginale 48 h avant</span> ; biopsie dirigée ; auto-prélèvement vaginal (test HPV).</li>
<li><b>Cytologie</b> (Papanicolaou) : koïlocytes ; classification de <b>Bethesda</b>.</li>
<li><b>Colposcopie</b> : acide acétique 3-5 % (lésion blanche), Lugol (Schiller) ; biopsie → histologie ; <b>p16</b> (IHC) = marqueur de HR-HPV.</li>
<li><b>Moléculaire</b> : PCR / capture d'hybrides (ADN HPV-HR), ARNm E6 / E7 ; génotypage 16 / 18 ; test HPV-HR préféré dès 30 ans (OMS).</li>
<li><span class="r">Ni culture, ni sérologie diagnostique</span> (reflet de l'exposition) ; pas d'ATBg.</li>
</ul>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Aucun antiviral spécifique</b> : on traite les lésions.</li>
<li><b>Verrues</b> : cryothérapie (azote liquide), acide salicylique ; abstention possible.</li>
<li><b>Condylomes</b> : podophyllotoxine 0,5 % ou imiquimod 5 % (patient ; <span class="r">proscrits pendant la grossesse</span>) ; cryothérapie, électrocoagulation, laser CO₂, exérèse ; rechercher les autres IST.</li>
<li><b>CIN2-3</b> : conisation (anse diathermique) ; cancer : chirurgie ± radio-chimiothérapie (cisplatine). Papillomatose laryngée : exérèse laser répétée ± cidofovir (hors AMM).</li>
<li><b>Vaccins</b> : VLP L1 recombinantes, <b>prophylactiques</b>, sans ADN viral.</li>
</ul>
