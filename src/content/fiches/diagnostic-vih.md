<div class="box bl"><div class="bt">Principes de la stratégie OMS</div><div class="bb"><ul>
<li><span class="h">A1</span> = test le plus <b>sensible</b> ; <span class="h">A2, A3</span> = les plus <b>spécifiques</b>, <b>distincts</b> les uns des autres (TDR ou EIA).</li>
<li><span class="h">Objectif</span> : VPP ≥ <b>99 %</b> pour annoncer un diagnostic positif.</li>
<li><span class="h">2019</span> : <b>3 tests réactifs consécutifs</b> pour <b>tous</b> les pays (≥ 18 mois) ; avant : 2 tests si prévalence ≥ 5 %, 3 tests si &lt; 5 %.</li>
<li><span class="h">Pourquoi</span> : quand la positivité tombe sous 5 %, la VPP d'une stratégie à 2 tests chute → faux positifs.</li>
<li><span class="r">Pas de « tie-breaker »</span> pour conclure positif (↑ faux positifs).</li>
<li><b>Western blot / immunoblot (LIA)</b> : abandon recommandé → retard diagnostique, indéterminés, perdus de vue.</li>
<li>Algorithme national : <b>étude de vérification</b> avant adoption.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Situations particulières (OMS)</div><div class="bb"><ul>
<li><b>CPN</b> : TDR <b>double VIH/syphilis</b> utilisable comme 1<sup>er</sup> test.</li>
<li><b>Autotest</b> : réactif → algorithme complet par un testeur formé ; recommandé aussi pour <b>PrEP/PEP</b> (OMS 2024).</li>
<li><b>Avant TARV</b> : retest sur <b>nouveau prélèvement</b> pour écarter une erreur d'identité ou de technique.</li>
<li><b>Indéterminé</b> : jamais négatif d'emblée → retest complet à <b>J14</b>.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Pièges de lecture</div><div class="bb"><ul>
<li><span class="r">Fenêtre sérologique</span> : primo-infection → Ac absents ; TDR (Ac seuls) moins performants que l'ELISA 4<sup>e</sup> G → Ag p24 / <b>ARN</b>.</li>
<li><b>Faux positifs</b> des TDR (trypanosomose humaine africaine, grossesse, auto-immunité, infections aiguës type EBV) → d'où A2 et A3 spécifiques.</li>
<li><b>VIH-2</b> : tests VIH-1/2 le détectent, mais la <b>CV VIH-1</b> est inadaptée ; immunoblot <b>différenciant</b> VIH-1/VIH-2 (un WB VIH-1 seul peut être indéterminé).</li>
</ul></div></div>

<div class="box bl"><div class="bt">Services de dépistage : les 5 C (OMS)</div><div class="bb">
<p><b>C</b>onsentement · <b>C</b>onfidentialité · <b>C</b>onseil (pré et post-test) · résultats <b>C</b>orrects (assurance qualité) · <b>C</b>onnexion (lien vers prévention et soins).</p>
</div></div>

<div class="box gr"><div class="bt">Assurance qualité</div><div class="bb"><ul>
<li><b>CQ interne</b> + <b>EEQ</b> (évaluation externe) ; testeurs formés ; <b>LNR</b> = référence nationale.</li></ul></div></div>

<div class="box db"><div class="bt">Nourrisson &lt; 18 mois (OMS 2021)</div><div class="bb">
<p><span class="r">Ac maternels transmis</span> → sérologie ininterprétable → <b>NAT</b> (PCR ; test au lit du patient recommandé).</p>
<table class="mt">
  <tr><th>Quand</th><th>Test</th></tr>

<p>NAT positif → <b>confirmer</b> sur 2<sup>e</sup> prélèvement · symptomatique → NAT · indéterminé → répéter vite · &gt; 18 mois : algorithme adulte.</p>

<div class="box br"><div class="bt">Contexte algérien</div><div class="bb"><ul>
<li><b>CD/CDV</b> : dépistage volontaire, gratuit ; <b>CPN-PTME</b> : proposition systématique, diagnostic précoce du nouveau-né exposé.</li>
<li>Donneurs de sang : dépistage <b>systématique</b> (depuis 1991).</li>
<li><b>LNR</b> = Institut Pasteur d'Algérie : dépistage et confirmation, <b>notification</b>, charge virale VIH-1.</li>
<li><b>CDR</b> : prise en charge ; cadre : PNS IST/VIH/sida 2020-2024.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Objectifs et cadre stratégique</div><div class="bb"><ul>
<li><b>ONUSIDA 95-95-95</b> : le diagnostic est la 1<sup>re</sup> étape de la cascade (connaître son statut).</li>
<li><b>PNS Algérie 2020-2024</b> (échu ; cycle suivant à vérifier) : objectif nouveaux cas &lt; 1 000/an ; fin du sida d'ici 2030 ; <b>Déclaration d'Alger</b> (dépistage, MENA).</li>
</ul></div></div>

<div class="box or"><div class="bt">Populations prioritaires du dépistage</div><div class="bb"><ul>
<li><b>HSH</b>, professionnel(le)s du sexe, <b>consommateurs de drogues injectables</b>, détenus, migrants, partenaires de PVVIH, femmes enceintes.</li>
<li>Dépistage <b>communautaire / mobile</b> et <b>autotest</b> : compléments du dépistage en structure.</li>
</ul></div></div>

<div class="box db"><div class="bt">Pratique en Algérie et outils</div><div class="bb">
<ul>
<li>Dépistage : <b>TDR</b> ou <b>ELISA</b> ; réactif → <b>confirmation</b> (ELISA répété, Western blot au LNR).</li>
<li>Suivi : <b>charge virale VIH-1</b> (RT-PCR temps réel, IPA).</li>
<li>Autotest réactif → confirmation selon l'<b>algorithme national</b>.</li>
</ul>

  <tr><td>RT-PCR</td><td>ARN VIH-1</td><td>~7–10 j</td></tr>

<div class="box dr"><div class="bt">Écarts Algérie ↔ OMS (à vérifier)</div><div class="bb"><ul>
<li><span class="r">Western blot encore cité en pratique</span> ↔ OMS : abandon.</li>
<li>Stratégie à 3 tests : <b>alignement national non retrouvé</b> dans les sources publiques → vérifier l'instruction en vigueur.</li>
<li>Confirmation centralisée au LNR → délai possible ↑ → risque de perdus de vue.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">Positif OMS = A1+ A2+ A3+</span> ; discordance ou A3– = <b>indéterminé</b> → retest J14.</li>
<li>TDR, ELISA ou autotest <b>réactif seul ≠ diagnostic</b>.</li>
<li><span class="r">Nourrisson &lt; 18 mois : NAT, jamais sérologie seule.</span></li>
<li>WB/LIA <b>abandonnés</b> (OMS) ; tie-breaker <b>proscrit</b>.</li>
</ul></div></div>
