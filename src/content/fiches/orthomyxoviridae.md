<div class="box bl"><div class="bt">Caractères virologiques</div><div class="bb">
<p><span class="h">Virion</span> : <b>enveloppé</b>, pléomorphe (sphérique 80–120 nm ou filamenteux) ; spicules <b>HA</b> (trimère, fixation + fusion) et <b>NA</b> (tétramère, libération) ; canal ionique <b>M2</b> (A) ; matrice <b>M1</b> ; nucléocapside hélicoïdale (NP).</p>
<p><span class="h">Génome</span> : ARN (–) <b>8 segments</b> (A, B) : <b>PB2, PB1, PA</b> (polymérase), <b>HA, NP, NA, M</b> (M1, M2), <b>NS</b> (NS1, NEP/NS2). Polymérase sans relecture ⇒ forte variabilité.</p>
<p><span class="h">Réplication</span> : HA se fixe à l'<b>acide sialique</b> (α2,6 voies aériennes hautes humaines ; α2,3 oiseaux et voies basses) → endocytose → fusion à pH acide (M2 acidifie) → <b>réplication nucléaire</b> (rare pour un virus à ARN), <b>« cap-snatching »</b> → bourgeonnement ; NA libère les virions.</p>
<p><span class="h">Culture / ECP</span> : <b>œufs embryonnés</b> (cavité allantoïdienne / amniotique), <b>cellules MDCK</b> + trypsine ; ECP inconstant ; <b>hémagglutination</b> des GR (poule, cobaye).</p>
<p><span class="h">Antigénie</span> : NP + M1 ⇒ <b>type A / B / C</b> ; HA + NA ⇒ <b>sous-types</b>. <b>Nomenclature</b> : type / hôte (si non humain) / lieu / n° / année (sous-type), ex. A/California/7/2009 (H1N1)pdm09.</p>
<p><span class="h">Variations</span> : <b>drift</b> = mutations ponctuelles ⇒ épidémies saisonnières ; <b>shift</b> = <b>réassortiment</b> de segments (A seul) ⇒ <span class="r">pandémies</span> (1918 H1N1, 1957 H2N2, 1968 H3N2, 2009 H1N1pdm).</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li>Réservoir A : <b>oiseaux aquatiques sauvages</b> ; <b>porc = « vase de mélange »</b> (récepteurs α2,3 et α2,6) ; B, C : homme.</li>
<li>Transmission <b>interhumaine</b> : gouttelettes, aérosols, mains / surfaces. Incubation <b>1–4 j</b> ; contagiosité de J–1 à J+5–7 (plus longue chez enfant, immunodéprimé).</li>
<li>Épidémies <b>hivernales</b> (Algérie : octobre–avril, pic décembre–février ; surveillance sentinelle IPA) ; OMS : ≈ 290 000–650 000 décès respiratoires / an.</li>
<li>Terrain à risque : <b>≥ 65 ans, &lt; 5 ans (surtout &lt; 2 ans), femme enceinte</b>, obèse, comorbidités (BPCO, cardiopathie, diabète), immunodéprimé.</li>
<li>Zoonoses (H5N1, H7N9) : contact avec volailles ; <span class="r">létalité cumulée OMS H5N1 ≈ 48 %</span> (cas asiatiques exposés aux volailles) ; cas US 2.3.4.4b (bovins laitiers) surtout bénins (conjonctivite) ; pas de transmission interhumaine soutenue.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>Clivage de HA</b> (HA0 → HA1 + HA2) par protéases de l'hôte (TMPRSS2, trypsine-like) <b>indispensable</b> à l'infectivité. Souches <b>HPAI</b> : site polybasique clivé par la <b>furine</b> ⇒ infection systémique.</li>
<li><b>NS1</b> : antagoniste de l'<b>interféron</b> ; <b>PB1-F2</b> : apoptose ; NA : libération + facilite les surinfections.</li>
<li>Nécrose de l'épithélium cilié trachéo-bronchique ⇒ <b>perte de la clairance mucociliaire</b> ⇒ <span class="r">surinfections bactériennes</span> (<i>S. pneumoniae</i>, <i>S. aureus</i>, <i>H. influenzae</i>).</li>
<li>Formes graves : pneumonie virale primitive, <b>SDRA</b>, tempête cytokinique.</li>
<li>Immunité : anticorps anti-HA (neutralisants, <b>souche-spécifiques</b>) ; anti-NA (limitent la sévérité) ; réinfections possibles par drift.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Grippe typique</b> : début <b>brutal</b>, fièvre 39–40 °C, frissons, <b>myalgies</b>, céphalées, toux sèche, asthénie ; guérison en 5–7 j, <b>asthénie prolongée</b>.</li>
<li><b>Complications</b> : <span class="r">pneumonie bactérienne secondaire</span> (<i>S. aureus</i>, <i>S. pneumoniae</i>), pneumonie virale primitive / SDRA, décompensation de BPCO ou cardiopathie, myocardite, myosite / rhabdomyolyse, encéphalite, Guillain-Barré.</li>
<li>Enfant : otite, croup, convulsions fébriles, signes digestifs ; <span class="r">syndrome de Reye (aspirine proscrite)</span>.</li>
<li>Grippe aviaire : conjonctivite, pneumonie rapidement progressive, SDRA, défaillance multiviscérale.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : écouvillon <b>nasopharyngé</b> (ou aspiration nasopharyngée) <b>≤ 48–72 h</b> après le début ; formes graves : aspirat trachéal / LBA. Milieu de transport viral à <b>+4 °C</b> (≤ 48 h), –70 °C au-delà ; <span class="r">piège : écouvillon sec ou coton-alginate, prélèvement tardif ⇒ faux négatif</span>.</li>
<li><b>RT-PCR temps réel</b> multiplex (gène M ⇒ type ; HA / NA ⇒ sous-type) = <b>référence</b>. <b>TDR antigéniques</b> : rapides, spécificité élevée, <span class="r">sensibilité moyenne : un négatif n'élimine pas</span>.</li>
<li><b>Culture</b> (MDCK / œufs) : surveillance, laboratoires de référence. <b>Typage</b> : séquençage HA / NA, surveillance <b>GISRS-OMS</b> (centre national de référence, IPA).</li>
<li><b>Sérologie</b> : inhibition de l'hémagglutination, séroconversion ×4 sur 2 sérums à 15 j ⇒ <b>rétrospective</b>, épidémiologie uniquement.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Résistance aux antiviraux</div><div class="bb"><ul>
<li><b>Adamantanes</b> (amantadine, rimantadine ; cible M2) : mutation <b>S31N</b> ⇒ résistance généralisée (H3N2, H1N1pdm09) ; <b>inactifs sur B et C</b> (pas de M2 de type A) ⇒ <span class="r">proscrits</span>.</li>
<li><b>Inhibiteurs de NA</b> : <b>H275Y</b> (N1) ⇒ R <b>oseltamivir + peramivir</b>, <b>zanamivir conservé</b> ; E119V, R292K (N2) ; inhibiteurs de NA <b>inactifs sur C / D</b> (pas de NA).</li>
<li><b>Baloxavir</b> (inhibiteur d'endonucléase PA) : mutation <b>I38T</b> de PA ; sélection rapide sous traitement.</li>
<li>Détection : phénotypique (activité NA, IC50) ou génotypique (séquençage).</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Oseltamivir</b> 75 mg ×2/j <b>5 j</b> (adulte ; enfant selon poids) : <b>≤ 48 h</b> du début, mais <b>sans attendre</b> si forme grave, hospitalisé ou à risque (même au-delà de 48 h). Zanamivir inhalé ; <b>baloxavir</b> PO <b>dose unique</b> (40 mg si 20–&lt; 80 kg ; 80 mg si ≥ 80 kg) ≤ 48 h ; non utilisé en routine en Algérie.</li>
<li>Symptomatique : paracétamol, hydratation ; <span class="r">aspirine proscrite chez l'enfant</span> ; antibiotiques si surinfection bactérienne.</li>
<li><b>Vaccin</b> inactivé <b>annuel</b> IM <b>trivalent</b>, composition réactualisée chaque année par l'OMS (depuis 2023 : A H1N1, A H3N2, B Victoria ; <span class="r">Yamagata exclu</span>) ; efficacité 40–60 % ; <b>cibles</b> : ≥ 65 ans, comorbidités, femme enceinte, soignants, jeunes enfants. <b>PEV algérien</b> : non inclus au calendrier ; campagne nationale annuelle gratuite ciblée (octobre–mars).</li>
<li><b>Prophylaxie de l'entourage</b> : oseltamivir 75 mg ×1/j 10 j chez sujet à risque exposé (≤ 48 h) ; précautions <b>gouttelettes</b> / masque, hygiène des mains. <b>Déclaration</b> : surveillance sentinelle ; <b>grippe à nouveau sous-type = MDO à déclaration immédiate (RSI)</b>.</li>
</ul></div></div>
