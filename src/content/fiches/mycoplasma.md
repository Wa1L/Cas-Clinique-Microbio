<div class="box bl"><div class="bt">Caractères bactériologiques</div><div class="bb">
<p><span class="h">Morphologie</span> : <b>aucune paroi</b> (membrane trilaminaire à stérols) ⇒ pléomorphes (0,2–0,3 µm), filtrables (0,45 µm), <span class="r">non visibles au Gram</span> ; plus petites bactéries à croissance autonome ; génome 0,6–1,4 Mb, G+C bas (24–33 %). <i>M. pneumoniae</i> : filamenteux, motilité par glissement, organelle terminal.</p>
<p><span class="h">Exigences</span> : <b>stérols</b> (cholestérol) + précurseurs d'acides nucléiques ⇒ sérum de cheval, extrait de levure ; <i>Ureaplasma</i> : pH acide (≈ 6) + urée.</p>
<p><span class="h">Culture</span> : PPLO / Hayflick (+ pénicilline), 35–37 °C, aérobie ou CO₂ 5 %, atmosphère humide ; colonies minuscules « <b>œuf sur le plat</b> » (centre enfoncé dans la gélose) ; <i>M. hominis</i> 2–4 j ; <i>Ureaplasma</i> 1–2 j, colonies brun-noir sur A7/A8 (MnSO₄ + urée) ; <i>M. pneumoniae</i> <b>1–3 sem</b> (SP4), colonies granuleuses « en mûre ».</p>
<p><span class="h">Biochimie</span> : glucose / arginine / urée (cf. tableau) ; <i>M. pneumoniae</i> : β-hémolyse (H₂O₂), hémadsorption, réduction du TTC.</p>
<p><span class="h">Antigénie</span> : <b>adhésine P1</b> (cytadhérence, immunogène majeur) ; glycolipides ⇒ réaction croisée avec l'antigène <b>I</b> des hématies (IgM = agglutinines froides).</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li><i>M. pneumoniae</i> : réservoir <b>strictement humain</b> ; <b>gouttelettes</b>, contact étroit (familles, écoles, casernes) ; incubation 2–3 sem ; <b>épidémies cycliques</b> tous les 3–7 ans ; enfant &gt; 5 ans, adulte jeune.</li>
<li>Génitaux : transmission <b>sexuelle</b> et <b>verticale</b> (accouchement) ; <b>portage commensal fréquent</b> (<i>Ureaplasma</i>, <i>M. hominis</i>) ⇒ interpréter selon contexte et seuil quantitatif.</li>
<li>Terrain : hypogammaglobulinémie, transplantés (arthrites, abcès extra-génitaux) ; prématuré.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><i>M. pneumoniae</i> : adhésine <b>P1</b> ⇒ fixation aux récepteurs sialylés de l'épithélium respiratoire ; ciliostase, desquamation ; <b>toxine CARDS</b> (ADP-ribosyltransférase) ; H₂O₂ + superoxyde ; <b>extracellulaire, non invasive</b>.</li>
<li>Lésions surtout <b>immunologiques</b> (inflammation excessive, auto-Ac) ⇒ <span class="r">manifestations extra-respiratoires</span>.</li>
<li><i>Ureaplasma</i> : <b>uréase</b> (NH₃), IgA protéase, phospholipases ⇒ chorioamniosite ; <i>M. hominis</i> : arginine désiminase ; <i>M. genitalium</i> : adhésine MgPa, internalisation ⇒ persistance.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b><i>M. pneumoniae</i></b> : trachéobronchite ; <b>pneumonie atypique</b> : début progressif, toux sèche tenace, fièvre modérée, céphalées ; <span class="r">dissociation radio-clinique</span> (auscultation pauvre, radio bruyante) ; otite myringite bulleuse.</li>
<li>Extra-respiratoire : <span class="r">anémie hémolytique à agglutinines froides</span>, érythème polymorphe / Stevens-Johnson, méningo-encéphalite, Guillain-Barré, péricardite.</li>
<li><b>UNG</b> (<i>M. genitalium</i>, <i>Ureaplasma</i>) : écoulement clair, cervicite, salpingite ⇒ <span class="r">stérilité tubaire</span>.</li>
<li><i>M. hominis</i> : vaginose, pyélonéphrite, fièvre du post-partum / post-abortum.</li>
<li><i>Ureaplasma</i> : chorioamniosite, <span class="r">prématurité</span>, avortement, dysplasie bronchopulmonaire, méningite néonatale.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : respiratoire (écouvillon nasopharyngé, expectoration, LBA) ; génital (1<sup>er</sup> jet d'urine, écouvillon urétral / endocervical) ; <span class="r">éviter alginate de calcium et bois</span> ; milieu de transport, 4 °C, délai &lt; 48 h.</li>
<li><b>Direct</b> : <span class="r">Gram inutile</span> (pas de paroi) ; <b>PCR temps réel</b> = méthode de choix (<i>M. pneumoniae</i>, <i>M. genitalium</i>).</li>
<li><b>Culture</b> : PPLO/Hayflick ; génitaux : dénombrement, seuil ≥ 10⁴ UCC/mL (≥ 10³ si 1<sup>er</sup> jet urinaire chez l'homme) ; <span class="r">culture de routine non recommandée en 1<sup>re</sup> intention</span> (portage) : réserver aux UNG chroniques, infections hautes, néonatal, immunodéprimé. <b>Sérologie</b> : IgM/IgG (ELISA, agglutination de particules), 2 sérums à 15 j, ×4 ; <b>agglutinines froides</b> ≥ 1/64 (non spécifiques, ≈ 1 cas sur 2).</li>
<li><b>Identification</b> : colonies œuf sur le plat + glucose / arginine / urée ; trousses (type Mycoplasma IST) : identification + dénombrement + ATBg.</li>
<li><b>ATBg</b> (CLSI M43-A) : <b>microdilution en bouillon</b> (CMI) ; <span class="r">jamais de disques</span> ; SP4 (<i>M. pneumoniae</i>, <i>M. hominis</i>), 10B / A8 (<i>Ureaplasma</i>). QC : <i>M. pneumoniae</i> ATCC 29342, <i>M. hominis</i> ATCC 23114, <i>U. urealyticum</i> ATCC 33175 (tet(M)). <span class="r">Piège</span> : galerie Mycoplasma IST 2 non conforme CLSI (faux R) ; IST 3 ne distingue pas <i>U. urealyticum</i> / <i>parvum</i>.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Résistance aux antibiotiques</div><div class="bb"><ul>
<li><b>Naturelle</b> : <b>β-lactamines</b>, glycopeptides, fosfomycine (cible = paroi, absente) ; <b>rifampicine</b> (rpoB) ; sulfamides–TMP, polymyxines, acide nalidixique.</li>
<li><b>Acquise</b> : tétracyclines ⇒ <b>tetM</b> (Tn916) ; macrolides ⇒ mutation <b>ARNr 23S</b> (A2063G/A2064G), <i>M. pneumoniae</i> et <i>M. genitalium</i> ; FQ ⇒ <i>gyrA/parC</i>.</li>
</ul>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b><i>M. pneumoniae</i></b> : <b>macrolide</b> (azithromycine 500 mg J1 puis 250 mg J2–J5 ; clarithromycine ; josamycine) ; échec / R : doxycycline 100 mg ×2/j 7–14 j ou FQ (adulte). Enfant &lt; 8 ans : <span class="r">cyclines et FQ proscrites</span> (recours : doxycycline cure courte ≤ 14–21 j si pneumonie sévère à souche R aux macrolides).</li>
<li><b>UNG</b> : doxycycline 100 mg ×2/j 7 j ; <i>M. genitalium</i> : <b>séquentiel</b> doxycycline 7 j <b>puis</b> azithromycine (si S) ou moxifloxacine 400 mg/j 7 j (si R ou inconnu ; 14 j si PID) ; <span class="r">azithromycine 1 g unique proscrite</span> (sélection de R) ; traiter les <b>partenaires</b>.</li>
<li><i>M. hominis</i> : doxycycline (clindamycine, FQ en alternative) ; <i>Ureaplasma</i> : doxycycline ou macrolide ; <b>femme enceinte</b> : <i>M. hominis</i> ⇒ clindamycine ou josamycine ; <i>Ureaplasma</i> ⇒ azithromycine ou josamycine ; <span class="r">jamais de cyclines</span> ; <span class="r">azithromycine inefficace sur <i>M. hominis</i></span>.</li>
<li><b>Vaccin</b> : aucun. <b>Prévention</b> : précautions gouttelettes en collectivité, préservatif ; prophylaxie de l'entourage non systématique ; déclaration non obligatoire en Algérie (hors liste MDO, décret 22-250), signaler les épidémies en collectivité.</li>
</ul></div></div>
