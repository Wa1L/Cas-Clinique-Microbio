<div class="box bl"><div class="bt">Caractères virologiques</div><div class="bb">
<p><span class="h">Virion</span> : icosaèdre <b>nu</b>, 70–90 nm ; 252 capsomères = <b>240 hexons + 12 pentons</b> portant chacun une <b>fibre</b> (bouton terminal = attachement ; F et G : fibre longue + courte). <span class="r">Résistant</span> : éther, détergents, pH acide, dessiccation (survie prolongée sur surfaces).</p>
<p><span class="h">Génome</span> : <b>ADN bicaténaire linéaire</b> ≈ 36 kb, répétitions terminales inversées (ITR) + <b>protéine terminale</b> liée au 5'. Gènes précoces (E1–E4), tardifs (L1–L5).</p>
<p><span class="h">Réplication</span> : <b>nucléaire</b>, ADN polymérase virale propre ; E1A → inactive Rb (phase S), E1B → inactive p53 (anti-apoptose) ⇒ <b>persistance</b>.</p>
<p><span class="h">Culture / ECP</span> : cellules épithéliales humaines (HEp-2, HeLa, A549, KB) ; ECP en <b>« grappes de raisin »</b>, cellules arrondies réfringentes, <b>inclusions intranucléaires</b> ; 2–7 j (jusqu'à 3 sem). Types 40/41 : cellules <b>293</b> (Graham).</p>
<p><span class="h">Antigénie</span> : <b>hexon</b> = antigène de <b>groupe</b> commun (FC, ELISA, IF) ; <b>hexon + fibre</b> = antigènes <b>type-spécifiques</b> (neutralisation, inhibition de l'hémagglutination) ; <b>penton</b> = toxine-like (détachement cellulaire). <b>&gt; 115 types</b>, 7 espèces A–G.</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li>Réservoir <b>strictement humain</b> ; ubiquitaire, toute l'année ; <b>gouttelettes / aérosols</b>, <b>mains souillées</b>, <b>fécal-oral</b> (F), <b>conjonctival</b> (eau de piscine, instruments ophtalmo), greffon.</li>
<li>Épidémies en <b>collectivités</b> (crèches, casernes, hôpitaux) ; incubation 2–14 j (resp.), 3–10 j (dig.) ; <span class="r">excrétion prolongée</span> (pharynx, selles : semaines–mois).</li>
<li>Terrain : <b>enfant &lt; 5 ans</b> ; <span class="r">immunodéprimé</span> (greffe CSH / organe, VIH) : <b>réactivation</b> ⇒ formes disséminées graves.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>Récepteurs</b> : <b>CAR</b> (A, C, E, F, certains D) ; <b>CD46 / desmogléine 2</b> (B) ; <b>acide sialique / CD46</b> (D oculaires) ; internalisation par <b>intégrines</b> αvβ3/β5 (penton, motif RGD sauf F) ⇒ endocytose.</li>
<li><b>Cytolyse</b> directe de l'épithélium (respiratoire, conjonctival, entérocytes, urothélium) ; inclusions nucléaires.</li>
<li>Échappement immun : protéines <b>E3</b> (↓ MHC I, anti-TNF) ; <b>latence lymphoïde</b> (amygdales, adénoïdes).</li>
<li>Immunodéprimé : défaut de lymphocytes T ⇒ virémie, dissémination (poumon, foie, rein, tube digestif).</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Respiratoire</b> : rhinopharyngite, <b>angine</b>, bronchiolite, pneumonie ; <b>fièvre pharyngo-conjonctivale</b> (3, 7 : fièvre + pharyngite + conjonctivite + adénopathies) ; syndrome <b>coqueluchoïde</b>. <span class="r">Séquelle : bronchiolite oblitérante</span> (7, 3, 21).</li>
<li><b>Oculaire</b> : <b>kératoconjonctivite épidémique</b> (8, 19, 37), unilatérale puis bilatérale ; <span class="r">opacités cornéennes sous-épithéliales</span> (baisse d'acuité).</li>
<li><b>Digestif</b> : <b>GEA du nourrisson &lt; 2 ans</b> (40, 41), diarrhée aqueuse prolongée 1–2 sem ; adénite mésentérique, <b>invagination intestinale aiguë</b>.</li>
<li><b>Urinaire</b> : <b>cystite hémorragique</b> (11, 34, 35), néphrite chez le greffé rénal.</li>
<li><span class="r">Immunodéprimé : pneumonie, hépatite fulminante, colite, encéphalite, mortalité élevée</span>.</li>
</ul></div></div>

<ul>
<li><span class="r">Piège</span> : excrétion prolongée ⇒ PCR + ≠ responsabilité ; interpréter selon clinique et <b>charge virale</b>.</li>
<li><b>PCR temps réel</b> (multiplex) = <b>technique de choix</b> ; suivi hebdomadaire de la charge sanguine chez le greffé. Culture : lente, peu utilisée en routine ; <b>MET</b> des selles (virions icosaédriques).</li>
<li><b>Sérologie</b> : peu utile (FC antigène de groupe, 2 sérums à 15 j, ×4) ; rétrospective.</li>
<li><b>Typage</b> : séquençage <b>hexon / fibre</b> (épidémies, nosocomial) ; neutralisation.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Antiviraux</div><div class="bb"><ul>
<li><b>Aucun antiviral spécifique</b> à large AMM ; aciclovir <span class="r">inactif</span> ; ganciclovir sans efficacité clinique établie.</li>
<li><b>Cidofovir</b> (analogue nucléotidique, inhibe l'ADN polymérase) ; <b>brincidofovir</b> (prodrogue orale, moins néphrotoxique ; accès limité).</li>
<li>Résistance : <b>rare</b>, exceptionnelle en clinique (mutations ADN polymérase E2B, démontrées in vitro).</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Immunocompétent</b> : <b>symptomatique</b> (hydratation, antipyrétiques) ; <span class="r">pas d'antibiotique</span> (sauf surinfection). Kératoconjonctivite : lavage, collyre antiseptique ; corticoïde local si opacités (avis ophtalmo).</li>
<li><b>Forme grave / immunodéprimé</b> : <b>cidofovir 5 mg/kg/sem × 2 sem puis 1 fois/15 j</b> (ou 1 mg/kg 3×/sem) <b>+ probénécide + hydratation</b> (<span class="r">néphrotoxicité</span>) ; ↓ immunosuppression ; brincidofovir.</li>
<li><b>Vaccin</b> : vivant oral types 4 et 7 réservé aux <b>recrues militaires</b> (USA) ; <span class="r">absent du PEV algérien</span>.</li>
<li><b>Prévention</b> : lavage des mains (<b>eau + savon</b>, alcool peu actif), <b>eau de Javel</b>, stérilisation des instruments ophtalmo, chloration des piscines ; <b>isolement contact + gouttelettes</b> (chambre seule si immunodéprimé).</li>
<li><b>Déclaration</b> : pas de MDO spécifique en Algérie (sauf méningite / méningo-encéphalite virales, PAVM) ; signaler les <b>épidémies en collectivité / nosocomiales</b>.</li>
</ul></div></div>
