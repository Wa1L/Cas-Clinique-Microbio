<div class="box bl"><div class="bt">Principe et définitions</div><div class="bb">
<p><span class="h">Sérologie</span> = recherche d'<b>anticorps</b> (diagnostic <b>indirect</b>) dans le sérum/plasma (± LCR, salive) ; la recherche d'<b>antigènes</b> relève du diagnostic direct.</p>
<p><span class="h">IgM</span> : précoces (≈ 1 sem), transitoires (1–3 mois) ; <span class="h">IgG</span> : plus tardives, persistantes ; <span class="h">IgA</span> : muqueuses, peu utilisées.</p>
<p><span class="h">Séroconversion</span> (stricto sensu) : sérum négatif → positif. <span class="h">Ascension significative</span> : titre IgG × 4 (2 dilutions) sur 2 sérums appariés à 10–15 j, testés en parallèle. <span class="h">Fenêtre sérologique</span> : délai infection → Ac détectables. <span class="h">Séroprévalence</span> : % de sujets porteurs d'Ac dans une population.</p>
</div></div>

<div class="box db"><div class="bt">Techniques</div><div class="bb">
<table class="mt">
  <tr><th>Technique</th><th>Principe</th><th>Exemples</th></tr>
  <tr><td>ELISA / CLIA</td><td>Ag ou Ac sur phase solide + conjugué enzymatique/chimiluminescent : <b>Ag fixé</b> (indirect, IgG), <b>anti-μ fixé</b> (capture, IgM), <b>Ac fixé</b> (sandwich, Ag)</td><td>VIH, VHB, VHC, rubéole, CMV</td></tr>

<div class="box pu"><div class="bt">Autres profils à connaître (EBV, VIH, VHC)</div><div class="bb"><ul>
<li><span class="h">EBV</span> : VCA IgM+ IgG+ EBNA– = primo-infection (tout début : IgM+ IgG– EBNA–) ; VCA IgG+ EBNA+ = ancienne. MNI test (Ac hétérophiles) : orientation, <span class="r">souvent faussement négatif &lt; 4–5 ans</span>.</li>
<li><span class="h">VIH</span> : test combiné Ag/Ac 4e génération → si positif : immunoblot + charge virale sur P1, puis P2 pour un 2e test (identitovigilance). <span class="r">Primo-infection</span> : p24+ avec immunoblot négatif/indéterminé → la <b>charge virale</b> confirme. OMS (programmes) : stratégie à 3 tests, sans Western blot.</li>
<li><span class="h">VHC</span> : anti-VHC (ELISA) → <b>ARN VHC</b> réflexe : anti-VHC+ ARN– = guérison (spontanée ou AAD) ou faux +. Ac <span class="r">non protecteurs</span> (réinfection possible) ; anti-VHC parfois négatif (précoce, immunodéprimé).</li>
</ul></div></div>

<div class="box dr"><div class="bt">Limites et pièges d'interprétation</div><div class="bb"><ul>
<li><span class="r">Fenêtre sérologique</span> : négatif n'exclut pas (VIH, VHB, VHC) → Ag / PCR.</li>
<li><span class="r">IgM faux positives ou persistantes</span> : réactions croisées (flavivirus ; EBV/CMV), activation polyclonale, facteur rhumatoïde ; persistance de plusieurs mois (rubéole, CMV).</li>
<li><span class="r">Nouveau-né</span> : IgG maternelles transplacentaires (6–12 mois ; VIH jusqu'à 18 mois) → <b>PCR</b>.</li>
<li><span class="r">Immunodéprimés</span> : réponse tardive ou absente → PCR.</li>
<li><span class="r">Anticorps passifs</span> (Ig, transfusion) et <b>vaccin</b> : IgG non liées à l'infection.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Les utilisations de la sérologie</div><div class="bb"><ul>
<li><span class="h">Infection aiguë</span> : IgM, séroconversion, sérums appariés (VHA, rubéole, parvovirus B19, EBV, dengue, IgM anti-HBc).</li>
<li><span class="h">Infection chronique ou ancienne</span> : AgHBs, anti-VHC, Ac anti-VIH, anti-HTLV.</li>
<li><span class="h">Dépistage</span> : dons de sang/organes, grossesse (rubéole, VIH, VHB), bilan pré-greffe, IST, personnel de santé.</li>
<li><span class="h">Statut immunitaire / vaccinal</span> : rubéole, varicelle, rougeole, VHA, VHB (anti-HBs ≥ 10 UI/L), rage (neutralisants ≥ 0,5 UI/mL) → décision de vaccination ou de prophylaxie.</li>
<li><span class="h">Datation</span> : IgM + <b>avidité des IgG</b> (CMV) : forte avidité ⇒ infection &gt; 3–4 mois.</li>
<li><span class="h">Infection congénitale/périnatale</span> : IgM du nouveau-né (rubéole) ; <b>CMV</b> : PCR urine/salive dans les 2–3 premières sem (IgM peu sensibles) ; VIH : PCR.</li>
<li><span class="h">Suivi/pronostic</span> : VHB (AgHBe → anti-HBe ; perte AgHBs → anti-HBs), VIH, greffés.</li>
<li><span class="h">Diagnostic rétrospectif</span> (PCR/culture impossibles ou tardives) : virus respiratoires, arboviroses.</li>
<li><span class="h">Épidémiologie</span> : enquêtes de séroprévalence, immunité de groupe, évaluation du PEV.</li>
<li><span class="h">Typage antigénique</span> : IHA, séroneutralisation.</li>
<li><span class="h">Détection d'Ag</span> (volet direct) : AgHBs, p24, NS1 dengue, Ag rapides (SARS-CoV-2, VRS, rotavirus).</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li>IgM = infection <b>récente</b>, IgG = <b>passée</b> ; <span class="r">IgM seules insuffisantes</span> → 2e sérum, avidité, PCR.</li>
<li><span class="r">Sérologie négative ≠ pas d'infection</span> (fenêtre, immunodépression) ; <span class="r">nouveau-né → PCR</span>.</li>
<li>Phase précoce : diagnostic <b>direct</b> (PCR, Ag) ; phase tardive ou rétrospective : <b>sérologie</b>.</li>
<li>Virus chroniques (VIH, VHB, VHC) : lecture par <b>profil de marqueurs</b>, jamais un seul résultat.</li>
</ul></div></div>
