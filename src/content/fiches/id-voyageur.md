<div class="box db"><div class="bt">Lecture du frottis sanguin — points clés</div><div class="bb"><ul>
<li><span class="h">P. falciparum</span> : anneaux fins, polyparasitisme, hématies non hypertrophiées, gamétocytes en banane ; <span class="r">schizontes circulants = gravité</span>.</li>
<li><span class="h">P. vivax / ovale</span> : hématies hypertrophiées, granulations de Schüffner ; tous stades visibles.</li>
<li><span class="h">P. knowlesi</span> (Asie SE) : mime <i>P. falciparum</i> (jeunes) et <i>P. malariae</i> (âgés) ; cycle 24 h → aggravation rapide ; <span class="r">TDR HRP2 souvent négatif</span> → PCR.</li>
<li><span class="h">Parasitémie</span> : &gt; 4 % = gravité chez l'adulte non immun (SPILF) ; <b>OMS : &gt; 10 %</b> (idem enfant en France).</li>
<li><span class="h">Après artésunate IV</span> : contrôle J3-J7-J14-J21-J28 + dépistage de l'<b>anémie hémolytique retardée (PADH)</b>.</li>
<li><span class="h">Babesia</span> : anneaux sans pigment ni gamétocytes, tétrades ; asplénie / tiques.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Pourquoi l'ID aggrave — mécanismes</div><div class="bb"><ul>
<li><b>Anguillulose</b> : auto-infestation ; corticoïdes → hyperinfection, larves entraînant des <b>BGN entériques</b> → bactériémie, méningite.</li>
<li><b>Leishmania, Histoplasma, Talaromyces</b> : intramacrophagiques, contrôlés par l'axe Th1 / IFN-γ / TNF → déficit CD4 ou anti-TNF = dissémination.</li>
<li><b>Rate</b> : clairance des hématies parasitées → asplénie = parasitémies élevées.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Biosécurité et BMR — rôle du laboratoire</div><div class="bb"><ul>
<li><b>FHV suspecte</b> : aucun examen hors circuit dédié ; avis infectiologue + LBM de référence (P3/P4).</li>
<li><b>Prévenir le labo</b> : <i>Brucella</i>, <i>B. pseudomallei</i>, <i>Histoplasma</i>, <i>Coccidioides</i> → <b>P3</b> <span class="r">(contaminations de laboratoire)</span>.</li>
<li>Hospitalisation à l'étranger dans l'année → dépistage <b>BHRe</b> (EPC, ERV) + précautions contact.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Prévention — avant le départ de l'ID</div><div class="bb"><ul>
<li><span class="r">Vaccins vivants contre-indiqués</span> si ID sévère : fièvre jaune 17D, typhoïde orale, <b>dengue (Qdenga®)</b>, <b>chikungunya (Ixchiq®)</b> → certificat de contre-indication. Alternative non vivante pour le chikungunya : <b>VLP (Vimkunya®)</b>.</li>
<li>Dépistage <b>anguillulose</b> (sérologie) ± ivermectine présomptive avant corticoïdes/greffe ; IGRA avant anti-TNF ; sérologie Chagas avant greffe si Amérique latine.</li>
<li>Chimioprophylaxie antipaludique + protection anti-vectorielle ; interactions avec ARV / immunosuppresseurs.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">Toute fièvre au retour de zone d'endémie = paludisme jusqu'à preuve du contraire</span> ; un seul frottis négatif ne l'exclut pas.</li>
<li>Chez l'ID, <b>privilégier les méthodes directes</b> (PCR, Ag, culture, myélogramme) : sérologie peu sensible.</li>
<li>Corticoïdes chez un ancien voyageur (même des décennies plus tôt) → penser <b>anguillulose maligne</b> ; éosinophilie normale ne l'exclut pas.</li>
<li>Asplénie + frottis « falciparum-like » → évoquer <b>babésiose</b>.</li>
</ul></div></div>
