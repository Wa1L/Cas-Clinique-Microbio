<div class="box bl"><div class="bt">Caractères virologiques</div><div class="bb">
<p><span class="h">Virion</span> : <b>plus grand virus humain / des vertébrés</b> (200–400 nm), « en brique » (Orthopox) ou ovoïde en pelote (Parapox) ; <b>limite de résolution du MO</b> (on voit surtout les inclusions ; forme « en brique » = ME) ; <b>pas de capside</b> vraie : noyau biconcave + 2 corps latéraux ; enveloppe (formes <b>IMV</b> mature intracellulaire et <b>EEV</b> enveloppée extracellulaire, dissémination).</p>
<p><span class="h">Génome</span> : ADN bicaténaire linéaire, <b>130–300 kb</b> (Orthopox ~190 kb), extrémités fermées en épingle à cheveux + répétitions terminales inversées (ITR) ; ~200 gènes.</p>
<p><span class="h">Réplication</span> : <b>entièrement CYTOPLASMIQUE</b> (« usines virales » = viroplasmes), indépendante du noyau ; <b>enzymes virales propres</b> (ARN polymérase ADN-dépendante, ADN polymérase, enzymes de coiffage / polyadénylation) ; virion <b>résistant</b> (dessiccation, croûtes infectieuses des mois).</p>
<p><span class="h">Culture / ECP</span> : œuf embryonné (membrane chorio-allantoïdienne → <b>pocks</b>), cellules Vero, MRC-5 : ECP arrondissement + <b>inclusions cytoplasmiques éosinophiles</b> (corps de Guarnieri). Molluscum : <span class="r">non cultivable</span> (corps de Henderson-Paterson en histologie). Culture variole : <span class="r">P4 uniquement</span>.</p>
<p><span class="h">Antigénie</span> : <b>forte réactivité croisée entre Orthopox</b> ⇒ vaccine protège contre variole et mpox ; antigènes de nucléoprotéine communs ; <span class="r">sérologie non discriminante</span> entre espèces du genre.</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li><b>Variole</b> : dernier cas naturel Somalie 1977 ; éradication par <b>vaccination en anneau</b> (OMS, 1980) ; vaccination arrêtée ⇒ <span class="r">population naïve</span> (nés après 1980, &lt; 45–50 ans).</li>
<li><b>Mpox</b> : zoonose d'Afrique centrale/ouest ; <b>transmission interhumaine</b> : contact direct peau-lésions, gouttelettes (contact étroit), objets souillés, sexuelle, materno-fœtale. PHEIC 2022-23 (IIb) et 2024-25 (Ib).</li>
<li>Terrain à risque : enfants, <b>immunodéprimés (VIH non contrôlé)</b>, femmes enceintes.</li>
<li><b>Molluscum</b> : contact cutané, piscines, auto-inoculation, IST. <b>Orf</b> : contact animal (non interhumain).</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>Variole</b> : voie respiratoire → réplication locale → ganglions → <b>virémie 1</b> → RES (rate, foie, moelle) → <b>virémie 2</b> → peau et muqueuses (lésions toutes <span class="r">synchrones</span>).</li>
<li><b>Facteurs de virulence</b> : protéines d'<b>échappement immunitaire</b> codées par le virus (récepteurs leurres cytokines / IFN, inhibiteurs du complément, serpines, inhibiteurs d'apoptose) ; <b>EEV</b> : dissémination cellule à cellule (comètes d'actine).</li>
<li><b>Immunité</b> : surtout cellulaire (LT CD8) + Ac neutralisants ; infection cutanée <b>localisée prolongée</b> (pas de latence) (molluscum : sans virémie, inhibition de l'apoptose épidermique).</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Variole</b> : incubation 10–14 j ; fièvre brutale 39–40 °C, algies (lombaires), 2–4 j ; énanthème puis éruption <b>centrifuge</b> : macule → papule → vésicule → <b>pustule ombiliquée</b> → croûte (2–3 sem) ; <span class="r">séquelles : cicatrices indélébiles, cécité</span> ; formes <b>hémorragique et maligne</b> mortelles.</li>
</ul>

<ul>
<li><b>Mpox</b> : incubation 3–21 j ; fièvre + <span class="r">adénopathies (distinguent de la variole)</span> ; éruption plus pauci-lésionnelle, souvent ano-génitale ; complications : surinfection, encéphalite, kératite.</li>
<li><b>Molluscum</b> : papules perlées ombiliquées 2–5 mm, bénin ; guérison en 6–12 mois. <b>Orf</b> : nodule unique ombiliqué du doigt, guérison ~6 sem.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : liquide de vésicule, croûtes, écouvillon de lésion, biopsie. <span class="r">Suspicion de variole : alerte OMS immédiate, aucune manipulation hors P4 (CDC, VECTOR)</span> ; IPA = référence nationale mpox.</li>
<li><b>Direct</b> : <b>PCR en temps réel</b> (méthode de choix) : Orthopoxvirus générique + <b>MPXV spécifique, clades I / II</b> ; ME en coloration négative : virion en brique (<span class="r">ne distingue pas</span> variole / mpox) ; histologie : inclusions.</li>
<li><b>Culture</b> : œuf / cellules, réservée aux labos de référence (P3-P4). <b>Sérologie</b> : IgM/IgG ELISA, <span class="r">réactions croisées Orthopox</span> ⇒ rétrospective.</li>
<li><b>Molluscum, Orf</b> : clinique ± histologie / PCR / ME.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Antiviraux (ATB inactifs : virus)</div><div class="bb"><ul>
<li><b>Tecovirimat</b> (TPOXX, ST-246) : inhibe <b>p37 (F13L)</b>, enveloppement ⇒ bloque la formation d'<b>EEV</b> ; <span class="r">résistance : mutations F13L</span> ; <span class="r">non recommandé dans le mpox</span> (PALM007, STOMP négatifs ; EMA 2026, à vérifier) ; réservé variole / cowpox / complications vaccinales.</li>
<li><b>Cidofovir</b> (IV) / <b>brincidofovir</b> (oral, prodrogue) : inhibent l'<b>ADN polymérase</b> virale ; cidofovir néphrotoxique (<span class="r">hydratation + probénécide</span>).</li>
<li><b>VIGIV</b> : complications vaccinales graves.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Mpox</b> : symptomatique ; antiviral si forme sévère / immunodéprimé ; <b>isolement</b> jusqu'à chute des croûtes.</li>
<li><b>Vaccins</b> : réplicatifs (Vaccinia, ACAM2000 : scarification, <span class="r">CI : immunodéprimés, eczéma, grossesse</span>) ; <b>MVA-BN</b> (Jynneos) non réplicatif, <b>2 doses à 28 j</b>, cible mpox ; LC16m8 (Japon, RDC). Post-exposition efficace si &lt; 4 j.</li>
<li><span class="r">Vaccination antivariolique absente du PEV algérien</span> (arrêtée depuis l'éradication).</li>
<li><b>Prévention</b> : précautions <b>air + contact</b>, traçage et vaccination des contacts, préservatifs ; <b>molluscum</b> : curetage, cryothérapie, cantharidine ; <b>déclaration</b> : variole = MDO + notification RSI immédiate ; mpox = alerte, cas suspects aux DSP / SEMEP.</li>
</ul></div></div>
