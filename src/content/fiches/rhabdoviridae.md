<div class="box bl"><div class="bt">Caractères virologiques</div><div class="bb">
<p><span class="h">Virion</span> : enveloppé, en <b>forme de balle</b> (« bullet-shaped »), 180 × 75 nm ; capside hélicoïdale ; spicules de <b>glycoprotéine G</b> ; <span class="r">fragile</span> : inactivé par solvants des lipides, savon, UV, chaleur (56 °C), dessiccation.</p>
<p><span class="h">Génome</span> : ARN (–) monocaténaire, ≈ 12 kb, non segmenté ; ordre 3'-<b>N–P–M–G–L</b>-5'. N = nucléoprotéine ; P = phosphoprotéine (cofacteur de L) ; M = matrice ; G = glycoprotéine ; L = ARN polymérase ARN-dépendante.</p>
<p><span class="h">Réplication</span> : <b>cytoplasmique</b> ; ARN (–) ⇒ transcription par la L virale (virion apporte sa polymérase) ; ARN génome seul <b>non infectieux</b>. Bourgeonnement à la membrane plasmique.</p>
<p><span class="h">Culture / ECP</span> : cellules de neuroblastome (N2a), BHK-21, Vero ; ECP faible ⇒ révélation par IFD. <b>Corps de Negri</b> : inclusions éosinophiles intracytoplasmiques des neurones (Ammon, Purkinje) ; <span class="r">absents dans ≈ 20 % des cas</span> : n'éliminent jamais la rage.</p>
<p><span class="h">Antigénie</span> : <b>G</b> = antigène protecteur (anticorps neutralisants, base du vaccin) ; <b>N</b> = antigène de groupe, cible de l'IFD ; <b>≥ 18 espèces ICTV / 3 phylogroupes</b> : <b>PG I</b> RABV, DUVV, EBLV-1/2, ABLV (couverts par le vaccin) ; <b>PG II</b> LBV, MOKV, SHIBV (protection insuffisante) ; <b>PG III</b> WCBV, IKOV, LLEBV (<span class="r">aucune protection</span>).</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li>Zoonose mondiale (sauf Antarctique) ; <b>≈ 59 000 décès/an</b>, surtout Asie et Afrique, ≈ 40 % <b>enfants</b>.</li>
<li>Réservoir <b>chien</b> (rage urbaine, Algérie, Afrique, Asie) ; faune sauvage (renard, chacal) ; <b>chauves-souris</b> (Amériques, Europe).</li>
<li>Transmission : <b>morsure</b> ou griffure, léchage de peau lésée / muqueuse ; rarement greffe (cornée, organes). Transmission interhumaine exceptionnelle.</li>
<li><b>Incubation 1–3 mois</b> (de quelques jours à &gt; 1 an) : plus courte si morsure à la <b>face / tête</b>, plaies multiples, inoculum élevé.</li>
<li>Algérie : endémique, <b>MDO</b> ; ≈ 15–20 cas humains/an, &gt; 240 000 morsures/an (à vérifier) ; chiens errants = principal risque.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li>Inoculation ⇒ réplication locale (<b>myocytes</b>) ⇒ fixation de G aux <b>récepteurs nicotiniques de l'acétylcholine</b> (jonction neuromusculaire), NCAM, p75NTR.</li>
<li><b>Ascension rétrograde</b> axonale (dynéine, 50–100 mm/j) jusqu'au SNC : moelle, tronc cérébral, hippocampe, cervelet. <span class="r">Phase silencieuse : pas de virémie, pas d'anticorps</span>.</li>
<li>Peu de lésions neuronales et d'inflammation ⇒ dysfonction neuronale ⇒ <b>hydrophobie</b> (tronc cérébral).</li>
<li>Dissémination <b>centrifuge</b> : glandes salivaires (excrétion salivaire), cornée, peau de la nuque (follicules pileux), surrénales.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Prodrome</b> (2–10 j) : fièvre, malaise ; <span class="r">paresthésies / prurit / douleur au site de morsure (très évocateur)</span>.</li>
<li><b>Forme furieuse</b> (≈ 80 %) : agitation, hallucinations, <b>hydrophobie</b>, <b>aérophobie</b>, hypersalivation, spasmes pharyngés, intervalles lucides ; mort en 2–7 j (arrêt cardiorespiratoire).</li>
<li><b>Forme paralytique</b> (≈ 20 %) : paralysie ascendante type Guillain-Barré, évolution plus longue.</li>
<li><span class="r">Une fois les symptômes déclarés : évolution fatale presque constante</span> ; coma puis décès.</li>
<li>DD : tétanos, Guillain-Barré, encéphalites virales, <b>pseudo-rage</b> hystérique.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement ante mortem</b> : <b>salive</b> (RT-PCR, répéter), <b>biopsie cutanée de nuque</b> (follicules pileux : IFD + RT-PCR), LCR, sérum (anticorps si non vacciné). <b>Post mortem</b> : <b>cerveau</b> (corne d'Ammon, cervelet, tronc) <span class="r">; fixation au formol déconseillée pour l'IFD</span> ; conserver à +4 °C ou congelé.</li>
<li><b>Direct</b> : <b>IFD</b> anti-N sur cerveau (<b>référence</b>, rapide, très sensible) ; histologie : corps de Negri (peu sensible).</li>
<li><b>Culture</b> sur cellules (N2a) + IFD ; <b>RT-PCR</b> (N) ; test de neutralisation <b>RFFIT</b> (seuil protecteur <b>≥ 0,5 UI/mL</b>).</li>
<li><b>Typage</b> : séquençage du gène N, anticorps monoclonaux (génotype, variant canin / chiroptère).</li>
<li><span class="r">Sécurité : manipuler sous PSM, laborantins vaccinés ; inoculation à la souris remplacée par culture cellulaire / RT-PCR (OMS 2018), tolérée en dernier recours</span>.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Antiviraux</div><div class="bb"><ul>
<li><b>Aucun antiviral efficace</b> à ce jour ; ribavirine, interféron, kétamine, amantadine ≈ <span class="r">sans bénéfice</span> ; protocole de Milwaukee = <span class="r">non validé</span>.</li>
<li>Pas d'antibiogramme : prévention = seule arme (vaccin + immunoglobulines).</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Curatif</b> : aucun ⇒ soins palliatifs (sédation, isolement).</li>
<li><b>Soins de la plaie</b> : lavage immédiat <b>eau + savon 15 min</b>, antiseptique (polyvidone iodée) ; <span class="r">pas de suture immédiate</span>.</li>
<li><b>PEP selon OMS</b> : <b>cat. I</b> (contact peau intacte) = rien ; <b>cat. II</b> (peau nue, éraflures) = <b>vaccin</b> ; <b>cat. III</b> (morsure transdermique, muqueuse, chauve-souris) = <b>vaccin + immunoglobulines</b> (HRIG 20 UI/kg, ERIG 40 UI/kg, infiltration péri-plaie ; <span class="r">reliquat non injecté à distance (OMS 2018) ; inutiles &gt; J7 après la 1<sup>re</sup> dose</span>).</li>
<li><b>Vaccin</b> sur culture cellulaire : <b>Essen abrégé 4 doses</b> J0-J3-J7-J14 (OMS 2018, immunocompétent) ; <b>5 doses</b> J0-J3-J7-J14-J28 (immunodéprimé, protocoles nationaux ; instruction ministérielle n° 16 de juillet 2024, à vérifier) ; <b>Zagreb</b> 2-1-1 ; voie ID (OMS 2018 : J0-J3-J7). Vaccin <b>hors PEV</b> (pré-exposition : vétérinaires, laborantins, voyageurs ; J0-J7).</li>
<li><b>Animal mordeur</b> : surveillance vétérinaire <b>10 j (OMS) / 15 j (réglementation algérienne : 3 visites J0-J7-J15)</b> ; si sain à la fin, pas d'excrétion lors de la morsure ; <span class="r">si rage suspecte ⇒ vacciner sans attendre</span>.</li>
<li><b>Déclaration obligatoire</b> ; vaccination des chiens (≥ 70 % de couverture).</li>
</ul></div></div>
