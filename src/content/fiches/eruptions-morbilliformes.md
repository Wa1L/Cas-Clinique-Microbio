<div class="box br"><div class="bt">Définition et cadre</div><div class="bb"><ul>
<li><span class="h">Exanthème morbilliforme</span> : éruption maculo-papuleuse rosée, généralisée, ± confluente, sur peau saine ; <b>ni vésiculeuse ni purpurique</b>.</li>
<li><span class="r">Clinique peu spécifique</span> (sauf rougeole typique) : rubéole, B19, HHV-6, entérovirus, adénovirus se ressemblent → <b>confirmation biologique</b>.</li>
<li>Non viral à éliminer : <b>toxidermie</b> (cause fréquente chez l'adulte), scarlatine, syphilis II, rickettsiose, Kawasaki.</li>
<li>Maladies éruptives classiques : <b>1re rougeole</b> · 2e scarlatine · <b>3e rubéole</b> · 4e Dukes-Filatov (non retenue) · <b>5e mégalérythème (B19)</b> · <b>6e roséole (HHV-6)</b>.</li>
</ul></div></div>

<div class="box or"><div class="bt">Orientation clinique → étiologie</div><div class="bb"><ul>
<li><b>Koplik</b> + 3 C + éruption descendante → <b>rougeole</b>.</li>
<li><b>Adénopathies rétro-auriculaires</b> + éruption discrète → <b>rubéole</b>.</li>
<li><b>Joues rouges</b> puis dentelle des membres → <b>B19</b>.</li>
<li>Fièvre 3–5 j du nourrisson, éruption à l'apyrexie → <b>HHV-6B / 7</b>.</li>
<li>Angine + adénopathies, éruption sous aminopénicilline → <b>EBV</b>.</li>
<li>Retour de zone tropicale + arthralgies / conjonctivite → <b>arbovirose</b>.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Conduite à tenir / prévention</div><div class="bb"><ul>
<li><b>Rougeole</b> : isolement respiratoire (air), déclaration (surveillance cas par cas) ; contacts : vaccin ≤ 72 h ou Ig polyvalentes ≤ 6 j ; vitamine A chez l'enfant (OMS).</li>
<li><b>Rubéole</b> : femme enceinte au contact → sérologie IgG en urgence ; vaccin vivant <span class="r">contre-indiqué en grossesse</span>.</li>
<li><b>B19</b> : femme enceinte exposée → IgG / IgM, surveillance échographique (anasarque fœtoplacentaire) ; drépanocytaire → crise aplasique.</li>
<li><b>HHV-6</b> : symptomatique ; antiviraux (ganciclovir, foscarnet) réservés aux formes graves de l'immunodéprimé.</li>
</ul></div></div>

  <tr><td>Arbovirus</td><td>RT-PCR / NS1 (dengue) (phase fébrile, ≤ J5–7) ; IgM ensuite</td><td>Réactions croisées entre flavivirus (dengue / Zika) ; chikungunya : RT-PCR précoce puis IgM</td></tr>
  <tr><td>VIH</td><td>Test combiné Ag p24-Ac (4e gén.) + ARN plasmatique</td><td>Ac encore négatifs possible → <b>ARN VIH</b> ; contrôle sérologique à distance</td></tr>

<div class="box dr"><div class="bt">Pièges et limites du diagnostic</div><div class="bb"><ul>
<li><span class="r">IgM rougeole</span> : faux négatifs si prélèvement &lt; 72 h (≈ 23 %) ; faux positifs fréquents hors épidémie → ne jamais se fier aux IgM seules.</li>
<li><span class="r">Post-vaccinal</span> : IgM rougeole et rubéole non interprétables après ROR récent (rubéole : <b>6–45 j</b>) → RT-PCR discriminante / séquençage (rougeole : génotype A = vaccin).</li>
<li><span class="r">Rougeole modifiée</span> (vacciné) : éruption atténuée, IgM absentes → RT-PCR.</li>
<li><span class="r">HHV-6 chromosomiquement intégré</span> (≈ 1 % de la population) : charge virale très élevée et persistante → <b>fausse infection active</b> ; PCR numérique / charge par cellule.</li>
<li><b>B19</b> : PCR peut rester positive jusqu'à 9 mois → ne prouve pas l'infection aiguë.</li>
<li><b>Toxidermie</b> : prise médicamenteuse récente, prurit, éosinophilie ; rickettsiose (escarre d'inoculation) à ne pas rater.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">Rougeole = urgence de santé publique</span> : RT-PCR + IgM au <b>1er contact</b>, sans attendre l'éruption pleine ni la sérologie.</li>
<li>Clinique seule non fiable : <b>rubéole ≈ B19 ≈ HHV-6 ≈ entérovirus</b> → confirmer si rougeole / rubéole suspectée ou <b>femme enceinte</b>.</li>
<li>IgM : <span class="r">faux – précoces (&lt; 72 h)</span>, faux + par réactions croisées (B19, EBV…), interférence vaccinale.</li>
<li>B19 : éruption = phase immunologique (<b>plus contagieux avant l'éruption</b>) ; HHV-6 : éruption à la <b>défervescence</b>.</li>
</ul></div></div>
