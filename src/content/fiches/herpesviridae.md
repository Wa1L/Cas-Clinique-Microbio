<div class="box bl"><div class="bt">Caractères virologiques</div><div class="bb">
<p><span class="h">Virion</span> : sphérique 120–200 nm ; capside icosaédrique (162 capsomères) + <b>tégument</b> + <b>enveloppe</b> (glycoprotéines gB, gD…) ⇒ <span class="r">fragile, sensible à l'éther</span>, transmission par contact étroit.</p>
<p><span class="h">Génome</span> : <b>ADN bicaténaire linéaire</b>, 125–240 kb.</p>
<p><span class="h">Réplication</span> : <b>noyau</b> ; cascade de gènes α (IE) → β (E : <b>TK</b>, <b>ADN pol</b>) → γ (L, structuraux) ; enveloppement primaire sur la membrane nucléaire interne → désenveloppement (membrane externe) → <b>enveloppement définitif dans le TGN</b> (Golgi) → exocytose. <b>Latence</b> : génome épisomique circulaire ; réactivation possible.</p>
<p><span class="h">Culture / ECP</span> : <b>HSV</b> : 24–72 h, cellules ballonisées, <b>cellules géantes multinucléées</b>, inclusions intranucléaires. <b>CMV</b> : lente (2–3 sem.), cellules en « œil de hibou », shell-vial. <b>VZV</b> : difficile. <b>EBV</b> : pas de culture de routine.</p>
<p><span class="h">Antigénie</span> : HSV-1 / HSV-2 : <b>gG-1 / gG-2</b> (sérologie type-spécifique). EBV : <b>VCA, EA, EBNA</b>. CMV : pp65 (antigénémie).</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li>Réservoir <b>strictement humain</b> ; ubiquitaire ; <b>infection à vie</b> (latence).</li>
<li><b>HSV-1</b> : salive, contact (primo-infection dans l'enfance). <b>HSV-2</b> : sexuelle, périnatale. <b>VZV</b> : <b>aérienne</b> (gouttelettes) + vésicules, très contagieux. <b>EBV</b> : salive (« maladie du baiser »). <b>CMV</b> : salive, urines, lait, sexuel, <b>transplacentaire</b>, greffe / transfusion.</li>
<li>Terrain : immunodépression (VIH, greffe, chimiothérapie) ⇒ <span class="r">réactivations et formes sévères</span>.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li>Primo-infection (muqueuse) → virémie / diffusion neurale → <b>latence</b> → <b>réactivation</b> (stress, UV, fièvre, immunodépression).</li>
<li>Échappement immunitaire (↓ CMH I, latence) ; immunité cellulaire (T CD8+) = clé du contrôle.</li>
<li><b>Oncogenèse</b> : EBV (<b>LMP1</b>, EBNA), HHV-8 (cofacteur VIH).</li>
<li><b>CMV congénital</b> : primo-infection maternelle → transmission 30–40 % (↑ avec le terme) ; <span class="r">séquelles graves surtout si 1<sup>er</sup> trimestre</span>.</li>
<li><b>Herpès néonatal</b> : contamination au passage de la filière génitale (primo-infection maternelle tardive = risque max).</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>HSV-1</b> : gingivostomatite, herpès labial récurrent, kératite dendritique ; <span class="r">encéphalite nécrosante temporale = urgence</span>, séquelles lourdes.</li>
<li><b>HSV-2</b> : herpès génital (primo-infection sévère, récurrences) ; <span class="r">herpès néonatal</span> (cutanéo-muqueux, SNC, disséminé).</li>
<li><b>VZV</b> : varicelle (vésicules <b>par poussées</b>, polymorphes) ; <b>zona</b> radiculaire unilatéral, <span class="r">névralgies post-zostériennes</span> ; varicelle congénitale / néonatale.</li>
<li><b>EBV</b> : <b>MNI</b> (angine, ADP, splénomégalie, syndrome mononucléosique) ; Burkitt, NPC, Hodgkin.</li>
<li><b>CMV</b> : congénital (<span class="r">surdité, microcéphalie, calcifications périventriculaires, choriorétinite</span>, HSMG) ; immunodéprimé : rétinite, colite, pneumonie.</li>
<li><b>HHV-6</b> : fièvre 3 j puis éruption à la défervescence (convulsions fébriles).</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : vésicule (écouvillon), LCR, sang / plasma, urines, LBA, biopsie. <span class="r">PCR HSV du LCR peut être négative avant 72 h ⇒ répéter</span>.</li>
<li><b>Direct</b> : <b>PCR (référence)</b> ; Tzanck (cellules géantes, peu sensible / non spécifique) ; IF directe ; <b>antigénémie pp65</b> (CMV). Culture : HSV (rapide), CMV (shell-vial).</li>
<li><b>Sérologie</b> : IgM / IgG ; <b>avidité des IgG</b> (datation d'une primo-infection CMV) ; <span class="r">IgG persistent à vie</span> ⇒ une sérologie seule ne diagnostique pas une réactivation. <b>EBV</b> : MNItest / Paul-Bunnell (anticorps hétérophiles).</li>
</ul>

<div class="box dr"><div class="bt">Antiviraux et résistance</div><div class="bb"><ul>
<li><b>Aciclovir</b> (HSV, VZV) : analogue guanosine, <b>phosphorylé par la TK virale</b> → inhibe l'ADN pol. Inactif sur EBV / HHV-8 (en clinique).</li>
<li><b>Ganciclovir</b> (CMV) : activé par la kinase <b>UL97</b> ; <b>foscarnet</b> et <b>cidofovir</b> : actifs sans activation virale.</li>
<li>Résistance HSV / VZV : <b>mutation TK</b> (UL23 HSV ; ORF36 VZV) ⇒ croisée aciclovir / valaciclovir / famciclovir → <b>foscarnet</b>. CMV : <b>UL97</b> (ganciclovir) ; <b>UL54</b> (ADN pol) ⇒ résistance croisée possible. <span class="r">Surtout chez l'immunodéprimé</span>.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Encéphalite herpétique</b> : aciclovir IV 10 mg/kg/8 h, 14–21 j, <span class="r">sans attendre la PCR</span>. <b>Herpès néonatal</b> : 20 mg/kg/8 h, 14 j (cutanéo-muqueux) ou 21 j (SNC / disséminé).</li>
<li><b>Herpès génital / labial</b> : valaciclovir PO ; <b>zona</b> : valaciclovir 1 g × 3/j, 7 j, idéalement &lt; 72 h. <b>Varicelle</b> : symptomatique ; aciclovir IV chez l'immunodéprimé.</li>
<li><b>CMV</b> : ganciclovir IV 5 mg/kg/12 h (2–3 sem.) puis valganciclovir ; prophylaxie / préemptif en greffe. <b>MNI</b> : symptomatique, <span class="r">aminopénicillines (ampicilline, amoxicilline) proscrites (rash)</span>.</li>
<li><b>Prévention</b> : vaccin varicelle (vivant atténué) et zona (recombinant ≥ 50 ans) : <b>hors PEV algérien</b>. <b>Ig spécifiques anti-VZV</b> : femme enceinte non immune, nouveau-né, immunodéprimé exposés. Césarienne si lésions génitales actives à l'accouchement ; hygiène des mains (CMV, grossesse) ; produits sanguins CMV-négatifs.</li>
</ul></div></div>
