<div class="box bl"><div class="bt">Caractères bactériologiques</div><div class="bb">
<p><span class="h">Morphologie</span> : bacilles Gram – <b>fins, incurvés</b> (0,2–0,5 × 0,5–5 µm), en <b>virgule / S / « ailes de mouette »</b> ; non sporulés ; <b>flagelle polaire</b> (à 1 ou aux 2 pôles) ⇒ mobilité <b>en vrille / « vol de moucherons »</b> à l'état frais ; formes coccoïdes dans les vieilles cultures. <span class="r">Piège : contre-coloration prolongée (fuchsine) sinon mal colorés.</span></p>
<p><span class="h">Exigences</span> : <b>microaérophiles</b> (O₂ 5 %, CO₂ 10 %, N₂ 85 %, sachets générateurs) ; <b>thermophiles</b> (<i>C. jejuni</i>, <i>C. coli</i> : 42 °C = température aviaire) ; fragiles (air, dessiccation, pH acide) ; <b>asaccharolytiques</b> (n'utilisent pas les sucres).</p>
<p><span class="h">Culture</span> : gélose <b>Skirrow</b> (sang + vancomycine, polymyxine B, triméthoprime), <b>Butzler</b>, <b>Karmali / CCDA</b> (charbon) ; <b>42 °C, microaérophilie, 48 h</b> (lecture 24–72 h) ; 37 °C en parallèle pour <i>C. fetus</i> ; enrichissement : bouillon de Preston. Colonies <b>grises, plates, humides, étalées</b> (« goutte d'eau »), non hémolytiques.</p>
<p><span class="h">Biochimie</span> : <b>oxydase +</b>, <b>catalase +</b> (sauf <i>C. upsaliensis</i>) ; nitrate réduit + ; <b>hydrolyse de l'hippurate + = <i>C. jejuni</i></b> ; <b>uréase –</b> <span class="r">(≠ <i>Helicobacter pylori</i>, ex-<i>C. pylori</i>)</span> ; ni fermentation ni oxydation des sucres.</p>
<p><span class="h">Antigénie</span> : <b>Penner</b> (thermostable, LPS / capsule) et <b>Lior</b> (thermolabile) ; <b>LOS</b> mimant les gangliosides (GM1, GD1a) ; flagelline <i>flaA</i> ; typage MLST.</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li><b>1re cause de gastro-entérite bactérienne</b> dans les pays industrialisés ; <b>zoonose</b> ; pic estival.</li>
<li>Réservoir : tube digestif des <b>oiseaux (volaille +++)</b>, bovins, porcs, chiens, chats ; eau contaminée.</li>
<li>Transmission : <b>volaille insuffisamment cuite</b>, <span class="r">contamination croisée en cuisine</span>, lait cru, eau non traitée, contact animal ; <b>faible dose infectante</b> (~10²–10³ germes) ; interhumaine rare.</li>
<li>Terrain : enfant &lt; 5 ans, adulte jeune, <b>diarrhée du voyageur</b> ; <i>C. fetus</i> : immunodéprimé, cirrhotique, âgé ; ruminants (avortements).</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>Flagelle + mobilité en hélice</b> dans le mucus ; adhésion (<b>CadF, FlpA</b>) et <b>invasion</b> de l'épithélium iléo-colique (Cia) ⇒ colite inflammatoire.</li>
<li><b>Toxine CDT</b> (<i>cdtA/B/C</i>) : arrêt du cycle cellulaire G2/M ⇒ apoptose.</li>
<li><span class="r">Mimétisme moléculaire</span> : LOS ↔ gangliosides du nerf périphérique ⇒ auto-anticorps ⇒ <b>Guillain-Barré</b> (GM1, GD1a) ; Miller Fisher (GQ1b).</li>
<li><i>C. fetus</i> : <b>couche S (protéines SAP)</b> ⇒ résistance au complément + variation antigénique ⇒ bactériémie, localisations vasculaires.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Entérite aiguë</b> (<i>C. jejuni / coli</i>) : incubation 2–5 j ; prodrome fébrile (fièvre, céphalées, myalgies), puis diarrhée aqueuse ⇒ <b>glairo-sanglante</b>, douleurs abdominales intenses <b>pseudo-appendiculaires</b> ; guérison spontanée en 5–7 j.</li>
<li><span class="r">Complications post-infectieuses</span> (1–3 sem après) : <b>syndrome de Guillain-Barré</b> (~1/1000, séquelles motrices possibles), Miller Fisher, <b>arthrite réactionnelle</b> (HLA-B27), SII post-infectieux.</li>
<li><b><i>C. fetus</i></b> : <b>bactériémie</b>, endocardite, méningite, thrombophlébite ; terrain débilité ; avortement / infection néonatale ; diarrhée inconstante.</li>
<li>Rares : cholécystite, péritonite, pseudo-appendicite.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : selles fraîches, ensemencement rapide (&lt; 2 h) ou <b>milieu de transport Cary-Blair</b> ; <span class="r">fragile à l'air / dessiccation</span> ; hémocultures si fièvre / terrain à risque (<i>C. fetus</i>).</li>
<li><b>Direct</b> : état frais (contraste de phase) : bacilles incurvés <b>mobiles en vrille</b> ; Gram (fuchsine).</li>
<li><b>Culture</b> : Skirrow / Karmali, <b>42 °C, microaérophilie, 48 h</b> ; <span class="r"><i>C. upsaliensis</i> : filtration (0,65 µm) sur gélose au sang non sélective.</span> <b>PCR multiplex</b> ou EIA sur selles (rapide, mais pas d'ATBg).</li>
<li><b>Identification</b> : Gram + oxydase + catalase, hippurate, sensibilité acide nalidixique / céfalotine, <b>MALDI-TOF</b>, PCR (<i>hipO</i> = <i>C. jejuni</i>, <i>glyA</i> = <i>C. coli</i>).</li>
<li><b>ATBg</b> (CLSI M45, <i>C. jejuni / coli</i> seulement) : <b>disques</b> : MH + sang de mouton 5 %, <b>42 °C, 24 h</b> ; <b>CMI</b> : bouillon MH + sang de cheval lysé, 36–37 °C 48 h ou 42 °C 24 h ; microaérophilie (jarre / générateur : CO₂ 10 %, O₂ 5 %) ; <b>CQ</b> : <i>S. aureus</i> ATCC 25923 (disques), <i>C. jejuni</i> ATCC 33560 (CMI). Seuils (mm) : ERY 15 µg S ≥ 16, R ≤ 12 ; CIP 5 µg S ≥ 24, R ≤ 20 ; TET 30 µg S ≥ 26, R ≤ 22. EUCAST : MH-F, 41 °C. <span class="r">Aucun seuil CLSI pour <i>C. fetus</i> / <i>C. lari</i>.</span></li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Entérite</b> : <b>réhydratation (SRO)</b> ; guérison spontanée ⇒ ATB non systématique. <b>Formes sévères</b> (dysenterie, fièvre élevée, &gt; 1 sem, immunodéprimé) : <b>azithromycine 500 mg/j × 3 j</b> (enfant 10 mg/kg/j) ou érythromycine 5 j ; <span class="r">FQ proscrites en probabiliste</span> (résistance élevée) ; antidiarrhéiques à éviter en cas de dysenterie.</li>
<li><b>Bactériémie / <i>C. fetus</i></b> : <b>imipénème / méropénème</b> ou amoxicilline-acide clavulanique (± gentamicine initiale si forme grave) ; <b>2–4 sem</b> (4–6 sem si endocardite / atteinte vasculaire).</li>
<li><b>Vaccin</b> : aucun (hors PEV algérien).</li>
<li><b>Prévention</b> : cuisson de la volaille <b>à cœur</b>, éviter la contamination croisée, lait pasteurisé, eau potable, lavage des mains, hygiène des élevages / abattoirs.</li>
<li><b>Entourage</b> : pas de prophylaxie ; éviction en collectivité tant que diarrhée ; <b>déclaration obligatoire des TIAC</b> + enquête alimentaire.</li>
</ul></div></div>
