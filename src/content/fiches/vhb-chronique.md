<div class="box br"><div class="bt">Généralités et entités cliniques</div><div class="bb">
<p><span class="h">Chronicisation</span> : AgHBs + &gt; 6 mois ; risque ≈ 90 % après infection périnatale, &lt; 5 % chez l'adulte immunocompétent. &gt; 250 millions de porteurs dans le monde (OMS) → cirrhose, CHC.</p>
<p><span class="h">Nomenclature EASL</span> : <b>infection chronique</b> (ALT normale, pas d'hépatite) vs <b>hépatite chronique</b> (ALT ↑, ADN ↑), AgHBe + ou –. La décision repose sur <b>ADN + ALT + fibrose</b>.</p>

  <tr><th>Entité</th><th class="c">AgHBe</th><th>ADN (UI/mL)</th><th class="c">ALT</th><th>Conduite</th></tr>
  <tr><td>Infection chronique AgHBe+</td><td class="c">+</td><td>&gt; 10⁷</td><td class="c">N</td><td>Surveiller *</td></tr>
  <tr><td>Hépatite chronique AgHBe+</td><td class="c">+</td><td>10⁴–10⁷</td><td class="c">↑</td><td>Traiter</td></tr>
  <tr><td>Infection chronique AgHBe–</td><td class="c">–</td><td>&lt; 2000</td><td class="c">N</td><td>Surveiller</td></tr>
  <tr><td>Hépatite chronique AgHBe–</td><td class="c">–</td><td>≥ 2000 (fluctuant)</td><td class="c">↑</td><td>Traiter</td></tr>
</table>
<p>* Traiter si fibrose ≥ F2, facteurs de risque de CHC (ATCD familiaux) ou cirrhose.</p>
</div></div>

<div class="box db"><div class="bt">Évaluation initiale et suivi biologique</div><div class="bb"><ul>
<li><b>Virologie</b> : AgHBs, AgHBe/anti-HBe, <b>ADN VHB quantitatif</b> (même technique au suivi) ; <b>anti-HDV chez tout AgHBs+</b> (OMS) ; anti-VHC, VIH, anti-VHA.</li>
<li><b>Foie</b> : ALT/AST (LSN OMS : 30 U/L (H), 19 U/L (F)), NFS-plaquettes, TP, albumine, bilirubine.</li>
<li><b>Fibrose non invasive</b> : FibroScan, APRI, FIB-4 ; biopsie si doute. OMS : F≥2 = APRI &gt; 0,5 ou &gt; 7 kPa ; F4 = APRI &gt; 1 ou &gt; 12,5 kPa.</li>
<li><b>Sous traitement</b> : ADN à 3 mois puis /6–12 mois ; ALT ; créatinine, phosphatémie (TDF) ; écho /6 mois si indiqué.</li>
<li><span class="r">ALT normale n'exclut pas une fibrose</span> ; ALT fluctuante → répéter sur 6–12 mois.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Objectifs et limites du traitement</div><div class="bb"><ul>
<li><b>But</b> : suppression durable de l'ADN → ALT normale, ↓ nécro-inflammation et fibrose, ↓ cirrhose, décompensation, CHC.</li>
<li><b>Guérison fonctionnelle</b> = perte de l'AgHBs : rare sous NA ; l'ADNccc persiste → pas de guérison virologique.</li>
<li><span class="r">Le risque de CHC diminue mais persiste sous traitement</span> → surveillance maintenue.</li>
</ul></div></div>

  <tr><td>Ténofovir DF (TDF)</td><td>245 mg/j</td><td>Barrière élevée, utilisable pendant la grossesse ; toxicité rénale (↓ DFG, ↓ PO₄), osseuse</td></tr>
  <tr><td>Ténofovir AF (TAF)</td><td>25 mg/j</td><td>Efficacité comparable au TDF ; ↓ toxicité rénale/osseuse → préférer si DFG ↓, ostéopénie</td></tr>
  <tr><td>PEG-IFN α</td><td>180 µg/sem SC, 48 sem</td><td>Durée finie, sujets sélectionnés non cirrhotiques ; effets : syndrome grippal, cytopénies, dysthyroïdie, dépression ; <span class="r">CI : cirrhose décompensée, grossesse</span></td></tr>
</table>
<p><span class="r">Lamivudine, adéfovir, télbivudine : non recommandés (résistance).</span> Pas de bithérapie d'emblée. NA = traitement prolongé, souvent à vie.</p>
</div></div>

<div class="box dr"><div class="bt">Échecs et pièges thérapeutiques</div><div class="bb"><ul>
<li><b>Rebond / échec</b> : vérifier d'abord l'<b>observance</b>, puis ADN, génotypage de résistance ; rare avec ETV/TDF/TAF chez le naïf.</li>
<li><b>Réactivation</b> (rituximab, chimiothérapie, anti-TNF, corticoïdes, greffe) : AgHBs + anti-HBc <b>avant</b> ; prophylaxie par ETV ou ténofovir.</li>
<li><b>Arrêt des NA</b> : risque de poussée sévère, surtout si cirrhose.</li>
<li><b>Coïnfection VIH</b> : ténofovir dans le schéma ARV complet ; <span class="r">jamais ETV/lamivudine seuls</span> (sélection de résistance VIH).</li>
</ul></div></div>

<div class="box or"><div class="bt">Populations particulières</div><div class="bb"><ul>
<li><b>Grossesse</b> : ADN &gt; 200 000 UI/mL → TDF dès 24–28 SA ; nouveau-né : vaccin + Ig anti-HBs dès la naissance (idéalement &lt; 24 h). OMS 2024 : si ADN/AgHBe indisponibles, TDF possible chez toute femme AgHBs+.</li>
<li><b>VHD</b> : anti-HDV → ARN VHD ; les NA n'agissent pas sur le VHD (traiter le VHB si indiqué) ; PEG-IFN, bulevirtide.</li>
<li><b>Adolescent ≥ 12 ans</b> : critères OMS 2024 identiques à l'adulte.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">Traiter selon ADN + ALT + fibrose</span>, pas selon l'AgHBe seul : ADN ≥ 2000 + ALT &gt; LSN, ou F≥2 (OMS) / cirrhose + ADN détectable.</li>
<li>1re ligne : <b>ETV, TDF ou TAF</b> ; <span class="r">jamais lamivudine/adéfovir</span>.</li>
<li>Cirrhose, CHC, décompensation : traiter d'emblée, <b>ne pas arrêter</b> ; écho /6 mois.</li>
<li>Arrêt : AgHBe+ après séroconversion ; AgHBe– avec ADN &lt; LOD ≥ 3 ans, non cirrhotique, idéalement AgHBs quantitatif bas (&lt; 100 UI/mL) ; suivi /mois × 3 puis /3 mois.</li>
<li>Anti-HDV chez tout AgHBs+.</li>
</ul></div></div>
