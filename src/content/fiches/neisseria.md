<div class="cols">

<div class="col">

<div class="box bl"><div class="bt">Caractères bactériologiques</div><div class="bb">
<p><span class="h">Morphologie</span> : diplocoque Gram négatif « en grains de café » (faces concaves adjacentes) ; <span class="r">piège : extraits de la cellule hôte (intra-cellulaires dans les PNN)</span>.</p>
<p><span class="h">Exigences</span> : capnophile (5–10 % CO₂), polypathique, hydraté ; mauvaise croissance sur gélose simple.</p>
<p><span class="h">Culture</span> : gélose chocolat (sang chauffé + PolyViteX), 37 °C, 5 % CO₂, 24–48 h ; colonies de 1–2 mm, grises, lisses, oxydase +.</p>
<p><span class="h">Biochimie</span> : oxydase +, catalase + ; oxydation du glucose (GKC) ± maltose ± lactose — base de l'identification.</p>
<p><span class="h">Antigénie</span> : capsule polysaccharidique du méningocoque (sérogroupes A, B, C, W, Y, X) ; pili et protéines Opa/porines chez le gonocoque.</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li>Réservoir <b>strictement humain</b> ; méningocoque : portage rhinopharyngé (10 %) ; gonocoque : muqueuses génitales.</li>
<li>Transmission : gouttelettes (méningocoque) ; <b>rapports sexuels</b> et accouchement (gonocoque).</li>
<li>Terrain : enfants/adolescents (méningite) ; jeunes adultes sexuellement actifs (gonorrhée) ; <span class="r">déficit en complément (C5–C9) : méningites à récidive</span>.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>Capsule</b> (méningocoque) : anti-phagocytaire, immunogène (vaccins).</li>
<li><b>Pili + Opa</b> : adhésion aux muqueuses ; <b>IgA protease</b> : neutralisation des IgA locales.</li>
<li><b>LPS (endotoxine)</b> : choc inflammatoire — purpura fulminans (C5a, TNF) ; passage méningé par voie hématogène.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Méningite cérébro-spinale</b> : fièvre + céphalées + raideur de nuque + vomissements ; <span class="r">purpura fulminans = urgence absolue (antibiothérapie IV avant transfert)</span>.</li>
<li><b>Gonorrhée</b> : urétrite masculine purulente, cervicite souvent muette chez la femme (risque de salpingite/PID, stérilité) ; proctite, pharyngite ; <span class="r">ophtalmie néonatale (instillation de nitrate d'argent à la naissance)</span>.</li>
<li>Formes disséminées : arthrite, septicémie.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : LCR (méningite) ; écouvillon urétral/cervical (gonorrhée) <span class="r">ensemencement immédiat sur milieu gélosé chauffé à 35–37 °C, jamais réfrigéré</span>.</li>
<li><b>Direct</b> : Gram (diplocoques G– intra-cellulaires), antigènes solubles (latex agglutination) ; <b>PCR</b> : référence (LCR, sang) — diagnostique de certitude de la méningite.</li>
<li><b>Culture</b> : gélose chocolat + CO₂, 24–48 h ; identification biochimique (GKC) ou API NH / MALDI-TOFF.</li>
<li><b>Sérotypage</b> : sérogroupe capsulaire (latex / PCR) pour le méningocoque ; ATBg systématique.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Résistance aux antibiotiques</div><div class="bb"><ul>
<li><b>Naturelle</b> : résistant aux macrolides, glycopeptides, vancomycine.</li>
<li><b>Acquise (gonocoque)</b> : pénicillinase plasmidique (TEM), chromosomique (penA mosaïque), résistance aux cyclines, quinolones (gyrA) ; <span class="r">C3G = 1ʳᵉ intention (céfixime / ceftriaxone)</span> ; phénotype de lecture obligatoire (ATBg de première intention : C3G, spectinomycine).</li>
<li><b>Méningocoque</b> : habituellement S à la pénicilline G (CMI en hausse possible) ; <span class="r">piège : résistance aux sulfamides fréquente</span>.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Méningite</b> : C3G IV en urgence (céfotaxime) 7 jours ; <span class="r">purpura fulminans : ceftriaxone IV immédiate (avant transfert)</span>.</li>
<li><b>Gonorrhée</b> : ceftriaxone IM dose unique (± azithromycine selon recommandations) ; traiter le partenaire.</li>
<li><b>Vaccin</b> méningocoque : polysaccharidique conjugée A/C/W/Y (MenACWY, pèlerinage à La Mecque) et vaccin protéique B (MenB) ; <span class="r">pas de vaccin gonococcique</span>.</li>
<li><b>Prophylaxie de l'entourage</b> : rifampicine ou ciprofloxacine (sujets contacts) ; <b>déclaration obligatoire</b> de la méningite à méningocoque.</li>
</ul></div></div>
