<div class="box br"><div class="bt">Généralités et dispositif</div><div class="bb">
<p><span class="h">Pourquoi surveiller</span> : virus en évolution constante (drift, shift) → savoir <b>quand / où</b> la grippe circule, <b>quels virus</b>, détecter les <b>mutations</b>, mesurer l'<b>impact</b> (morbidité, hospitalisations, décès). OMS : ~1 milliard de cas/an, 3–5 millions de formes graves, 290 000–650 000 décès respiratoires.</p>
<p><span class="h">Méthodes</span> : <b>passive</b> (déclaration spontanée et routinière par structures de santé / labos), <b>active</b> (recherche proactive des cas par les autorités), <b>sentinelle</b> (réseau de sites avec données détaillées + prélèvements).</p>
<p><span class="h">GISRS</span> (OMS, depuis 1952) : <b>NIC</b> (centres nationaux) → <b>Centres collaborateurs OMS</b> → <b>ERL</b> (réactifs, régulation). Surveillance <b>intégrée</b> : grippe + autres virus respiratoires (SARS-CoV-2, VRS).</p>
<p><span class="h">Algérie</span> : réseau sentinelle national (INSP) + laboratoire de référence de la grippe de l'<b>Institut Pasteur d'Algérie</b> (CNR/NIC OMS).</p>
</div></div>

<div class="box or"><div class="bt">Prélèvement et pré-analytique</div><div class="bb"><ul>
<li><b>Quand</b> : idéalement ≤ 3 j après le début des signes (charge virale maximale).</li>
<li><b>Quoi</b> : écouvillon nasopharyngé ; nez + gorge combinés = meilleur rendement que l'oropharyngé seul. SARI intubé : aspirat endotrachéal / LBA.</li>
<li><b>Matériel</b> : écouvillon synthétique en milieu de transport viral ; <span class="r">pas d'alginate de calcium</span> (inhibe la PCR).</li>
<li><b>Conservation</b> : 2–8 °C ≤ 72 h ; sinon –70 °C ; éviter les cycles congélation/décongélation.</li>
<li><b>Renseignements</b> : âge, date de début, statut vaccinal, antiviraux, voyage/contact animal. Étiquetage « sentinelle » + définition de cas (ILI/SARI).</li>
<li><span class="r">Biosécurité</span> : grippe saisonnière : PSM classe II ; <b>culture / isolement</b> d'un sous-type zoonotique (H5, H7…) = <b>BSL-3</b> ; extraction RT-PCR en BSL-2 renforcé selon directives nationales ; alerte.</li>
</ul></div></div>

<ul>
<li>Contexte : <b>sous-clade K</b> (J.2.4.1) d'A(H3N2) émergé en août 2025, majoritaire ; B/Yamagata <b>non détecté depuis mars 2020</b>.</li>

<div class="box dr"><div class="bt">Limites de la surveillance</div><div class="bb"><ul>
<li><span class="r">ILI/SARI non spécifiques</span> : VRS, SARS-CoV-2, rhinovirus donnent le même tableau → PCR multiplex.</li>
<li>Sentinelle ≠ exhaustif : sert aux <b>tendances</b>, pas au dénombrement.</li>
<li>Faux négatifs : prélèvement tardif, mauvais matériel, conservation ; <b>dérive</b> → cible PCR mutée.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">ILI</span> = fièvre ≥ 38 °C + toux ≤ 10 j (ambulatoire) ; <span class="r">SARI</span> = idem (ATCD de fièvre possible) + <b>hospitalisation</b>.</li>
<li>Le labo : <b>détecte / sous-type</b> → <b>caractérise</b> (antigène, génome, résistance) → <b>partage</b> (CC OMS → vaccin, fév. HN / sept. HS).</li>
<li><span class="r">TDR négatif n'exclut pas la grippe</span> ; RT-PCR = référence.</li>
<li>Sous-type inhabituel → alerte immédiate (RSI) et biosécurité renforcée.</li>
</ul></div></div>
