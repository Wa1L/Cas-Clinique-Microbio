<div class="box br"><div class="bt">Généralités — toxinogenèse</div><div class="bb">
<p><span class="h">Principe</span> : symptômes <b>à distance du foyer</b> par toxine circulante ; bactériémie non nécessaire ; lésions de SSSS <b>stériles</b>.</p>
<p><span class="h">Régulation</span> : système <i>agr</i> (quorum sensing) → exotoxines en fin de phase exponentielle. <span class="h">Réservoir</span> : portage nasal (≈ 20–30 %), vagin (TSS menstruel), mains (TIAC).</p>
<p><span class="h">Autres cytotoxines</span> : <b>α-toxine</b> (pores heptamériques, nécrose), β (sphingomyélinase), δ, γ-hémolysine.</p>
</div></div>

<div class="box dr"><div class="bt">Limites / pièges thérapeutiques</div><div class="bb"><ul>
<li><b>Anti-toxine</b> : clindamycine et linézolide inhibent la <b>synthèse protéique</b> → ↓ production de toxine ; β-lactamines et vancomycine n'agissent pas sur la toxine déjà produite.</li>
<li><span class="r">Clindamycine</span> : résistance MLS<sub>B</sub> inductible (antagonisme érythromycine–clindamycine). <b>D-test</b> (CLSI M100) : disques érythromycine 15 µg et clindamycine 2 µg à 15–26 mm bord à bord, gélose Mueller-Hinton, 35 ± 2 °C, 16–18 h → si +, <b>rendre clindamycine R</b> ; préférer le linézolide.</li>
<li>IgIV : neutralisent les superantigènes ; bénéfice surtout démontré dans le TSS streptococcique, <b>preuve limitée</b> pour <i>S. aureus</i>.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>TSS</b> : <b>clinique</b> (critères CDC) ; prélèvements locaux (vagin, plaie, tampon) + hémocultures (<span class="r">souvent négatives</span>) ; PCR <i>tst</i> / toxine sur la souche (labo de référence).</li>
<li><b>SSSS</b> : clinique ; biopsie (coupe congelée) si doute avec NET ; cultures nez, ombilic, conjonctive, ORL (<span class="r">pas les bulles</span>).</li>
<li><b>TIAC</b> : culture de l'aliment (≥ 10<sup>5</sup> UFC/g), recherche d'entérotoxine (ELISA), enquête épidémiologique.</li>
<li><b>PVL</b> : PCR <i>lukS/F-PV</i> sur la souche.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
