<div class="box bl"><div class="bt">Caractères bactériologiques</div><div class="bb">
<p><span class="h">Morphologie</span> : bacille Gram <b>–</b> <b>spiralé / incurvé</b> (0,5 × 3 µm), <b>mobile</b> (4–6 flagelles engainés polaires, mobilité en vrille), non sporulé ; <span class="r">formes coccoïdes (vieilles cultures, stress) = viables non cultivables</span>.</p>
<p><span class="h">Exigences</span> : <b>microaérophile</b> (O₂ 5 %, CO₂ 10 %, N₂ 85 %) ; atmosphère humide ; sang ou sérum (cheval, mouton) ; ne pousse pas en aérobiose.</p>
<p><span class="h">Culture</span> : gélose Columbia / Brucella + sang 5–10 % ; <b>milieux sélectifs</b> (Pylori agar, Skirrow, Dent : vancomycine, TMP, amphotéricine B) ; <b>37 °C, 3–7 j</b> (jusqu'à 10 j) ; colonies 1–2 mm, translucides, non hémolytiques.</p>
<p><span class="h">Biochimie</span> : <b>uréase +++ (rapide)</b>, <b>oxydase +</b>, <b>catalase +</b> ; sucres non fermentés ; MALDI-TOF ; gènes <i>ureA/B</i>, <i>glmM</i>, ARNr 16S.</p>
<p><span class="h">Antigénie</span> : <b>CagA</b> (îlot <i>cag</i>-PAI, SST4), <b>VacA</b> (cytotoxine vacuolisante), adhésines <b>BabA</b> (Lewis b) / <b>SabA</b>, LPS (mimétisme Lewis), flagelline, uréase.</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li>Réservoir <b>strictement humain</b> (estomac) ; infecte ≈ <b>50 % de la population mondiale</b>, &gt; 80 % des adultes dans les pays en développement (Algérie : séroprévalence adulte élevée, ≈ 57–88 % selon les études) ; <b>résistance primaire à la clarithromycine élevée</b> ⇒ bismuthée d'emblée.</li>
<li>Transmission <b>interhumaine oro-orale / féco-orale</b>, intrafamiliale ; <b>acquisition dans l'enfance</b>, persistance <b>à vie sans traitement</b>.</li>
<li>Facteurs : promiscuité, bas niveau socio-économique, eau contaminée.</li>
<li><span class="r">Carcinogène de classe I (OMS/CIRC)</span> ; tout porteur n'est pas malade (&lt; 20 % symptomatiques).</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>Colonisation</b> : <b>uréase</b> → urée → NH₃ + CO₂ ⇒ neutralise l'acidité (microclimat) ; flagelles → traversée du mucus ; adhésines BabA / SabA.</li>
<li><b>CagA</b> injecté dans la cellule épithéliale (SST4) → prolifération, désorganisation ⇒ <b>carcinogenèse</b> ; <b>VacA</b> : vacuoles, apoptose.</li>
<li>Inflammation : IL-8, polynucléaires → <b>gastrite chronique</b> ; mimétisme antigénique et variation de phase ⇒ <b>persistance</b>.</li>
<li><b>Gastrite antrale</b> : ↑ gastrine → hyperacidité ⇒ <b>ulcère duodénal</b>. <b>Pangastrite</b> : atrophie, hypochlorhydrie ⇒ <b>ulcère gastrique</b>, cancer.</li>
<li>Non invasif : reste <b>extracellulaire</b> (mucus, surface épithéliale).</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Gastrite chronique</b> : le plus souvent <b>asymptomatique</b> ; dyspepsie.</li>
<li><b>Ulcère duodénal</b> (&gt; 90 % <i>H. pylori</i>+) et <b>gastrique</b> (≈ 70–80 %) : douleur épigastrique rythmée par les repas. <span class="r">Complications : hémorragie, perforation, sténose.</span></li>
<li><b>Adénocarcinome gastrique</b> (séquence gastrite atrophique → métaplasie → dysplasie) ; <b>lymphome du MALT</b> gastrique (régression après éradication au stade précoce).</li>
<li>Extradigestif : <b>anémie ferriprive</b>, <b>PTI</b>, carence en B12.</li>
<li><span class="r">Signes d'alerte</span> : &gt; 50 ans, amaigrissement, dysphagie, anémie, vomissements ⇒ <b>FOGD</b>.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : biopsies gastriques (<b>antre + fond</b>, ≥ 2 sites). <span class="r">Arrêt des IPP ≥ 2 sem. et des ATB ≥ 4 sem. avant les tests (faux négatifs)</span>.</li>
<li><b>Transport</b> : milieu de transport (type thioglycolate), ≤ 4 h à +4 °C ; <span class="r">pas d'eau ni de sérum physiologique prolongé</span>.</li>
<li><b>Invasif</b> : <b>test rapide à l'uréase</b> ; histologie (Giemsa, Warthin-Starry) ; <b>culture</b> (seule méthode donnant l'ATBg) ; <b>PCR</b> (ARNr 23S, <i>gyrA</i>).</li>
<li><b>Non invasif</b> : <b>test respiratoire à l'urée ¹³C</b> (référence, contrôle d'éradication) ; <b>Ag fécal</b> ; <b>sérologie</b> <span class="r">(inutile pour le contrôle : reste +)</span>.</li>
<li><b>Contrôle d'éradication</b> : ≥ 4 sem. après fin du traitement, ≥ 2 sem. après arrêt IPP.</li>
<li><b>ATBg (CLSI M45)</b> : <b>dilution en gélose</b> seule méthode de référence (disques / microdilution non standardisés) ; gélose MH + <b>sang de mouton 5 % vieilli (≥ 2 sem.)</b> ; inoculum <b>McFarland 2</b> (10⁷–10⁸ UFC/mL) ; 35 °C, microaérophilie, 72 h ; CQ <b>ATCC 43504</b> (clarithro 0,015–0,12 µg/mL). <span class="r">≠ EUCAST (MH-F, cheval + β-NAD, McF 3)</span>.</li>
</ul></div></div>

<li><b>Naturelle</b> : glycopeptides, triméthoprime, polymyxines (base des milieux sélectifs).</li>
<li><b>Acquise</b> (échec = 1<sup>re</sup> cause : <b>résistance à la clarithromycine</b>) :</li>
</ul>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Indications</b> : ulcère, MALT, gastrite atrophique, après résection d'un cancer précoce, AINS / aspirine, anémie ferriprive / PTI, ATCD familial de cancer gastrique.</li>
<li><b>1<sup>re</sup> intention</b> (Maastricht VI) : <b>quadrithérapie bismuthée 14 j</b> (IPP + bismuth + tétracycline + métronidazole) ; si résistance clarithro &lt; 15 % : trithérapie IPP + amoxicilline 1 g ×2 + clarithromycine 500 mg ×2, <b>14 j</b>. Alternative : quadrithérapie concomitante (IPP + amox + clari + métro).</li>
<li><b>2<sup>e</sup> intention</b> : IPP + amoxicilline + lévofloxacine (si pas de FQ avant) ou bismuthée. <span class="r">Pas de clarithromycine en ré-traitement sans ATBg</span>.</li>
<li><b>Contrôle d'éradication systématique</b> (test respiratoire / Ag fécal) ; échec → culture + ATBg.</li>
<li><b>Prévention</b> : hygiène, eau saine ; <b>pas de vaccin</b> disponible ; pas de prophylaxie de l'entourage systématique ; <b>pas de déclaration obligatoire</b> (non MDO).</li>
</ul></div></div>
