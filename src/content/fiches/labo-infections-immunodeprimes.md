<div class="box br"><div class="bt">Généralités — pourquoi le labo est central</div><div class="bb">
<p><span class="h">Terrains</span> : neutropénie, hémopathies, greffes CSH / organe solide, VIH, corticoïdes, biothérapies, asplénie, déficits immunitaires primitifs ; <b>CAR-T et anticorps bispécifiques</b> (lymphopénie prolongée, hypogammaglobulinémie, réactivations CMV même sans neutropénie).</p>
<p><span class="h">Particularités</span> : signes inflammatoires atténués (fièvre souvent isolée) ; agents <b>opportunistes</b> ou inhabituels ; infections <b>polymicrobiennes</b>, <b>réactivations</b> (CMV, VHB, BK, toxo) ; évolution rapide → <span class="r">urgence diagnostique</span>.</p>
<p><span class="h">3 temps</span> : <b>avant</b> (dépistage) · <b>pendant</b> (diagnostic, ATBg) · <b>en continu</b> (surveillance, BMR, hygiène).</p>
</div></div>

<div class="box or"><div class="bt">Interface clinico-biologique</div><div class="bb"><ul>
<li><b>Renseignements cliniques</b> indispensables (type de déficit, greffe, ATB/antifongique en cours) → choix des examens, milieux et durée d'incubation.</li>
<li><b>Résultats critiques</b> téléphonés : Gram d'HC+, LCR, Ag cryptococcique +, BAAR + → ATB / antifongique adapté sans attendre l'ATBg.</li>
<li><b>Désescalade</b> guidée par l'identification et l'ATBg ; <b>écologie locale</b> (BMR, profils de résistance) → protocoles probabilistes de neutropénie fébrile.</li>
<li><span class="r">Suspicion de Nocardia, mycobactéries, champignons → le signaler</span> : incubation prolongée, milieux spécifiques.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Pièges d'interprétation</div><div class="bb"><ul>
<li><span class="h">Sérologies</span> : <span class="r">faux négatifs</span> (déficit humoral, rituximab) ; faux positifs passifs (IgIV, transfusions) → privilégier <b>Ag, PCR, culture</b>.</li>
<li><span class="h">GM</span> : <span class="r">faux négatif sous antifongique anti-moisissures</span> ; réactions croisées (Fusarium, Histoplasma, Talaromyces).</li>
<li><span class="h">BDG</span> : faux + (IgIV, albumine, hémodialyse sur membrane cellulosique, compresses de gaze, bactériémies) ; <span class="r">négatif dans mucormycose et cryptococcose</span>.</li>
<li><span class="h">Colonisation vs infection</span> : Candida dans les expectorations ≈ colonisation ; Aspergillus en culture chez un neutropénique = <b>significatif</b> ; PCR Pj à faible charge = colonisation possible.</li>
<li><span class="h">Charges virales</span> : seuils non universels → comparer même technique, même matrice (sang total ≠ plasma).</li>
<li><span class="h">SCN</span> sur 1 HC/2 = contaminant probable ; sur KT, répété = significatif.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Dépistage, surveillance, résistance, hygiène</div><div class="bb"><ul>
<li><b>Bilan pré-thérapeutique</b> (greffe, chimio, biothérapie) : VIH, VHB (AgHBs, <b>Ac anti-HBc</b>, anti-HBs), VHC, CMV, EBV, VZV, toxo, syphilis, HTLV-1 (zone d'endémie) ; <b>IGRA avant</b> corticoïdes / IS (sinon indéterminé ou faux –) ; sérologie <i>Strongyloides</i> si exposition, avant corticoïdes.</li>
<li><span class="r">Anti-HBc + isolé sous rituximab → risque de réactivation VHB</span> → prophylaxie (entécavir / ténofovir) ou suivi rapproché de l'ADN VHB.</li>
<li><b>Surveillance</b> : prophylaxie létermovir (allo-CSH R+) ; qPCR CMV hebdomadaire post-allo-CSH → traitement préemptif ; GM sérique 2×/sem. si neutropénie prolongée sans prophylaxie anti-moisissures.</li>
<li><b>BMR</b> : écouvillon rectal (EBLSE, EPC, ERV), nasal (SARM) → isolement, choix probabiliste.</li>
<li><b>Résistances</b> : ATBg CA-SFM/EUCAST ; CMI antifongiques (<i>Nakaseomyces glabratus</i> ex-<i>C. glabrata</i>, <i>C. auris</i> = <i>Candidozyma auris</i>, Aspergillus azole-R).</li>
<li><b>Génotypage CMV</b> si échec : UL97/UL54 (ganciclovir, cidofovir, foscarnet) · UL56 ± UL89/UL51 (létermovir) · UL97/UL27 (maribavir).</li>
<li><b>Hygiène</b> : contrôle de l'air (flux laminaire, Aspergillus), de l'eau (Legionella, P. aeruginosa), investigation d'épidémies.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">Neutropénie fébrile = urgence</span> : HC (KT + périph.) <b>avant</b> ATB, sans retarder l'ATB.</li>
<li>Chez l'ID, la <b>détection directe</b> (Ag, PCR, culture) prime sur la <span class="r">sérologie</span>.</li>
<li>Mucormycose : <span class="r">GM et BDG négatifs</span> → culture / histologie / PCR.</li>
<li>Ag urinaire Legionella = <b>sérogroupe 1 seul</b> : un négatif n'élimine pas.</li>
</ul></div></div>
