<div class="box bl"><div class="bt">Caractères virologiques</div><div class="bb">
<p><span class="h">Virion</span> : <b>enveloppé</b>, <b>pléomorphe</b> (150–350 nm), nucléocapside <b>hélicoïdale</b> ; <span class="r">sensible</span> à l'éther, aux détergents et à la dessiccation (fragile dans le milieu extérieur).</p>
<p><span class="h">Génome</span> : ARN simple brin <b>–</b>, non segmenté, ≈ 15–16 kb (6 gènes chez la rougeole : <b>N-P-M-F-H-L</b>) ; non infectieux seul : <b>polymérase L</b> embarquée dans le virion.</p>
<p><span class="h">Protéines</span> : <b>N</b> (nucléoprotéine), <b>P</b> (phosphoprotéine), <b>L</b> (polymérase) ; <b>M</b> (matrice, bourgeonnement) ; <b>F</b> (fusion), clivée F0 → F1 + F2 pour devenir active : <b>furine</b> (rougeole, ourlien, VRP3), <b>cathepsine L</b> (Hendra / Nipah), protéases type trypsine (VRP1) ; <b>H / HN / G</b> (attachement).</p>
<p><span class="h">Réplication</span> : <b>cytoplasmique</b> (pas d'étape nucléaire) ; fusion membranaire à pH neutre ; bourgeonnement à la membrane plasmique.</p>
<p><span class="h">Culture / ECP</span> : cellules Vero, rein de singe ; ECP = <b>syncytia</b> (cellules géantes multinucléées) + <b>inclusions éosinophiles intracytoplasmiques</b> (toute la famille) ; <b>intranucléaires = rougeole</b> (<i>Morbillivirus</i>) seule ; histologie : cellules de Warthin-Finkeldey.</p>
<p><span class="h">Antigénie</span> : rougeole = <b>1 seul sérotype</b>, très stable (24 génotypes) ⇒ vaccin efficace durable ; ourlien : 1 sérotype, 12 génotypes (A–N) ; VRP : <b>types 1 à 4</b> ; pas de protection croisée entre VRP.</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li><b>Rougeole</b> : réservoir <b>strictement humain</b> ; transmission <b>aérienne</b> (aérosols, gouttelettes) ; <b>R0 12–18</b> ; contagieux de <b>J–4 à J+4</b> de l'éruption ; incubation ≈ 10 j (éruption à J14) ; seuil d'immunité collective <b>≥ 95 %</b> (2 doses).</li>
<li><b>Ourlien</b> : salive, gouttelettes ; incubation 16–18 j (12–25) ; contagieux de 2 j avant à 5 j après la parotidite ; 30 % d'infections asymptomatiques.</li>
<li>Terrain à risque : nourrisson < 1 an, <span class="r">dénutrition</span> (carence en vit A), immunodéprimé, femme enceinte non immune ; <span class="r">résurgences</span> liées à une couverture vaccinale < 95 %.</li>
<li>VRP : enfant < 5 ans ; réinfections fréquentes (immunité non durable). Nipah : zoonose (<b>sève crue de palmier-dattier</b> souillée par les chauves-souris <i>Pteropus</i>, ou fruits rongés), transmission interhumaine nosocomiale.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>Rougeole</b> : voies aériennes → macrophages / cellules dendritiques (<b>CD150 = SLAM</b>) → ganglions → <b>1<sup>re</sup> virémie</b> (J2–3) → dissémination au système réticulo-endothélial → <b>2<sup>e</sup> virémie</b> → épithéliums (peau, muqueuses, conjonctives).</li>
<li>Récepteurs : <b>CD150</b>, <b>nectine-4</b> (sauvage) ; <b>CD46</b> (souches vaccinales) ; ourlien : acide sialique.</li>
<li><span class="r">Immunosuppression transitoire</span> (lymphopénie, « amnésie immune ») ⇒ <b>surinfections bactériennes</b> ; l'éruption est due à la <b>réponse immunitaire cellulaire T</b>.</li>
<li>SNC : <b>encéphalite post-infectieuse</b> (démyélinisation auto-immune, 1/1000) ; <span class="r">PESS</span> : persistance de virus <b>mutant M</b>, 5–10 ans après.</li>
<li><b>Ourlien</b> : multiplication parotidienne puis virémie → <b>glandes, méninges, testicule</b>, pancréas.</li>
</ul></div></div>

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Rougeole</b> : invasion 3–4 j (fièvre, <b>catarrhe oculo-nasal</b>, toux) avec <b>signe de Köplik</b> (<span class="r">pathognomonique</span>, avant l'éruption) ; puis éruption <b>maculo-papuleuse morbilliforme descendante</b> (rétro-auriculaire → visage → tronc → membres), 5–6 j.</li>
<li>Complications rougeole : OMA, <b>pneumonie</b> (1<sup>re</sup> cause de décès), laryngite, diarrhée, <span class="r">kératite / cécité</span> ; <span class="r">encéphalite (1/1000), PESS (≈ 1/10 000 ; jusqu'à ~1/600–1/2 500 si rougeole < 1–2 ans)</span> ; formes de l'immunodéprimé sans éruption (<span class="r">pneumonie à cellules géantes d'Hecht</span>).</li>
<li><b>Oreillons</b> : <b>parotidite</b> fébrile uni- ou bilatérale ; <span class="r">orchite</span> (post-pubère, rarement stérilité) ; <b>méningite lymphocytaire</b> bénigne ; pancréatite ; <span class="r">surdité unilatérale neurosensorielle</span>.</li>
<li><b>VRP</b> : croup (VRP1, 2), bronchiolite et pneumonie (VRP3). <b>Nipah</b> : encéphalite fébrile, <span class="r">létalité 40–75 %</span>.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement rougeole</b> : sérum (IgM) + <b>écouvillon naso-pharyngé, salive ou urines (RT-PCR)</b>, idéalement dans les 4 j (≤ 7 j) après le début de l'éruption ; <span class="r">IgM souvent négatives si prélèvement < 72 h</span> ⇒ refaire.</li>
<li><b>Sérologie</b> : IgM spécifiques (ELISA) ; IgG : séroconversion ou ×4. <span class="r">Faux positifs d'IgM</span> : rubéole, parvovirus B19, HHV-6, <b>vaccination récente</b> (< 8 semaines).</li>
<li><b>Ourlien</b> : RT-PCR sur salive / frottis du canal de Sténon, LCR, urines ; IgM (parfois absentes chez le vacciné) ; <span class="r">amylasémie ↑ non spécifique</span>.</li>
<li><b>Direct</b> : cellules géantes multinucléées sur frottis nasal ; immunofluorescence ; <b>culture</b> sur Vero (réservée à la recherche et à la surveillance).</li>
<li><b>Typage</b> : séquençage (gène <b>N-450</b> rougeole) pour la surveillance OMS ⇒ distingue la <b>souche vaccinale</b> (génotype A) d'une souche sauvage. <b>Nipah</b> : laboratoire P4 uniquement.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Antiviraux</div><div class="bb"><ul>
<li><span class="r">Aucun antiviral spécifique validé</span> pour la rougeole ni l'ourlien ; pas de résistance cliniquement décrite.</li>
<li><b>Ribavirine</b> (± IFN) : activité <i>in vitro</i>, usage compassionnel hors AMM (pneumonie / encéphalite de l'immunodéprimé, PESS). <b>Nipah</b> : anticorps anti-G <b>m102.4</b> (phase 1, accès compassionnel) ; anti-F hu1F5 en développement.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Rougeole</b> : traitement <b>symptomatique</b> + antibiothérapie des surinfections ; <b>vitamine A</b> (OMS, 2 j consécutifs) : <b>50 000 UI</b> (< 6 mois), <b>100 000 UI</b> (6–11 mois), <b>200 000 UI</b> (≥ 12 mois).</li>
<li><b>Vaccin</b> : vivant atténué (Edmonston-Zagreb / Schwarz), <b>ROR</b> ; <span class="r">contre-indiqué</span> : grossesse, immunodépression sévère ; éviter la grossesse 1 mois après ; PEV algérien : <b>ROR à 11 mois et 18 mois</b> (RR = repli si rupture de ROR).</li>
<li><b>Prophylaxie de l'entourage</b> : vaccin dans les <b>72 h</b> après le contact (dès 6 mois : nourrisson de 6–11 mois inclus) ; <b>Ig polyvalentes IV</b> 400 mg/kg dans les 6 j (nourrisson < 6 mois, femme enceinte non immune, immunodéprimé) ; isolement respiratoire jusqu'à J+4 de l'éruption ; éviction scolaire.</li>
<li><b>Déclaration</b> : rougeole (et rubéole) = <b>MDO</b> ; <span class="r">oreillons non MDO</span> (seules méningites / méningo-encéphalites virales) ; enquête autour du cas.</li>
</ul></div></div>
