<div class="box bl"><div class="bt">Caractères virologiques</div><div class="bb">
<p><span class="h">Virion</span> : tous <b>nus</b> ⇒ résistent à l'éther/solvants, au pH 3 (passage gastrique) et à la plupart des désinfectants ; <span class="r">alcool-gel peu efficace</span>.</p>
<p><span class="h">Rotavirus</span> : capside à 3 couches ; ARNdb segmenté ⇒ réassortiments (variabilité). VP6 = Ag de groupe (A–J ; A = principal humain) ; VP7 (G) + VP4 (P) = typage binaire G/P ; NSP4 = entérotoxine virale. Clivage de VP4 par la trypsine ⇒ infectiosité. Réplication cytoplasmique (viroplasmes) ; transcription par la particule à double couche.</p>
<p><span class="h">Norovirus</span> : ARN+ à VPg ; ORF1 = polyprotéine non structurale (RdRp), ORF2 = VP1 (capside), ORF3 = VP2 ; recombinaison ORF1/ORF2 ; récepteurs = HBGA (ABO/Lewis, FUT2). <b>Non cultivable en routine.</b> Survit à 60 °C/30 min, pH 3.</p>
<p><span class="h">Sapovirus</span> : même famille ; aspect ME en « étoile de David » (cupules).</p>
<p><span class="h">Adénovirus 40/41</span> : ADN ; réplication nucléaire ; fibre double (courte + longue) ; culture exigeante : cellules 293 (Graham) ; ECP en grappes de raisin.</p>
<p><span class="h">Astrovirus</span> : ARN+ ; clivage par trypsine ; culture CaCo-2 + trypsine ; 8 sérotypes.</p>
<p><span class="h">Culture / ECP</span> : non utilisée en routine (rotavirus : MA104 + trypsine, ECP faible).</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li><b>Rotavirus</b> : 1<sup>re</sup> cause de GEA sévère &lt; 5 ans dans le monde ; infection quasi universelle avant 5 ans ; pic 6 mois–2 ans ; hiver (zones tempérées) ; ≈ 120–200 000 décès/an, surtout Afrique/Asie du Sud <i>(à vérifier)</i>.</li>
<li><b>Norovirus</b> : 1<sup>re</sup> cause de GEA épidémique tous âges ; <span class="r">dose infectante 10–100 particules</span> ; épidémies en collectivités fermées ; hiver.</li>
<li><b>Transmission féco-orale</b> (mains, objets, eau, coquillages crus) ; aérosols de vomissements (noro) ; excrétion massive (10<sup>10</sup>–10<sup>11</sup>/g de selles pour rota) ; porteurs asymptomatiques ; excrétion prolongée chez l'immunodéprimé.</li>
<li><b>Nosocomial fréquent</b> (pédiatrie, gériatrie) ⇒ précautions contact.</li>
<li>Adénovirus 40/41 : toute l'année ; astrovirus : hiver ; tous &lt; 2 ans.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>Rotavirus</b> : infecte les entérocytes matures du sommet des villosités (grêle) ⇒ lyse, atrophie villositaire, déficit en disaccharidases (lactase) ⇒ malabsorption ⇒ <b>diarrhée osmotique</b>.</li>
<li><b>NSP4</b> ⇒ ↑ Ca<sup>2+</sup> intracellulaire ⇒ sécrétion de Cl<sup>−</sup> + stimulation du système nerveux entérique ⇒ <b>hypersécrétion</b> ; hyperplasie compensatrice des cryptes.</li>
<li><b>Norovirus</b> : atteinte duodéno-jéjunale ; ralentissement de la vidange gastrique ⇒ vomissements ; lésions villositaires modérées.</li>
<li><b>Immunité</b> : IgA sécrétoires locales ; Ac maternels protecteurs les premiers mois ; réinfections de gravité décroissante (rota) ; immunité noro courte et dépendante du génotype ; non-sécréteurs FUT2 relativement résistants.</li>
<li><span class="r">Déshydratation = cause de décès</span> ; forme chronique chez l'immunodéprimé (SCID).</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Rotavirus</b> : incubation 1–3 j ; fièvre 38–39 °C, vomissements précoces, puis diarrhée aqueuse profuse 5–7 j ; déshydratation rapide du nourrisson.</li>
<li><b>Norovirus</b> : incubation 12–48 h ; début brutal, vomissements en jet, crampes, diarrhée, fièvre faible ; guérison en 1–3 j.</li>
<li><b>Adénovirus 40/41</b> : incubation 8–10 j ; diarrhée prolongée, vomissements modérés. <b>Astrovirus / sapovirus</b> : formes bénignes 2–4 j.</li>
<li><b>Signes de gravité</b> : perte de poids ≥ 10 %, fontanelle déprimée, pli cutané persistant, oligurie, léthargie. Complications rota : convulsions afébriles bénignes, invagination (rare). <span class="r">Sang, glaires, fièvre &gt; 39 °C ⇒ évoquer une cause bactérienne</span>.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : selles fraîches, liquides, phase aiguë (J1–J5) ; +4 °C ≤ 48 h, −20/−80 °C au-delà ; noro : vomissements possibles. <span class="r">Pièges : prélèvement tardif (excrétion ↓), selles formées ⇒ faux négatif</span>.</li>
<li><b>Direct</b> : détection d'Ag (ELISA / immunochromatographie, VP6) rota et adénovirus 40/41 ; <b>RT-PCR temps réel = référence</b> (noro : ELISA peu sensible) ; PCR multiplex syndromique ; ME ; PAGE de l'ARN (11 segments, électrotypes).</li>
<li><b>Culture</b> : non réalisée en routine. <b>Sérologie</b> : sans intérêt (infection universelle).</li>
<li><b>Typage</b> : G/P par RT-PCR/séquençage (surveillance, impact vaccinal) ; noro : séquençage ORF1/ORF2.</li>
<li><span class="r">Pièges</span> : rotavirus vaccinal excrété ~7–10 j après la dose ⇒ test positif ; PCR positive prolongée après guérison ; coïnfections. Si fièvre élevée/sang ⇒ coproculture (<i>Salmonella, Shigella, Campylobacter, E. coli</i> diarrhéiques). Ionogramme si déshydratation sévère.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Antiviraux</div><div class="bb"><ul>
<li><b>Aucun antiviral validé en routine</b> ; nitazoxanide (hors AMM) chez l'immunodéprimé en forme chronique <i>(à vérifier)</i>.</li>
<li><span class="r">Antibiotiques inutiles</span> (résistance : sans objet).</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Réhydratation = traitement essentiel</b> : SRO OMS faible osmolarité (245 mOsm/L). Plan A (pas de déshydratation) : SRO après chaque selle ; plan B (modérée) : SRO 75 mL/kg en 4 h ; plan C (sévère/choc) : IV Ringer lactate 100 mL/kg (30 puis 70 mL/kg). Alimentation et allaitement maintenus.</li>
<li><b>Zinc</b> : 20 mg/j × 10–14 j (10 mg/j si &lt; 6 mois). Racécadotril : option selon contexte.</li>
<li><span class="r">Proscrits</span> : antibiotiques, lopéramide/antimotilité chez l'enfant, jeûne, sodas.</li>
<li><b>Vaccin rotavirus</b> (oral, vivant atténué) : Rotarix® 2 doses (2 et 4 mois) ; RotaTeq® 3 doses (2, 4, 6 mois) ; 1<sup>re</sup> dose avant 15 sem. ; <span class="r">CI : ATCD d'invagination, SCID, malformation intestinale</span>. Non inclus au PEV algérien <i>(à vérifier)</i> ; recommandé par l'OMS. Norovirus : pas de vaccin.</li>
<li><b>Prévention</b> : lavage des mains eau + savon ; surfaces à l'eau de Javel ; précautions contact ; éviction de collectivité jusqu'à 48 h après la fin des symptômes <i>(à vérifier)</i> ; cuisson des coquillages ; eau potable.</li>
<li><span class="r">TIAC / épidémie en collectivité = déclaration obligatoire + enquête</span>.</li>
</ul></div></div>
