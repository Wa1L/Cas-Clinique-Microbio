<div class="box bl"><div class="bt">Caractères virologiques</div><div class="bb">
<p><span class="h">Virion</span> : <b>nu</b> (non enveloppé), icosaédrique T = 7, 40–45 nm ; capside = 72 pentamères de <b>VP1</b> + VP2/VP3 internes ; <span class="r">très résistant</span> dans le milieu extérieur.</p>
<p><span class="h">Génome</span> : <b>ADN db circulaire superenroulé</b> ≈ 5 kb, associé aux histones cellulaires. 3 régions : <b>précoce</b> (Ag T grand et petit), <b>tardive</b> (VP1, VP2, VP3 ; agnoprotéine JCV/BKV), <b>NCCR</b> (régulation ; <span class="r">réarrangements de la NCCR du JCV ⇒ PML</span>).</p>
<p><span class="h">Réplication</span> : <b>nucléaire</b>, cellule en phase S ; <b>Ag T grand</b> inactive <b>p53</b> et <b>pRb</b> ⇒ entrée en cycle (base de l'oncogenèse).</p>
<p><span class="h">Culture / ECP</span> : BKV sur cellules rénales humaines, Vero ; JCV difficile (cellules gliales fœtales) ; ECP lent : <b>inclusions intranucléaires</b>, vacuolisation (SV40 = <i>simian vacuolating virus</i>).</p>
<p><span class="h">Antigénie</span> : <b>hémagglutination</b> (hématies humaines O) ; génotypes BKV I–IV (I dominant), JCV 1–8 (distribution géographique) ; Ag T commun (anticorps anti-SV40 LT : réaction croisée BKV/JCV).</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li>Réservoir <b>strictement humain</b> (SV40 : singe) ; <b>primo-infection asymptomatique</b> dans l'enfance (BKV 2–5 ans ; JCV adolescence) ; transmission respiratoire / oro-fécale (probable), <b>greffon rénal</b> (BKV).</li>
<li>Latence à vie ; <b>réactivation = immunodépression</b> : greffe rénale ou de CSH, VIH (CD4 &lt; 200/mm³), biothérapies, hémopathies.</li>
<li>Excrétion urinaire intermittente chez le sujet sain (BKV, JCV) ⇒ <span class="r">virurie isolée non pathologique</span>.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>BKV</b> : lyse des cellules tubulaires et de l'urothélium ⇒ néphrite interstitielle, fibrose ; cystite hémorragique (conditionnement + réplication).</li>
<li><b>JCV</b> : forme à NCCR réarrangée neurotrope ⇒ lyse des <b>oligodendrocytes</b> ⇒ démyélinisation multifocale.</li>
<li><b>MCPyV</b> : intégration clonale + mutation tronquante de l'Ag T ⇒ perte de la réplication, conservation de la transformation.</li>
<li>Contrôle de l'infection par l'immunité <b>cellulaire T</b> ; la sérologie ne protège pas.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>BKV</b> : <b>néphropathie du greffon rénal</b> (1–10 %) : ↑ créatininémie, sans fièvre ; <span class="r">risque de perte du greffon</span>. Cystite hémorragique post-CSH (J7–J60), sténose urétérale.</li>
<li><b>JCV – LEMP / PML</b> : déficits focaux <b>subaigus</b> (hémiparésie, aphasie, hémianopsie, troubles cognitifs), <span class="r">sans fièvre ni effet de masse</span> ; <span class="r">pronostic sombre</span>.</li>
<li><b>MCPyV</b> : nodule rouge-violacé indolore, sujet âgé, photo-exposé ; métastases ganglionnaires précoces.</li>
<li>TSPyV : trichodysplasia spinulosa (greffé) ; ttt : ↓ IS, cidofovir topique, valganciclovir.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : <b>urine, plasma</b> (BKV) ; <b>LCR</b> (JCV) ; biopsie rénale / cérébrale ; biopsie cutanée (Merkel).</li>
<li><b>Direct</b> : <b>PCR quantitative</b> (charge virale) ; cytologie urinaire : <b>cellules « decoy »</b> (inclusion intranucléaire en verre dépoli) ; ME : particules de 40 nm.</li>
<li><b>Biopsie rénale</b> (confirmation) : <b>IHC anti-SV40 LT</b> (marque BKV et JCV) ; <span class="r">virémie plus prédictive que la virurie</span>.</li>
<li><b>PML</b> : PCR JCV du LCR (sensibilité imparfaite : si négative et suspicion forte ⇒ répéter / biopsie) ; IRM : hypersignal T2 de la substance blanche sous-corticale, <span class="r">sans prise de contraste</span>.</li>
<li><b>Sérologie</b> : peu utile (séroprévalence élevée) sauf <b>index anti-JCV</b> sous natalizumab.</li>
</ul>

<div class="box dr"><div class="bt">Antiviraux</div><div class="bb"><ul>
<li><span class="r">Aucun antiviral spécifique validé</span> (ni ADN polymérase virale cible, ni antiviral actif prouvé).</li>
<li><b>Cidofovir</b> : activité in vitro, <span class="r">néphrotoxique</span>, efficacité non démontrée (usage hors AMM : cystite hémorragique). Léflunomide, fluoroquinolones, IgIV : bénéfice non démontré.</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Néphropathie BKV</b> : <b>réduire l'immunosuppression</b> (tacrolimus / MMF) ; PCR plasmatique mensuelle jusqu'à M9 puis tous les 3 mois jusqu'à 2 ans post-greffe ; ↓ IS si virémie persistante &gt; 10<sup>3</sup> copies/mL (d'emblée si &gt; 10<sup>4</sup>).</li>
<li><b>PML</b> : <b>restaurer l'immunité</b> : TARV si VIH ; arrêt du natalizumab (± échanges plasmatiques) ; surveiller l'<b>IRIS</b> (corticoïdes).</li>
<li><b>Merkel</b> : exérèse large + ganglion sentinelle ± radiothérapie ; anti-PD-1/PD-L1 (avélumab, pembrolizumab) si métastatique.</li>
<li><b>Cystite hémorragique</b> : hydratation, irrigation vésicale.</li>
<li><b>Vaccin</b> : <span class="r">aucun</span> ; pas de vaccin au PEV algérien. <b>Déclaration</b> : non obligatoire.</li>
</ul></div></div>
