<div class="col">

<div class="box bl"><div class="bt">Caractères virologiques</div><div class="bb">
<p><span class="h">Virion</span> : <b>pléomorphe</b> (sphérique / filamenteux, 100–350 nm) ; <b>enveloppe</b> à spicules (labile : solvants, détergents, chaleur) ; nucléocapside hélicoïdale (N, P, L). <span class="r">Pas d'HA ni de NA</span> (≠ H / HN des <i>Paramyxoviridae</i> classiques ; G des <i>Henipavirus</i> aussi sans HA/NA).</p>
<p><span class="h">Génome / protéines</span> : ARN (–) non segmenté ; <b>F</b> (fusion), <b>G</b> (attachement, très variable), <b>SH</b> ; M, M2-1 (facteur d'élongation), M2-2 ; <b>NS1/NS2</b> (VRS seul) = antagonistes de l'interféron.</p>
<p><span class="h">Réplication</span> : <b>cytoplasmique</b> ; ARN polymérase ARN-dépendante <b>virale</b> (L) ; transcription → ARNm puis réplication via anti-génome ; bourgeonnement à la membrane.</p>
<p><span class="h">Culture / ECP</span> : cellules <b>HEp-2</b> ; <b>syncytia</b> (cellules géantes multinucléées) en 3–7 j ; hMPV : culture lente et difficile (<b>LLC-MK2 + trypsine</b>).</p>
<p><span class="h">Antigénie</span> : <b>F conservée</b> (cible des anticorps neutralisants / monoclonaux) ; <b>G variable</b> ⇒ sous-groupes A / B ; immunité <span class="r">incomplète et peu durable</span> ⇒ réinfections toute la vie ; protection partielle contre les formes basses sévères (grand enfant, adulte sain).</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li>Réservoir <b>strictement humain</b> ; <b>épidémies hivernales</b> (automne-hiver) ; quasi tous infectés avant <b>2 ans</b> (VRS) / <b>5 ans</b> (hMPV).</li>
<li>Transmission : <b>gouttelettes</b>, contact direct, <b>mains / objets souillés</b> ; très contagieux ; <span class="r">nosocomial +++</span> (pédiatrie).</li>
<li>Incubation 4–6 j ; excrétion 3–8 j (jusqu'à 3–4 sem chez le nourrisson ; <b>prolongée</b> chez l'immunodéprimé).</li>
<li>Terrain : nourrisson &lt; 6 mois, <b>prématuré</b>, DBP, <b>cardiopathie congénitale</b>, déficit immunitaire, sujet âgé, BPCO.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li>Entrée par <b>nasopharynx</b> → bronches / <b>bronchioles</b> ; <b>F</b> = fusion membranaire et formation de syncytia ; <b>pas de virémie</b>.</li>
<li><b>Nécrose</b> des cellules ciliées, œdème, <b>hypersécrétion</b> → bouchons muco-cellulaires ⇒ obstruction bronchiolaire, atélectasie, piégeage d'air.</li>
<li><b>NS1/NS2</b> : inhibition de l'interféron ⇒ échappement immunitaire.</li>
<li><span class="r">Vaccin inactivé au formol (années 1960) : maladie aggravée (ERD) → proscrit.</span></li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Bronchiolite aiguë du nourrisson</b> (&lt; 2 ans, pic 2–6 mois) : rhinite → toux, <b>polypnée, tirage</b>, sibilants, râles sous-crépitants, distension ; fièvre modérée ; durée 8–12 j.</li>
<li><span class="r">Signes d'alerte : apnées (prématuré, &lt; 2 mois), refus de boire, cyanose, SpO₂ &lt; 92 %</span> (seuil d'O₂ / hospitalisation).</li>
<li>Pneumonie, otite moyenne ; <span class="r">sibilants récurrents</span> en séquelle.</li>
<li><b>Adulte</b> : rhume ; <b>sujet âgé / immunodéprimé</b> : pneumonie sévère, exacerbation BPCO / asthme.</li>
<li><b>hMPV</b> : même spectre ; tableau souvent plus tardif (&gt; 6 mois).</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : <b>aspiration / écouvillon nasopharyngé</b> ; <span class="r">virus labile : transport à +4 °C, délai &lt; 24 h, jamais de congélation lente pour la culture</span>.</li>
<li><b>Direct</b> : <b>RT-PCR (multiplex)</b> = référence, sensible ++ ; <b>IFD</b> / <b>TDR antigénique</b> (bonne Se chez le nourrisson, <span class="r">faible chez l'adulte</span>).</li>
<li><b>Culture</b> : HEp-2, syncytia, rarement faite. <b>Sérologie</b> : sans intérêt (rétrospective).</li>
<li><b>Typage</b> A / B : RT-PCR / séquençage du gène <i>G</i> (épidémiologie).</li>
</ul></div></div>

<div class="box dr"><div class="bt">Antiviraux</div><div class="bb"><ul>
<li><b>Pas de traitement antiviral de routine</b>.</li>
<li><b>Ribavirine</b> (aérosol) : réservée aux formes sévères / <b>immunodéprimés</b>, efficacité discutée ; <span class="r">tératogène</span> (femmes enceintes exclues).</li>
<li><b>Échappement aux monoclonaux</b> : mutations du gène <i>F</i> ⇒ <b>palivizumab</b> (site antigénique II) ; <b>nirsévimab</b> (site Ø ; cas rares, surtout VRS-B).</li>
</ul></div></div>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Bronchiolite</b> : symptomatique ; <b>lavage nasal au sérum physiologique</b>, hydratation / fractionnement, position proclive ; <b>O₂</b> si hypoxémie ; hospitalisation selon gravité.</li>
<li><span class="r">Pas d'antibiotiques (sauf surinfection), ni corticoïdes, ni bronchodilatateurs systématiques.</span></li>
</ul>
