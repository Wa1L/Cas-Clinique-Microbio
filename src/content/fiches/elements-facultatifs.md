<div class="box bl"><div class="bt">Définition et vue d'ensemble</div><div class="bb">
<p><span class="h">Élément facultatif</span> = présent de façon <b>inconstante</b> selon l'espèce, la souche ou les conditions de culture ; non indispensable à la survie <i>in vitro</i> mais souvent <b>facteur de virulence</b> ou d'adaptation. S'oppose aux <b>éléments constants</b> (paroi*, membrane cytoplasmique, cytoplasme, ribosomes 70S, nucléoïde). <span class="r">*sauf Mycoplasma, sans paroi.</span></p>
<table class="mt">
  <tr><th>Élément</th><th>Nature chimique</th><th>Rôle principal</th></tr>
  <tr><td>Capsule</td><td>Polyoside (<span class="r">principale exception médicale : <i>B. anthracis</i>, polypeptide d'acide poly-D-glutamique</span>)</td><td>Antiphagocytaire, adhésion, Ag K</td></tr>
  <tr><td>Flagelle</td><td>Flagelline (protéine)</td><td>Mobilité, chimiotactisme, Ag H</td></tr>
  <tr><td>Pili/fimbriae</td><td>Piline (protéine)</td><td>Adhésion (communs) / conjugaison (sexuel)</td></tr>
  <tr><td>Spore</td><td>Peptidoglycane + DPA-Ca + SASP</td><td>Survie en conditions hostiles</td></tr>
  <tr><td>Plasmide</td><td>ADN db circulaire</td><td>Résistance, virulence, métabolisme</td></tr>
  <tr><td>Inclusions</td><td>Polyphosphates, PHB, glycogène</td><td>Réserves énergétiques</td></tr>
</table>
<p><span class="h">Flagelle</span> : filament + crochet + corpuscule basal — <b>4 anneaux</b> (L, P, S, M) chez les Gram ⊖, <b>2</b> (S, M) chez les Gram ⊕ (pas de membrane externe).</p>
<p><span class="h">Pili de type IV</span> : mobilité en saccades (<i>twitching</i>), transformation naturelle — <i>Neisseria</i>, <i>Pseudomonas</i>.</p>
</div></div>

<div class="box rd"><div class="bt">La spore — mécanismes</div><div class="bb">
<p><span class="h">Structure (de l'extérieur vers le centre)</span> : exosporium → tuniques protéiques → cortex (peptidoglycane peu réticulé) → paroi sporale → membrane → <b>core</b> déshydraté (10–30 % d'eau).</p>
<p><span class="h">Bases de la résistance</span> : déshydratation du core + <b>dipicolinate de calcium (DPA-Ca)</b> + <b>SASP</b> (protéines liant l'ADN, protection UV) + minéralisation + enzymes au repos.</p>
<ul>
<li><b>Sporulation</b> : déclenchée par la <b>carence nutritionnelle</b> ; ~7 stades, plusieurs heures ; 1 bactérie → 1 spore <span class="r">(pas une multiplication)</span>.</li>
<li><b>Germination</b> : activation (chaleur) → germination (perte de réfringence, libération du DPA) → croissance végétative.</li>
<li>Genres : <i>Bacillus</i>, <i>Clostridium</i>, <i>Clostridioides</i>, <i>Geobacillus</i>, <i>Sporosarcina</i>.</li>
</ul>
</div></div>

<div class="box gr"><div class="bt">Applications diagnostiques et thérapeutiques</div><div class="bb"><ul>
<li><b>Sérotypage</b> : Ag O (paroi) · <b>Ag H</b> (flagelle) · <b>Ag K</b> (capsule) → <i>E. coli</i> O157:H7, schéma de Kauffmann-White (<i>Salmonella</i>).</li>
<li><b>Vaccins polyosidiques conjugués</b> contre les bactéries capsulées : <i>H. influenzae</i> b (PRP), pneumocoque, méningocoque — conjugaison à une protéine porteuse → réponse T-dépendante chez le nourrisson.</li>
<li><b>Plasmides</b> : support transférable de la résistance (BLSE, carbapénémases, <i>mcr</i>) → diffusion horizontale, épidémies de clones et de plasmides.</li>
<li><b>Spores</b> : résistent à l'ébullition et aux antiseptiques usuels → <b>autoclave 121 °C / 15–20 min</b> ; indicateurs biologiques de stérilisation (<i>G. stearothermophilus</i> pour la vapeur, <i>B. atrophaeus</i> pour la chaleur sèche et l'oxyde d'éthylène).</li>
<li><span class="r">Solutions hydro-alcooliques inactives sur les spores</span> → lavage au savon + eau de Javel (<i>C. difficile</i>).</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li>Facultatif ≠ inutile : la plupart sont des <b>facteurs de virulence</b> (capsule, pili d'adhésion) ou d'adaptation (plasmide).</li>
<li><span class="r">Capsule de <i>B. anthracis</i> = polypeptidique</span> (acide poly-D-glutamique) — principale exception médicale à la règle polyosidique (aussi <i>B. licheniformis</i>, <i>S. epidermidis</i>).</li>
<li><span class="r">La spore n'existe que chez les Gram ⊕</span> ; une spore par bactérie, ce n'est pas un mode de multiplication.</li>
<li>Pilus sexuel codé par le <b>plasmide F</b> ; le plasmide est un réplicon autonome, perdu sans létalité (<i>curing</i>).</li>
</ul></div></div>
