<div class="box bl"><div class="bt">Principe et marqueurs</div><div class="bb"><ul>
<li><span class="h">VCA</span> (antigène de capside) : IgM = infection aiguë ; IgG = contact (vie entière).</li>
<li><span class="h">EA</span> (précoce) : <b>EA-D</b> (diffus) = primo/réactivation ; <b>EA-R</b> (restreint) = Burkitt.</li>
<li><span class="h">EBNA-1</span> (nucléaire) : marqueur <b>tardif</b> = infection passée.</li>
<li><span class="h">Hétérophiles</span> (Paul-Bunnell-Davidsohn, Monospot) : Ig <b>non spécifiques d'EBV</b>, + chez ~85-90 % des adultes, <span class="r">souvent − avant 4-5 ans</span> ; faux + : lymphome, hépatite, LES, VIH.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Limites et situations particulières</div><div class="bb"><ul>
<li><b>Immunodéprimés / greffés</b> : sérologie peu fiable (défaut de synthèse d'Ig, IgIV, transfusion) → <b>PCR quantitative EBV</b> (sang total/plasma).</li>
<li><b>Nouveau-né</b> : IgG maternelles jusqu'à ~6 mois ; IgM = infection congénitale rare.</li>
<li><b>Avidité IgG VCA</b> : faible = infection &lt; 3 mois.</li>
<li><span class="r">Une IgG VCA seule ne date pas l'infection.</span></li>
</ul></div></div>

<div class="box rd"><div class="bt">Programmes de latence</div><div class="bb"><ul>
<li><b>0</b> : lymphocyte B mémoire (aucune protéine) = <b>portage</b>.</li>
<li><b>I</b> : EBNA-1 seule (Burkitt, gastrique) ; <b>II</b> : EBNA-1 + LMP1 + LMP2 (Hodgkin, NPC, NK/T).</li>
<li><b>III</b> : tous les EBNA + LMP (MNI, PTLD, LCL) ; <span class="r">LMP1 = oncoprotéine</span>.</li>
<li>Dans les tumeurs, les anticorps ne servent qu'à l'orientation : <b>EBER-ISH = référence tissulaire</b>.</li>
</ul></div></div>

<div class="box db"><div class="bt">Stratégie diagnostique</div><div class="bb"><ul>
<li><b>Suspicion de MNI</b> : NFS (syndrome mononucléosique) + hétérophiles ; si négatifs ou enfant → <b>VCA IgM/IgG + EBNA</b>.</li>
<li><b>Doute</b> : avidité IgG, 2<sup>e</sup> prélèvement à 2-3 sem. (même technique), PCR.</li>
<li><b>Immunodéprimé</b> : PCR quantitative, suivi cinétique.</li>
<li><b>Tissu</b> : EBER-ISH ; LMP1 en IHC.</li>
</ul></div></div>

<div class="box key"><div class="bt">À retenir / pièges d'examen</div><div class="bb"><ul>
<li><span class="r">VCA IgM + / IgG + / EBNA − = primo-infection</span> ; EBNA + exclut une primo-infection datant de &lt; 2-4 mois.</li>
<li><span class="r">Hétérophiles négatifs ≠ pas de MNI</span> (enfant &lt; 5 ans, début précoce).</li>
<li><span class="r">IgA VCA/EA = NPC</span> ; EA-R = Burkitt ; chez le greffé → <b>PCR, pas sérologie</b>.</li>
<li>EBV = <b>1<sup>er</sup> virus oncogène humain</b> décrit ; portage à vie (&gt; 90 % adultes).</li>
</ul></div></div>
