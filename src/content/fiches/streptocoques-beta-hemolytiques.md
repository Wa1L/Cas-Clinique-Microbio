<div class="box bl"><div class="bt">Caractères bactériologiques</div><div class="bb">
<p><span class="h">Morphologie</span> : cocci <b>Gram +</b> (0,6–1 µm) en <b>chaînettes</b> (surtout en milieu liquide), immobiles, asporulés, <b>catalase –</b>, oxydase – ; SGA capsulé (ac. hyaluronique).</p>
<p><span class="h">Exigences</span> : aéro-anaérobies facultatifs, exigeants ; <b>gélose au sang</b> frais (mouton 5 %).</p>
<p><span class="h">Culture</span> : 35–37 °C, 5 % CO₂ (ou anaérobiose), 18–24 h ; colonies 0,5–1 mm grises translucides + <b>halo β net</b> ; <span class="r">streptolysine O (O₂-labile) : stries profondes / anaérobiose améliorent l'hémolyse</span>.</p>
<p><span class="h">Hémolysines</span> : <b>SLO</b> (antigénique → ASLO) ; <b>SLS</b> (O₂-stable, non antigénique).</p>
<p><span class="h">Biochimie</span> : <b>PYR +</b> (SGA) ; bacitracine S (SGA) ; CAMP + / hippurate + (SGB) ; MALDI-TOF.</p>
<p><span class="h">Antigénie</span> : <b>polyoside C</b> (groupage de Lancefield : A, B, C, G) ; SGA : <b>protéine M</b> (typage <i>emm</i>, &gt; 200 types), T, R ; SGB : capsule, 10 sérotypes (Ia, Ib, II–IX), <b>III</b> = méningites néonatales.</p>
</div></div>

<div class="box br"><div class="bt">Épidémiologie</div><div class="bb"><ul>
<li><b>SGA</b> : réservoir <b>humain strict</b> (pharynx, peau) ; gouttelettes de Flügge, contact cutané ; enfant 5–15 ans, saison froide ; portage pharyngé 10–20 % des enfants.</li>
<li><b>SGB</b> : commensal digestif et <b>vaginal</b> (10–30 % des femmes) ; <b>transmission verticale</b> (accouchement) ; nosocomiale rare.</li>
<li><b>C/G</b> : pharynx, peau, tube digestif ; adulte âgé, terrain vasculaire / diabète.</li>
<li>Terrain invasif : varicelle (SGA), plaie, diabète, immunodépression, post-partum.</li>
</ul></div></div>

<div class="box rd"><div class="bt">Physiopathologie</div><div class="bb"><ul>
<li><b>Protéine M + capsule</b> : anti-phagocytose ; adhésines (acide lipotéichoïque, F) ; <b>streptolysines O/S</b>.</li>
<li><b>Exotoxines pyrogènes SpeA, B, C</b> = <b>superantigènes</b> → scarlatine, choc toxique ; streptokinase, hyaluronidase, DNase B, SpyCEP (diffusion tissulaire).</li>
<li><b>RAA</b> : mimétisme moléculaire (protéine M / myosine, valve) ; <b>GNA</b> : complexes immuns, souches « néphritogènes » (C3 ↓).</li>
<li><b>SGB</b> : capsule à acide sialique, β-hémolysine, facteur CAMP ; <span class="r">nouveau-né sans anticorps maternels anti-capsule</span>.</li>
</ul></div></div>

</div>

<div class="col">

<div class="box or"><div class="bt">Clinique</div><div class="bb"><ul>
<li><b>Angine SGA</b> : fièvre, odynophagie, adénopathies ; <b>scarlatine</b> (éruption + langue framboisée). Pas de toux ni rhinite.</li>
<li><b>Peau</b> : impétigo, érysipèle, dermohypodermite ; <span class="r">fasciite nécrosante + choc toxique (urgence chirurgicale)</span>.</li>
<li><b>Post-streptococciques non suppurées</b> (SGA) : <span class="r">RAA (2–3 sem après angine ; jamais après peau ; cardite = séquelle)</span> ; <b>GNA</b> (10–21 j après angine, 3–6 sem après impétigo).</li>
<li><b>SGB</b> : néonatal <b>précoce</b> (≤ 6 j : septicémie, pneumonie) ; <b>tardif</b> (7 j–3 mois : méningite) ; adulte : peau, os, bactériémie.</li>
</ul></div></div>

<div class="box db"><div class="bt">Diagnostic</div><div class="bb"><ul>
<li><b>Prélèvement</b> : écouvillon pharyngé (amygdales + piliers, <span class="r">sans toucher langue ni joues</span>) ; pus, hémocultures, LCR ; SGB : vaginal ± rectal (35–37 SA, milieu enrichi Todd-Hewitt).</li>
<li><b>TDR angine</b> : enfant ≥ 3 ans ; <span class="r">sans intérêt avant 3 ans</span>. <b>Direct</b> : Gram. <b>Culture</b> : gélose sang, 35–37 °C, 5 % CO₂, 24–48 h.</li>
<li><b>Identification</b> : catalase –, groupage latex (A, B, C, G), PYR, bacitracine, CAMP / hippurate (SGB), MALDI-TOF ; <b>typage</b> <i>emm</i>.</li>
<li><b>Sérologie</b> (RAA, GNA) : <b>ASLO</b> pic 3–5 sem ; <span class="r">ASLO faible après infection cutanée → ASDOR / anti-DNase B</span>.</li>
<li><b>ATBg (CLSI M100)</b> : <b>disques</b> : MH + 5 % sang de mouton (sans NAD), McFarland 0,5, 35 °C, CO₂ 5 %, 20–24 h ; <b>CMI</b> : bouillon MH ajusté en cations + 2,5–5 % sang de cheval lysé, 20–24 h ; ATCC <i>S. pneumoniae</i> 49619.</li>
</ul></div></div>

<div class="box dr"><div class="bt">Résistance aux antibiotiques</div><div class="bb"><ul>
<li><b>Naturelle</b> : aminosides bas niveau.</li>
<li><b>β-lactamines</b> : <span class="r">pénicilline G jamais de résistance (SGA)</span> ; SGB : sensible (rares CMI ↑ par PLP2x, à surveiller).</li>
<li><b>Macrolides-lincosamides</b> : <b><i>erm</i></b> (méthylase) ou <b><i>mef</i></b> (efflux) ; tétracyclines <i>tet(M)</i> fréquente (SGB) ; FQ : <i>gyrA/parC</i> (rare). <b>D-test</b> : Ery 15 µg / Clinda 2 µg à <b>12 mm</b> bord à bord (strepto β ; ≠ staph) ; <span class="r">D+ → clinda rendue R</span>.</li>
</ul>

<div class="box gr"><div class="bt">Traitement et prévention</div><div class="bb"><ul>
<li><b>Angine SGA</b> : amoxicilline 50 mg/kg/j en 2 prises (adulte 2 g/j) 6 j <b>ou</b> pénicilline V 10 j (à vérifier). Allergie : C2G (céfuroxime-axétil) / C3G orale (cefpodoxime), macrolide (azithromycine 3 j).</li>
<li><b>Invasif / fasciite / choc toxique</b> : pénicilline G IV <b>+ clindamycine</b> (anti-toxine) ± IgIV ; <b>chirurgie</b>.</li>
<li><b>RAA</b> : prévention 2<sup>aire</sup> par <b>benzathine-pénicilline IM 1,2 MUI / 3–4 sem</b>, ≥ 5 ans et jusqu'à ≥ 21 ans (à vérifier) ; angine bien traitée = prévention 1<sup>aire</sup> du RAA <span class="r">(pas de la GNA)</span>.</li>
<li><b>SGB</b> : <b>antibioprophylaxie per-partum</b> (pénicilline G ou ampicilline) si portage, ATCD néonatal, fièvre, RPM &gt; 12 h, prématurité ; néonatal : ampicilline + gentamicine ; méningite : C3G / amoxicilline forte dose.</li>
<li><b>Vaccin</b> : aucun (SGA, SGB). Éviction scolaire 2 j sous ATB (angine SGA).</li>
</ul></div></div>
