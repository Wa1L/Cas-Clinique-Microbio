🦠 II · Virologie Les Hépatites virales 81 / 219

Cas 6.4

SOURCE : CONCOURS MCA, janvier 2021

CAS CLINIQUE 1

Madame X âgée de 34 ans a passé l’été en Egypte, 3 semaines après son retour, elle se présente aux urgences médicales avec le tableau clinique suivant :

  • Fièvre à 38°C, asthénie

  • Arthralgies, myalgies

  • Ictère cutanéo-muqueux

2 de ses enfants ont présenté une fièvre + des vomissements quelques jours avant. Bilan hépatique

  • ASAT : 1500, ALAT : 1120

  • Bilirubine totale : 132, bilirubine conjuguée : 115 Echographie hépatique : aspect normal du foie, voies biliaires libres.

Question n=1 :

A-Enumérer les étiologies virales possibles? B-Quel diagnostic vous paraît le plus probable? Arguments? C-Quel bilan faites-vous pour le confirmer? D-Quel bilan viral complémentaire faites-vous? Les IgM anti-HAV sont positives. Question n=2 : Quel traitement proposez-vous? Quelles sont les complications possibles? Question n=3 : Quelles sont les principales caractéristiques biologiques de ce virus? Quelles sont donc les conséquences épidémiologiques? Question n°4 : Quels sont les modes de transmission? Question n=5 : Quel type de vaccin existe-t-il? Quelles sont ses indications?

CORRIGÉ · CAS 6.4

Corrigé type issu du document d’examen, reproduit tel quel.

Question n=1 :

A-Quelles sont toutes les étiologies virales possibles? 1.HAV

2.HBV/HDV

3.HCV

4.HEV

5.EBV

6.CMV

7.HSV

  1. Autres : HHV6, Fièvre jaune, autres arbovirus B-Quel diagnostic vous paraît le plus probable? Arguments? Hépatite virale A aiguë

  • Hépatite infectieuse aiguë la plus fréquente

  • Séjour en pays de forte prévalence

  • Cas groupés

  • Cytolyse majeure, cholestase modérée

  • Pas d’argument pour une obstruction des voies biliaires C-Quel bilan faites-vous pour le confirmer? Sérologie : IgM anti-VHA D-Quel bilan viral complémentaire faites-vous?

  • Hépatite B : AgHBs, Ac anti HBs, Ac anti HBc

  • Hépatite C : Ac anti VHC

  • Hépatite E : IgM anti VHE +/*−*PCR Symptômes chez 70 à 90% des adultes (10% avant 5 ans). VHB et VHC : primo-infection rarement symptomatique. VHE : même contexte que VHA mais plus rare. Question n=2 : Quel traitement proposez-vous? Quelles sont les complications possibles? Symptomatique, Hépatite fulminante 0,2% des symptomatiques; rechute 10% un à 3 mois après. Pas de chronicité. Question n=3 : Quelles sont les principales caractéristiques biologiques de ce virus? Quelles sont donc les conséquences épidémiologiques? Virus nu, résistant dans le milieu extérieur. Persiste dans l’environnement. Question n=4 : Quels sont les modes de transmission? Fécal-oral : contamination fécale de l’environnement, mains sales, activités culinaires (fruits de mer, eau non potable). Pays endémie + + +. Question n=5 : Quel type de vaccin existe-t-il? Quelles sont ses indications? Viral inactivé. Havrix : voyageurs, professionnels exposés ou exposants.
