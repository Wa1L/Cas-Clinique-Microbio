Genre Neisseria
Fiche de systématique bactérienne – DEMS Microbiologie
Phylum Pseudomonadota · Classe Betaproteobacteria · Ordre Neisseriales · Famille Neisseriaceae
EspèceOxydaseGlucoseMaltoseCapsuleIntérêt clinique
N. meningitidis (méningocoque)++++Méningite purulente et septicémie (purpura fulminans) ; urgence médico-légale, déclaration obligatoire.
N. gonorrhoeae (gonocoque)++––Gonorrhée (IST) : urétrite, cervicite, PID, ophtalmie néonatale ; forte résistance acquise.
N. lactamica+++–Commensal de l'enfant (rhinopharynx) ; piège : β-galactosidase +, peut être confondu avec le méningocoque.
N. sicca / N. mucosa+++–Commensaux des muqueuses ; colonies sèches ou muqueuses.
Caractères bactériologiques

Morphologie : diplocoque Gram négatif « en grains de café » (faces concaves adjacentes) ; piège : extraits de la cellule hôte (intra-cellulaires dans les PNN).

Exigences : capnophile (5–10 % CO₂), polypathique, hydraté ; mauvaise croissance sur gélose simple.

Culture : gélose chocolat (sang chauffé + PolyViteX), 37 °C, 5 % CO₂, 24–48 h ; colonies de 1–2 mm, grises, lisses, oxydase +.

Biochimie : oxydase +, catalase + ; oxydation du glucose (GKC) ± maltose ± lactose — base de l'identification.

Antigénie : capsule polysaccharidique du méningocoque (sérogroupes A, B, C, W, Y, X) ; pili et protéines Opa/porines chez le gonocoque.

Épidémiologie
  • Réservoir strictement humain ; méningocoque : portage rhinopharyngé (10 %) ; gonocoque : muqueuses génitales.
  • Transmission : gouttelettes (méningocoque) ; rapports sexuels et accouchement (gonocoque).
  • Terrain : enfants/adolescents (méningite) ; jeunes adultes sexuellement actifs (gonorrhée) ; déficit en complément (C5–C9) : méningites à récidive.
Physiopathologie
  • Capsule (méningocoque) : anti-phagocytaire, immunogène (vaccins).
  • Pili + Opa : adhésion aux muqueuses ; IgA protease : neutralisation des IgA locales.
  • LPS (endotoxine) : choc inflammatoire — purpura fulminans (C5a, TNF) ; passage méningé par voie hématogène.
Clinique
  • Méningite cérébro-spinale : fièvre + céphalées + raideur de nuque + vomissements ; purpura fulminans = urgence absolue (antibiothérapie IV avant transfert).
  • Gonorrhée : urétrite masculine purulente, cervicite souvent muette chez la femme (risque de salpingite/PID, stérilité) ; proctite, pharyngite ; ophtalmie néonatale (instillation de nitrate d'argent à la naissance).
  • Formes disséminées : arthrite, septicémie.
Diagnostic
  • Prélèvement : LCR (méningite) ; écouvillon urétral/cervical (gonorrhée) ensemencement immédiat sur milieu gélosé chauffé à 35–37 °C, jamais réfrigéré.
  • Direct : Gram (diplocoques G– intra-cellulaires), antigènes solubles (latex agglutination) ; PCR : référence (LCR, sang) — diagnostique de certitude de la méningite.
  • Culture : gélose chocolat + CO₂, 24–48 h ; identification biochimique (GKC) ou API NH / MALDI-TOFF.
  • Sérotypage : sérogroupe capsulaire (latex / PCR) pour le méningocoque ; ATBg systématique.
Résistance aux antibiotiques
  • Naturelle : résistant aux macrolides, glycopeptides, vancomycine.
  • Acquise (gonocoque) : pénicillinase plasmidique (TEM), chromosomique (penA mosaïque), résistance aux cyclines, quinolones (gyrA) ; C3G = 1ʳᵉ intention (céfixime / ceftriaxone) ; phénotype de lecture obligatoire (ATBg de première intention : C3G, spectinomycine).
  • Méningocoque : habituellement S à la pénicilline G (CMI en hausse possible) ; piège : résistance aux sulfamides fréquente.
Traitement et prévention
  • Méningite : C3G IV en urgence (céfotaxime) 7 jours ; purpura fulminans : ceftriaxone IV immédiate (avant transfert).
  • Gonorrhée : ceftriaxone IM dose unique (± azithromycine selon recommandations) ; traiter le partenaire.
  • Vaccin méningocoque : polysaccharidique conjugée A/C/W/Y (MenACWY, pèlerinage à La Mecque) et vaccin protéique B (MenB) ; pas de vaccin gonococcique.
  • Prophylaxie de l'entourage : rifampicine ou ciprofloxacine (sujets contacts) ; déclaration obligatoire de la méningite à méningocoque.
