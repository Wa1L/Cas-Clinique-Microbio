# Cas 1.49

SOURCE : *Examen de Rattrapage Résidanat 3*^ème^ *année — Année universitaire 2014-2015, le 26/10/2015*

**Profils de sensibilité des entérobactéries aux** *β***-lactamines (phénotypes sauvages) :** Citez les espèces bactériennes appartenant à chaque groupe phénotypique et complétez les profils correspondants?


| Groupe phénotypique | Profil de sensibilité (I, R ou S) |
|---|---|
| Phénotype sensible Groupe 1 : | AMX AMC TIC TCC PIP PTZ CF CTX CAZ |
| Phénotype pénicillinase de bas niveau Groupe 2 : | AMX AMC TIC TCC PIP PTZ CF CTX CAZ |
| Phénotype céphalosporinase bas niveau Groupe 3 : | AMX AMC TIC TCC PIP PTZ CF CTX CAZ |
| Phénotype pénicillinase et céphalosporinase bas niveau Groupe 4 : | AMX AMC TIC TCC PIP PTZ CF CTX CAZ |
| Phénotype céfuroximase Groupe 5 : | AMX AMC TIC TCC PIP PTZ CF CTX CAZ |
